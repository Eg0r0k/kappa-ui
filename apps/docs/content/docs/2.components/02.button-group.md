## Usage

```vue
<script setup lang="ts">
import { Button } from '@/components/ui/button'
import { ButtonGroup } from '@/components/ui/button-group'
</script>

<template>
  <ButtonGroup aria-label="Text alignment">
    <Button variant="outline" color="neutral">Left</Button>
    <Button variant="outline" color="neutral">Center</Button>
    <Button variant="outline" color="neutral">Right</Button>
  </ButtonGroup>
</template>
```

The group only joins its children: it squares the corners where they meet and overlaps two neighbours that both have an edge by 1px, so the edges of outlined buttons, inputs and text meet in a single line. It passes nothing down, so each button keeps its own `variant`, `color` and `size`.

### Separator

Buttons without an edge need a divider to read as separate. `ButtonGroupSeparator` draws one the height of the group; in a vertical group, give it `orientation="horizontal"`.

::component-preview{name="button-group-with-separator"}
::

### Text and inputs

`ButtonGroupText` puts a label, prefix or suffix inside the group, at the group's height. Inputs join like buttons: a text field between a prefix and a button reads as one control. With `as-child`, the text can be a `label` for the input.

### Connected

Made with classes only. Buttons sit 2px apart, outer corners are fully round, and inner corners stay small (set them with `--button-group-radius`). The selected button (`aria-pressed`) rounds all its corners, with a smooth transition.

Why not `rounded-full`? If one corner has an infinite radius, the browser shrinks every corner of the box, and the small inner ones disappear. So the outer radius is half the button's height.

## Accessibility

The group renders `role="group"`; give it an `aria-label` that names what its buttons do together. When the buttons pick one option, as in the connected example, mark the chosen one with `aria-pressed`.
