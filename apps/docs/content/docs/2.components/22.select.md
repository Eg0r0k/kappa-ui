## Usage

```vue
<script setup lang="ts">
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from '@/ui/select'

const fruit = ref<string>()
</script>

<template>
  <Select v-model="fruit">
    <SelectTrigger aria-label="Fruit">
      <SelectValue placeholder="Select a fruit" />
    </SelectTrigger>
    <SelectContent>
      <SelectItem value="apple">Apple</SelectItem>
      <SelectItem value="banana">Banana</SelectItem>
    </SelectContent>
  </Select>
</template>
```

`Select` is Reka UI's select with delta-ui's styles. The trigger is a button with `role="combobox"` and the list a `role="listbox"`: the arrow keys open it and move through the options, typing jumps to the option that starts with the typed letters, and Enter or Space chooses. The list is [modal](/docs/getting-started/overlays): while it is open, an outside click only closes it.

The trigger has the [input](/docs/components/input)'s variants and sizes, so a select sits in a form row next to inputs of the same size. Inside a [Field](/docs/components/field) it takes its `id`, description, error and state from it.

### Groups

`SelectGroup` gathers options under a `SelectLabel`, which also names the group for screen readers, and `SelectSeparator` draws a line between groups. A list taller than the space, or than a `max-h-*` class on `SelectContent`, scrolls, with buttons at the ends that scroll it while the pointer rests on them.

::component-preview{name="select-groups"}
::

### Position

By default the list opens below the trigger, or above it when there is no room. With `position="item-aligned"` it opens over the trigger with the selected option exactly where the trigger's text is, as a native select does on macOS.

::component-preview{name="select-item-aligned"}
::

### Icons

The trigger repeats the selected option's text, not its markup. To show an icon in the trigger too, fill `SelectValue` yourself from the selected value.

::component-preview{name="select-icons"}
::

### Field

A select in a required field gets `aria-required`, and when the field is invalid, `aria-invalid` and a `--destructive` border. Give the select a `name` to submit its value with the form through a hidden native select. Press Invite without choosing a role.

::component-preview{name="select-field"}
::

### Data attributes

::data-slots
---
rows:
  - slot: select-trigger
    attributes: data-state, data-placeholder, data-disabled, data-variant
    description: The button. `data-placeholder` is set while nothing is selected.
  - slot: select-value
    description: The selected option's text, or the placeholder.
  - slot: select-content
    attributes: data-state, data-side, data-align
    description: The list's panel.
  - slot: select-scrim
    description: The transparent layer under the open list that takes the first outside click.
  - slot: select-viewport
    description: The scrolling part of the list.
  - slot: select-item
    attributes: data-state, data-highlighted, data-disabled
    description: One option. `data-state` is `checked` for the selected one.
  - slot: select-item-indicator
    description: The check at the end of the selected option.
  - slot: select-label
    description: A group's name.
  - slot: select-separator
    description: The line between groups.
---
