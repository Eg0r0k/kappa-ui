## Usage

```vue
<script setup lang="ts">
import { Avatar, AvatarFallback, AvatarImage } from '@/components/ui/avatar'
</script>

<template>
  <Avatar>
    <AvatarImage src="/me.jpg" alt="Kappa Person" />
    <AvatarFallback>KP</AvatarFallback>
  </Avatar>
</template>
```

`AvatarImage` stays hidden until its file has loaded, and `AvatarFallback` shows until then, and for good if the file fails. Put initials or an icon in it; the root sets the text and icon size for each `size`.

## Examples

### Sizes

`xs` to `xl` are 24, 32, 40, 48 and 64px. `md` is the default. Text and icons in the fallback scale with the size.

::component-preview{name="avatar-sizes"}
::

### Fallback

The fallback renders at once, so a slow photo shows initials first. `delay-ms` holds it back for photos that usually arrive quickly, to avoid a flash of initials. A square avatar is `class="rounded-lg"` on `Avatar`: the root clips, and the fallback has no radius of its own.

::component-preview{name="avatar-fallback"}
::

### Group

`AvatarGroup` overlaps its children by a quarter of their size and separates them with a 2px ring. `AvatarGroupCount` is the same circle as a fallback, with whatever you put in it. The ring is the page background; on another surface, set `--avatar-ring` to it.

::component-preview{name="avatar-group"}
::

### With Image

For a `srcset`, `<picture>` sources, or a loading layer, put [Image](/docs/components/image) in the avatar in place of `AvatarImage`. It fills the circle, and its `ImageError` is the fallback, so `AvatarFallback` is not needed. Never nest one inside the other: `AvatarImage` tracks the load through a request of its own and would hide `Image` and its layers until that finished.

::component-preview{name="avatar-image"}
::

### Data attributes

::data-slots
---
rows:
  - slot: avatar
    attributes: data-size
    description: The root, a span that clips to a circle.
  - slot: avatar-image
    attributes: ''
    description: "The img. Hidden with `display: none` until it has loaded."
  - slot: avatar-fallback
    attributes: ''
    description: The fallback, rendered while the image has not loaded.
  - slot: avatar-group
    attributes: ''
    description: The row.
  - slot: avatar-group-count
    attributes: data-size
    description: The count, a circle like a fallback.
---
::

### CSS variables

::css-vars
---
rows:
  - name: --avatar-size
    default: 2.5rem for md
    description: Width and height of an avatar or a count, set by `size`. A group overlaps its children by a quarter of it.
  - name: --avatar-ring
    default: var(--color-background)
    description: Colour of the 2px ring between the members of a group. Set it on the group to the surface it sits on, for example `class="[--avatar-ring:--theme(--color-card)]"`.
---
::
