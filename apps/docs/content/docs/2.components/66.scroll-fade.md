## Installation

::install-tabs{name="scroll-fade"}
::

Adds `@import "@kappa-ui/core/tailwind.css";` to your global stylesheet, once, even if other components need it too.

::callout
Already importing `shadcn-vue/tailwind.css`? It defines the same mask classes. They don't conflict, so you can keep both.
::

## Mask or overlay?

| | `scroll-fade` (mask) | `scroll-fade-overlay` |
|---|---|---|
| How it fades | content turns transparent | a gradient covers the edge |
| Background | anything, even an image | one plain colour |
| While scrolling | repaints near an edge, can lag on long lists | free |
| On a [ScrollArea](/docs/components/scroll-area) | doesn't work | works |

Short version: use the overlay by default. Reach for the mask only when the background isn't a plain colour.

## Usage

```vue
<script setup lang="ts">
import { vScrollFade } from "@kappa-ui/core/scroll-fade";
</script>

<!-- mask: on the scroll container itself -->
<div v-scroll-fade class="scroll-fade overflow-y-auto">…</div>

<!-- overlay: on a wrapper around the scroll container -->
<div class="scroll-fade-overlay overflow-hidden">
  <div v-scroll-fade class="h-full overflow-y-auto">…</div>
</div>

<!-- overlay on a scroll area: no directive needed -->
<ScrollArea orientation="horizontal" class="scroll-fade-overlay-x">…</ScrollArea>
```

Always put `v-scroll-fade` on the scroll container. Without it, [Firefox](#firefox) keeps both edges faded.

::callout
The overlay's wrapper must have exactly one child: the scroll container. Add a second child, and the fade disappears.

## Customizing

**Depth.** `scroll-fade-8` or `scroll-fade-[40px]` sets how deep the fade goes, in both modes. In mask mode, each edge can have its own: `scroll-fade-t-4 scroll-fade-b-12`.

**Colour.** The overlay fades into `--scroll-fade-color`, the page background by default. Cards, dialogs, menus, popovers and other surfaces of the kit set it for you. On a surface of your own, set it to match:

```vue
<div class="scroll-fade-overlay overflow-hidden bg-muted [--scroll-fade-color:var(--muted)]">
  <div v-scroll-fade class="h-full overflow-y-auto">…</div>
</div>
```

**Edges.** `-y` for top and bottom (the default), `-x` for left and right, or one edge: `-t`, `-b`, `-s`, `-e`. Use `-none` to turn the fade off, for example `md:scroll-fade-none`.

**Speed.** `--scroll-fade-reveal` sets how far you scroll before an edge fully fades in.

## Reference

| Class | Mode | Edges |
|---|---|---|
| `scroll-fade`, `scroll-fade-y` | mask | top and bottom |
| `scroll-fade-x` | mask | start and end |
| `scroll-fade-t`, `-b`, `-l`, `-r`, `-s`, `-e` | mask | one edge; `s` and `e` follow the reading direction |
| `scroll-fade-<n>`, `scroll-fade-[<length>]` | both | fade depth |
| `scroll-fade-t-<n>`, `-b-<n>`, `-s-<n>`, `-e-<n>` | mask | depth of one edge |
| `scroll-fade-none` | mask | removes the mask |
| `scroll-fade-overlay`, `scroll-fade-overlay-y` | overlay | top and bottom |
| `scroll-fade-overlay-x` | overlay | start and end |
| `scroll-fade-overlay-s`, `-e`, `-t`, `-b` | overlay | one edge |
| `scroll-fade-overlay-none` | overlay | removes both overlays |

::css-vars
---
rows:
  - name: --scroll-fade-size
    default: min(12%, calc(var(--spacing) * 10))
    description: Depth of the fade, for both modes.
  - name: --scroll-fade-t-size
    default: --scroll-fade-size
    description: Depth of one edge in mask mode; also -b-, -s-, -e-.
  - name: --scroll-fade-reveal
    default: calc(var(--spacing) * 24)
    description: Scroll distance over which an edge fades in or out.
  - name: --scroll-fade-color
    default: var(--background)
    description: Colour the overlay gradients run to. Kit surfaces set it to their own background.
