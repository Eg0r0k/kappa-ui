## Usage

```vue
<script setup lang="ts">
import { Bold, Italic } from '@lucide/vue'

import { Toolbar, ToolbarButton, ToolbarSeparator, ToolbarToggleGroup, ToolbarToggleItem } from '@/components/ui/toolbar'
</script>

<template>
  <Toolbar aria-label="Formatting">
    <ToolbarToggleGroup type="multiple" size="icon-sm">
      <ToolbarToggleItem value="bold" aria-label="Bold"><Bold /></ToolbarToggleItem>
      <ToolbarToggleItem value="italic" aria-label="Italic"><Italic /></ToolbarToggleItem>
    </ToolbarToggleGroup>
    <ToolbarSeparator />
    <ToolbarButton>Share</ToolbarButton>
  </Toolbar>
</template>
```

Give it an `aria-label` so screen readers know what it's for.

- `ToolbarButton`, `ToolbarLink`: a regular [Button](/docs/components/button), `ghost` + `neutral` by default
- `ToolbarToggleGroup`, `ToolbarToggleItem`: a [ToggleGroup](/docs/components/toggle-group) with gaps instead of joined edges
- `ToolbarSeparator`: a divider

## Examples

### Vertical

`orientation="vertical"` stacks the parts and the up and down arrows move focus. Toggle groups and separators follow.

::component-preview{name="toolbar-vertical"}
::

### Ghost

`variant="ghost"` drops the frame, for a row of buttons in a card or page header that still moves focus with the arrows.

### Data attributes

::data-slots
---
rows:
  - slot: toolbar
    attributes: data-variant, aria-orientation
    description: "The root, a `role=\"toolbar\"`."
  - slot: toolbar-button
    attributes: data-variant, data-color, data-size, data-orientation
    description: A Button in the focus order.
  - slot: toolbar-link
    attributes: data-variant, data-color, data-size, data-orientation
    description: A link Button in the focus order.
  - slot: toolbar-separator
    attributes: data-orientation
    description: The line, carrying the toolbar's orientation.
  - slot: toolbar-toggle-group
    attributes: data-orientation
    description: "A `role=\"group\"` of toggle items."
  - slot: toolbar-toggle-item
    attributes: data-state, data-variant, data-color, data-size, data-orientation
    description: A toggle item in the focus order.
---
::

### Keyboard

::keyboard-table
---
rows:
  - keys: Tab
    description: Moves focus into the toolbar, onto the last focused part, and out again.
  - keys: ArrowLeft / ArrowRight
    description: Moves focus between the parts of a horizontal toolbar, wrapping around.
  - keys: ArrowUp / ArrowDown
    description: Moves focus between the parts of a vertical toolbar, wrapping around.
  - keys: Home / End
    description: Moves focus to the first or last part.
  - keys: Space / Enter
    description: Activates the focused button, link or toggle.
---
::
