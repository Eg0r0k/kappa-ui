## Usage

```vue
<script setup lang="ts">
import { FolderOpen } from '@lucide/vue'

import { Button } from '@/components/ui/button'
import { Empty, EmptyContent, EmptyDescription, EmptyHeader, EmptyMedia, EmptyTitle } from '@/components/ui/empty'
</script>

<template>
  <Empty>
    <EmptyHeader>
      <EmptyMedia><FolderOpen /></EmptyMedia>
      <EmptyTitle>No projects yet</EmptyTitle>
      <EmptyDescription>Create a project to start tracking work.</EmptyDescription>
    </EmptyHeader>
    <EmptyContent>
      <Button>Create project</Button>
    </EmptyContent>
  </Empty>
</template>
```

`Empty` is a centred column. `EmptyHeader` groups the media, the title and the description and keeps them no wider than 24rem; `EmptyContent` does the same for the actions below. Anything else, such as a link, goes straight into `Empty`.

It draws no border and no background. The surface comes from what holds it: a [Card](/docs/components/card), the empty slot of a [DataTable](/docs/components/data-table), or the page itself. That keeps one empty state right in every place it appears, without variants that try to guess the container.

`size` runs from `xs` to `xl` and sets the padding and the gaps. A bare icon in `EmptyMedia` follows it too, from 24px to 56px, through `--empty-icon` on the root. The title and description keep `text-title-md` and `text-body-md`, so a `text-*` class of your own on them wins. `md` by default.

`EmptyTitle` is an `h3`. Set `as` to the level that fits the page, `h2` on an empty page and `h4` inside a card that already has a heading.

## Examples

### In a card

The card draws the border and the radius; the empty state only fills it.

### In a table

A [DataTable](/docs/components/data-table) with no rows renders its `empty` slot in a centred cell that already pads and mutes its content, so this one drops its own padding and restores the text colour with `class`.

::component-preview{name="empty-table"}
::

### Avatars

`EmptyMedia` takes anything, here an [AvatarGroup](/docs/components/avatar). Only a bare `svg` is sized by the root; other content keeps its own size.

## API Reference

Every part accepts `class`, merged over its base classes.

::api-reference{parts="Empty,EmptyHeader,EmptyMedia,EmptyTitle,EmptyDescription,EmptyContent"}
::

### Data attributes

::data-slots
---
rows:
  - slot: empty
    attributes: data-size
    description: The root. The parts read `data-size` through the `group/empty` class.
  - slot: empty-header
    description: The media, title and description.
  - slot: empty-media
    description: The icon, avatar or image.
  - slot: empty-title
    description: "The heading, an `h3` unless `as` says otherwise."
  - slot: empty-description
    description: The muted paragraph.
  - slot: empty-content
    description: The actions.
---
::
