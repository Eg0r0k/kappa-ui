## Usage

```vue
<script setup lang="ts">
import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from '@/components/ui/table'
</script>

<template>
  <Table>
    <TableHeader>
      <TableRow>
        <TableHead>Name</TableHead>
        <TableHead align="end">Amount</TableHead>
      </TableRow>
    </TableHeader>
    <TableBody>
      <TableRow v-for="row in rows" :key="row.id">
        <TableCell>{{ row.name }}</TableCell>
        <TableCell align="end">{{ row.amount }}</TableCell>
      </TableRow>
    </TableBody>
  </Table>
</template>
```

The parts are shadcn-vue's, with two differences underneath. Borders sit on the cells, not the rows, under `border-collapse: separate`, so a sticky header and a pinned cell carry their own lines. Row state never paints the row: hover, `selected` and stripes set `--table-row-bg` on the row and every cell paints it, so a pinned cell can stay opaque and still follow the row. The tints are `--table-hover-bg`, `--table-selected-bg` and `--table-stripe-bg` on the table, for a theme to retune.

`Table` wraps the table in a container that scrolls sideways, as shadcn does. A sticky header cannot stick to that container, which never scrolls vertically; give the table `overflow="visible"` and put it where the scrolling happens: in a [scroll area](/docs/components/scroll-area) or on the page.

## Examples

### Sticky header and footer

`sticky` on `TableHeader` and `TableFooter`, with `overflow="visible"` on the table so the scroll area's viewport is the only scroller between them.

::component-preview{name="table-sticky"}
::

### Pinned columns

`pinned="start"` or `"end"` on a head and its cells keeps the column in view while the rest scrolls sideways. The first pinned column needs nothing more; a second one sets `--pin-start` (or `--pin-end`) to the width of the first, in `style` or a class. `pinnedEdge` on the outermost pinned column draws the shadow, which shows only inside a scroll area and only while there is content under it. Right-to-left mirrors everything.

::component-preview{name="table-pinned"}
::

### Density and stripes

`density` sets the row height through `--table-row-h`; `striped` tints every even body row.

::component-preview{name="table-density"}
::

### Selection and clickable rows

`selected` tints a row and `clickable` makes it a target with `tabindex="0"`. The row keeps no role, so screen readers still read it as a row; handle the click and the Enter and Space keys yourself, and stop the click on controls inside the row.

::component-preview{name="table-selection"}
::

### Empty

`TableEmpty` spans the row with `colspan` and centres its content.

::component-preview{name="table-empty"}
::

## Accessibility

Every `TableHead` renders `scope="col"`. `TableCaption` is read by assistive technology and hidden from sight unless `visible`; a table with a purpose that is not obvious from its surroundings should have one. A `clickable` row is focusable and a pointer target but has no role, since `role="button"` on a row hides it from some screen readers; give the same action to a control inside the row for keyboard and screen reader users.
