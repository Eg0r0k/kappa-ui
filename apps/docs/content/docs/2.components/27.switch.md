## Usage

```vue
<script setup lang="ts">
import { Field, FieldLabel } from '@/ui/field'
import { Switch } from '@/ui/switch'

const airplane = ref(false)
</script>

<template>
  <Field orientation="horizontal">
    <Switch v-model="airplane" />
    <FieldLabel>Airplane mode</FieldLabel>
  </Field>
</template>
```

`Switch` is Reka UI's switch with Material's look and motion: a `<button role="switch">` whose handle grows as it turns on, slides across with a slight overshoot, and swells a little while pressed. Behind the handle sits the same circular state layer as on a [checkbox](/docs/components/checkbox): it follows the mouse over the track itself and any press, including one on the label. Inside a [Field](/docs/components/field) it takes its `id`, description, error and state from it.

Use a switch for a setting that applies the moment it changes. For a choice that waits for a Save button, a checkbox says that better.

## Examples

### Sizes

`size` runs from `xs`, 16px tall, to `xl`, 32px, in steps of 4px. `md`, the default, is 24px by 39px, between shadcn's switch and Material's; `xl` is Material's 52px by 32px. The width, handle, icons and state layer all scale with the height.

::component-preview{name="switch-sizes"}
::

### Icons

Put an icon in the `checked-icon` slot, the `unchecked-icon` slot or both. An icon only for the on state rotates into view as the switch turns on. Giving an icon for the off state keeps the handle at its larger size in both states, so the icon fits, as Material does. Icons are sized to half the track's height, so they read best from `lg` up, and are hidden from screen readers, since the switch already announces its state.

::component-preview{name="switch-icons"}
::

### Description

For a settings row, put the label and description first and the switch after them; the label grows to push the switch to the end of the row.

Only `xl` is as wide as 48px, and none is that tall. `touch-target` works as on the [button](/docs/components/button): `expand` grows the pressable area to 48px without moving anything, and `wrapper` also reserves the space with a margin. Both areas are outlined below.
