## Usage

```vue
<script setup lang="ts">
import { Slider } from '@/ui/slider'

const volume = ref(50)
</script>

<template>
  <Slider v-model="volume" aria-label="Volume" />
</template>
```

`Slider` is Reka UI's slider with kappa-ui's styles. Each thumb is an element with `role="slider"` that takes focus, and the arrow keys move it by `step`, Page Up and Page Down by ten steps, and Home and End to the ends. Pressing anywhere on the track moves the nearest thumb there.

The thumb borrows the [switch](/docs/components/switch)'s handle: a solid circle with a state layer behind it that shows while the mouse is over the thumb, deepens while it is dragged, and grows the thumb a little until it is let go.

Unlike Reka UI, `v-model` takes a plain number for a single thumb. Pass an array to get one thumb per item.

Inside a [Field](/docs/components/field) the slider is named by the field's label and described by its description and error. Without a field, give it `aria-label`.

## Examples

### Min, max and step

The value runs from `min` to `max`, 0 to 100 by default, in steps of `step`. When the number alone does not say what it means, set `aria-valuetext`, which screen readers read instead.

::component-preview{name="slider-min-max"}
::

### Multiple

An array value gives one thumb per item, here a price range. Screen readers call two thumbs "Minimum" and "Maximum", and more "Value 1 of 3" and so on; the label names them as a group.

::component-preview{name="slider-multiple"}
::

### Min steps between thumbs

`min-steps-between-thumbs` keeps neighbouring thumbs that many steps apart. Without it, thumbs can meet and pass each other.

::component-preview{name="slider-min-steps"}
::

### Orientation

`orientation="vertical"` runs the slider from bottom to top. It fills the height of its container and is at least 176px tall.

::component-preview{name="slider-orientation"}
::

### Sizes

`size` sets the handle, from 12px for `xs` to 24px for `xl`, and the track thickness with it, from 4px to 10px. `md`, the default, is a 16px thumb on a 6px track.

::component-preview{name="slider-sizes"}
::

### Inset

`variant="inset"` puts the thumb inside a thick track, adapted from HeroUI's slider with a round handle. The track is 4px thicker than the handle, from 16px at `xs` to 28px at `xl`. The thumb is a disc in the fill's colour, so the fill ends in a half circle around the handle, and the handle shrinks a little while it is dragged. There is no state layer; the focus ring shows keyboard focus. An invalid slider turns its fill and thumbs `--destructive`, like the default one. The fill always ends under the centre of the handle, because the track leaves half a thumb at each end for the thumbs to stay inside. That relies on the default `thumb-alignment="contain"`; with `overflow` the fill and the handle drift apart towards the ends.

::component-preview{name="slider-inset"}
::

### Inverted

`inverted` runs the slider from the other end: right to left, or top to bottom. The keys follow, so the right arrow still moves the thumb right. In a right-to-left page a horizontal slider already runs right to left.

::component-preview{name="slider-inverted"}
::

### States

A disabled slider turns grey and ignores the pointer and the keyboard. An invalid one turns its range and thumbs `--destructive` and sets `aria-invalid` on each thumb.

::component-preview{name="slider-states"}
::

### Touch target

No size is 48px tall. `touch-target` works as on the [switch](/docs/components/switch): `expand` makes the track pressable 48px high and gives each thumb a 48px area, without moving anything, and `wrapper` also reserves that height with a margin. Pressing a thumb's area picks the thumb up where it is; pressing the track elsewhere moves the nearest thumb to the finger. The track's area is outlined in pink below, the thumbs' in blue.

::component-preview{name="slider-touch-target"}
::

### Data attributes

::data-slots
---
rows:
  - slot: slider
    attributes: data-orientation, data-disabled, data-touch-target, data-variant
    description: The root, and the pressable area of the track.
  - slot: slider-track
    attributes: data-orientation, data-disabled
    description: The full length of the track.
  - slot: slider-range
    attributes: data-orientation, data-disabled
    description: The filled part of the track.
  - slot: slider-thumb
    attributes: data-orientation, data-disabled, data-hovered
    description: One thumb, with `role="slider"`. Draws the state layer, or, with `inset`, the disc around the handle.
  - slot: slider-handle
    description: The circle inside a thumb.
---
::
