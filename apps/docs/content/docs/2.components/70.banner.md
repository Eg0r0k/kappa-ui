## Usage

```vue
<script setup lang="ts">
import { Banner, BannerActions, BannerClose, BannerSubtitle, BannerTitle } from '@/components/ui/banner'
</script>

<template>
  <Banner>
    <MegaphoneIcon />
    <BannerTitle>kappa-ui 0.15</BannerTitle>
    <BannerSubtitle>Tour, Banner and Marker are in.</BannerSubtitle>
    <BannerActions>
      <Button size="xs" color="neutral">Read more</Button>
    </BannerActions>
    <BannerClose />
  </Banner>
</template>
```

A banner spans the page above everything else, for news, maintenance or a problem with the account. Its parts sit in one centred row and wrap on narrow screens; an icon goes in as a direct `svg` child. Nuxt UI's Banner, taken apart into parts.

`BannerClose` sets `open` to `false`, and the banner leaves the DOM. Bind `v-model:open` to react to it or bring the banner back. A close button keeps the content centred: the banner pads both sides by the button's width.

## Examples

### Colours

`color` picks the colour role of the fill, `primary` by default. `neutral` inverts the page's colours. Any name declared on `[data-slot][data-color]` works too.

::component-preview{name="banner-colors"}
::

### Remembering the choice

The banner keeps no state of its own beyond `open`, so remembering a dismissal is a matter of where you store it. `useLocalStorage` from VueUse keeps it in the browser; with `initOnMounted: true` it reads the storage after hydration, so a server-rendered page does not mismatch, though the banner shows for a moment before it hides. In Nuxt, `useCookie` reaches the server, which then never renders a dismissed banner at all.

::component-preview{name="banner-persistent"}
::

```ts
const open = useCookie('banner-maintenance', { default: () => true })
```

## Accessibility

The banner has no role, since most banners are there from the start and need no announcement. For one that appears while the page is open, add `role="status"`, or `role="alert"` when it is urgent. `BannerClose` is labelled "Close"; pass your own `aria-label` to translate it.
