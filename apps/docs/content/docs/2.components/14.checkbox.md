## Usage

```vue
<script setup lang="ts">
import { Checkbox } from '@/components/ui/checkbox'
import { Field, FieldLabel } from '@/components/ui/field'

const accepted = ref(false)
</script>

<template>
  <Field orientation="horizontal">
    <Checkbox v-model="accepted" />
    <FieldLabel>Accept terms and conditions</FieldLabel>
  </Field>
</template>
```

Set `name`, and it submits with the form. Inside a [Field](/docs/components/field), clicking the label toggles it. On its own, give it an `aria-label` or a [Label](/docs/components/label).

When checked, the box fills with its colour, `--primary` by default, and the check draws itself in. Hover or press it, and a soft circle shows up behind the box.

## Examples

### States

`v-model` is `true`, `false` or `'indeterminate'`. The last one is the "it's complicated" state: a "select all" checkbox when only some items are checked. Click it, and it becomes checked.

::component-preview{name="checkbox-states"}
::

### Colours

`color` takes Button's colours, `primary` by default, or [one of your own](/docs/getting-started/theming#your-own-tone). It colours the fill, the edge and the circle behind a checked box. An unchecked box keeps the `--input` edge, so a column of empty boxes looks the same whatever their colour. An invalid checkbox still turns red, whatever its colour, so an error always looks like one.

A `CheckboxGroup` passes its `color` to every checkbox in it. A checkbox with a `color` of its own keeps it.

::component-preview{name="checkbox-colors"}
::

### Sizes

`size` runs from `xs`, 14px, to `xl`, 24px. `md`, the default, is Material's 18px. The circular state layer grows with the box.

::component-preview{name="checkbox-sizes"}
::

### Touch target

Smaller than a finger? Add `touch-target`: `expand` when it stands alone, `wrapper` when it sits close to others. [How it works](/docs/getting-started/accessibility#touch-targets).

With `wrapper`, the label moves along with the box.

::component-preview{name="checkbox-touch-target"}
::

### Description

Put the label and its description in a `FieldContent`. The checkbox lines up with the first line of the label, and the description is added to the checkbox's `aria-describedby`.

### Group

`CheckboxGroup` collects the checked values into one array.

Wrap it in a [FieldSet](/docs/components/field) with a legend to name it. For a group-wide error like "pick at least one", set `invalid` on the fieldset, and every checkbox turns red.

::component-preview{name="checkbox-group"}
::

Each checkbox is its own Tab stop, as everywhere else. Want one Tab stop and arrow keys instead? Turn on `roving-focus`.

`variant` and `orientation` lay the options out as cards, a list or a table, in a column or a row. See [Choice Group](/docs/components/choice-group).

  - slot: checkbox
    attributes: data-state, data-color, data-size, data-disabled, data-touch-target
