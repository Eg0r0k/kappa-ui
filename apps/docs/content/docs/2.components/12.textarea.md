## Usage

```vue
<script setup lang="ts">
import { Textarea } from '@/components/ui/textarea'

const message = ref('')
</script>

<template>
  <Textarea v-model="message" placeholder="Type your message here." />
</template>
```

Every attribute goes to the `<textarea>` itself, so `name`, `maxlength`, `placeholder` and the native validation attributes work as they do in HTML. Inside a [Field](/docs/components/field) it takes its `id`, description, error and state from it, as the [input](/docs/components/input) does, and it turns invalid the same two ways: through `aria-invalid`, or through the browser's own validation after the user has interacted with it.

## Examples

### Variants

The same five variants as the input: `outline`, `soft`, `filled`, `ghost` and `subtle`.

::component-preview{name="textarea-variants"}
::

### Sizes

The sizes set the padding and text size of the input sizes of the same name, so a one-row textarea is as tall as the input next to it.

::component-preview{name="textarea-sizes"}
::

### Rows

`rows` sets the height in lines of text. It defaults to 3, one more than the browser's own, so an empty textarea reads as a place for more than a line. The user can still drag the corner to make it taller.

::component-preview{name="textarea-rows"}
::

### Autoresize

With `autoresize` the textarea grows to fit its text instead of scrolling, and the drag handle goes away. `rows` becomes the height it never shrinks below, and `maxrows` the height at which it stops growing and scrolls instead. It measures itself when the value changes; if its width changes on its own, call the exposed `resize()`.

::component-preview{name="textarea-autoresize"}
::

### In a scroll area

Don't like the browser's scrollbar? Turn on `autoresize` and wrap the textarea in a fixed-height [ScrollArea](/docs/components/scroll-area).

Then move the border: take it off the textarea and put it on the scroll area, using `has-focus-visible:` and `has-aria-invalid:` for the focus and error states.

Stretch the scroll area's content, as in the example below, so a click anywhere inside the frame starts typing.
