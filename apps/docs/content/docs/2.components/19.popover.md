## Usage

```vue
<script setup lang="ts">
import { Button } from '@/ui/button'
import { Popover, PopoverContent, PopoverTrigger } from '@/ui/popover'
</script>

<template>
  <Popover>
    <PopoverTrigger as-child>
      <Button variant="outline" color="neutral">Open</Button>
    </PopoverTrigger>
    <PopoverContent>Place content for the popover here.</PopoverContent>
  </Popover>
</template>
```

`Popover` is Reka UI's popover with kappa-ui's styles: a panel with any content, opened and closed by its trigger. Escape or an outside click closes it, and focus returns to the trigger. By default it opens centred below the trigger and moves to stay on screen.

`PopoverAnchor` positions the panel against another element than the trigger, such as the input a trigger button sits in.

## Examples

### Modal

A popover is not modal by default: the page stays live, and an outside click closes the popover and also reaches what it lands on. With `modal`, the page is [shut](/docs/getting-started/overlays) while it is open: focus stays inside, the page does not scroll, and an outside click only closes the popover.
