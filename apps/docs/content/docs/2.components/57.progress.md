## Usage

```vue
<script setup lang="ts">
import { Progress } from '@/components/ui/progress'

const value = ref(40)
</script>

<template>
  <Progress v-model="value" />
</template>
```

The API is Nuxt UI's Progress, without `ui`: the parts are styled through their `data-slot`.

## Examples

### Indeterminate

Without a value, or with `null`, the bar is indeterminate and animated. `animation` picks the movement: `carousel` (the default), `carousel-inverse`, `swing` or `elastic`. The carousels run the other way in a right-to-left document, and every animation becomes a slow pulse under reduced motion.

::component-preview{name="progress-animations"}
::

### Status

`status` shows the percentage above the bar, where the fill ends. Replace it through the `status` slot, which receives `percent`.

::component-preview{name="progress-status"}
::

### Steps

An array as `max` gives the bar one step per item: the value is the index of the current step, and its name shows under the bar. Replace a step's name through its `step-<index>` slot, which receives `step`.

::component-preview{name="progress-steps"}
::

### Sizes

`2xs` to `2xl` set the thickness from 1 to 20px, and the size of the status and step text. `md` is the default.

::component-preview{name="progress-sizes"}
::

### Orientation

`orientation="vertical"` fills the height of the container from the top; `inverted` fills either orientation from the other end.

::component-preview{name="progress-vertical"}
::

### Colours

`color` takes Button's colours or [your own](/docs/getting-started/theming#your-own-tone), `primary` by default. The bar, its track at 20% and the step names are drawn in the colour's [text shade](/docs/getting-started/theming#tones), which stays readable on the page where a bright `success` or `warning` wouldn't.

All three follow the root's text colour, so a class such as `class="text-foreground"` still recolours them.

::component-preview{name="progress-colors"}
::

### Label and value

`ProgressLabel` and `ProgressValue` go in the default slot and sit in a row above the bar. The label names the bar for screen readers. The value shows the percentage and is hidden from screen readers, since the bar already reports its value; its slot receives `percent`, `value` and `max`.

::component-preview{name="progress-label"}
::

### Data attributes

::data-slots
---
rows:
  - slot: progress
    attributes: data-color, data-orientation, data-size
    description: The root.
  - slot: progress-header
    description: The row around the default slot, rendered only when it is used.
  - slot: progress-status
    description: The percentage shown by `status`.
  - slot: progress-track
    attributes: data-state, data-value, data-max
    description: The track, with `role="progressbar"`. `data-state` is `indeterminate`, `loading` or `complete`.
  - slot: progress-indicator
    attributes: data-state
    description: The fill.
  - slot: progress-steps
    description: The step names under the bar.
  - slot: progress-step
    attributes: data-state
    description: One step name. `data-state` is `active` or `first` for the current step, `other` for the rest.
  - slot: progress-label
    description: The label.
  - slot: progress-value
    description: The percentage beside the label.
---
::
