## Usage

```vue
<script setup lang="ts">
import { Skeleton } from '@/ui/skeleton'
</script>

<template>
  <Skeleton class="h-4 w-48" />
</template>
```

As in shadcn, a skeleton is a block in `--accent` with rounded corners that pulses, and you give it its size with classes. It is hidden from screen readers, since it has nothing to say; mark the region that is loading with `aria-busy="true"` instead, and drop it when the content arrives.

## Examples

### Animations

`animation` is `pulse` by default, the same fade in and out as shadcn's. `wave` sweeps a band of light across the block, from the start edge to the end edge, so it runs the other way in right-to-left layouts. `none` keeps it still. With reduced motion, `pulse` and `wave` stand still too.

::component-preview{name="skeleton-animations"}
::

### Text

`variant="text"` stands in for a line of text. It is as tall as the font and sits in the line the way the text would, so give it the text's typescale class and the layout does not move when the text replaces it. `variant="circle"` is round and square, for avatars: set only its width, or a `size-*`.

::component-preview{name="skeleton-text"}
::
