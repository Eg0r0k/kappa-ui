## Usage

```vue
<script setup lang="ts">
import { Button } from '@/ui/button'
import {
  Dialog,
  DialogBody,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from '@/ui/dialog'
</script>

<template>
  <Dialog>
    <DialogTrigger as-child>
      <Button>Edit profile</Button>
    </DialogTrigger>
    <DialogContent>
      <DialogHeader>
        <DialogTitle>Edit profile</DialogTitle>
        <DialogDescription>Changes are saved when you press Save.</DialogDescription>
      </DialogHeader>
      <DialogBody>
        <!-- the content -->
      </DialogBody>
      <DialogFooter>
        <DialogClose as-child>
          <Button>Save</Button>
        </DialogClose>
      </DialogFooter>
    </DialogContent>
  </Dialog>
</template>
```

`Dialog` holds the state, `DialogTrigger` opens it, and `DialogContent` is the window. It renders the overlay, centres the window on the screen, and puts a close button in its top corner. Inside the window, `DialogHeader`, `DialogBody` and `DialogFooter` lay out the three parts. `DialogClose` around any button makes it close the dialog. `v-model:open` on `Dialog` opens it from code.

Underneath is Reka UI's dialog. Focus moves into the window and stays there. Escape or a press outside closes it, and focus returns to the trigger. The page behind is [shut](/docs/getting-started/overlays). The close button comes last in the window, so a form's first field takes focus when the dialog opens.

The window is as tall as its content, up to the height of the screen less 1rem on each side. Past that the body scrolls while the header and footer stay put. The body is a plain element with `overflow-y: auto`, so the dialog needs no scroll area.

## Examples

### Long content

Once the window reaches the edge of the screen, the body scrolls between the header and the footer.

::component-preview{name="dialog-body-scroll"}
::

### Scroll area

For delta-ui's [scroll area](/docs/components/scroll-area) instead of the native scrollbar, give the window a height and let the scroll area take the rest with `min-h-0 flex-1`. A scroll area has no height of its own, so the window's height must not depend on it.

::component-preview{name="dialog-scroll-area"}
::

### Scrolling overlay

With `DialogScrollContent` in place of `DialogContent`, the window keeps its full height and the overlay scrolls instead, like a page. Use it for long reading, where a fixed header and footer would take too much room. It needs `modal`, which is on by default: without it there is no overlay to scroll.

::component-preview{name="dialog-scroll-overlay"}
::

### Fullscreen

The window's position and size are classes, so `class` can make it fill the screen: `inset-0 size-full max-h-none max-w-none translate-none rounded-none border-0`. The classes they replace are merged away.

::component-preview{name="dialog-fullscreen"}
::

### Not dismissible

`DialogContent` passes on Reka UI's events. Prevent `escape-key-down` and `interact-outside`, and only a button in the window closes it. `:show-close-button="false"` removes the close button.

::component-preview{name="dialog-dismissible"}
::

### Nested

A dialog can open another from inside it. The new one stacks on top with its own overlay, and Escape and outside presses close only the top one. When it closes, focus returns to the first dialog. Below, the inner dialog confirms a change with a `DialogClose` button, and the first dialog stays open and shows the result.

::component-preview{name="dialog-nested"}
::

### Custom layout

The parts are plain elements with classes, so any of them can be restyled or left out. This confirmation centres its header and drops the close button.

::component-preview{name="dialog-custom"}
::

### Opened from code

Without a trigger, bind `v-model:open` and open the dialog from anywhere. Here it opens from a [menu](/docs/components/menu) item.

## Accessibility

The dialog's name comes from its `DialogTitle` and its description from its `DialogDescription`. Always give it a title: without one, screen readers announce an unnamed dialog. To name a dialog without showing the title, wrap the title in `VisuallyHidden` from `@delta-ui/core/visually-hidden`. The description is optional. When either is missing, the window renders an empty hidden one in its place, so Reka UI does not warn in the console.

::keyboard-table
---
rows:
  - keys: Tab / Shift + Tab
    description: Moves to the next or previous control in the window, wrapping around inside it.
  - keys: Escape
    description: Closes the dialog and returns focus to the trigger.
---
::
