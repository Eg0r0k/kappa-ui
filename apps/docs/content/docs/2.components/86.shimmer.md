## Installation

`shimmer` comes with `@kappa-ui/core/tailwind.css`, which the `tokens` item imports; there is no separate item.

## Usage

```vue
<p class="shimmer text-muted-foreground">Generating response…</p>
```

The text is painted through a gradient with `background-clip: text`, and the highlight sweeps across it in a loop. The highlight comes from the text's own colour, so it works on `text-muted-foreground` and on brand colours alike, and it brightens in dark mode to stay visible. Ported from shadcn-vue's utility of the same name.

| Class | Effect |
|---|---|
| `shimmer` | The sweep, two seconds per pass, looping. |
| `shimmer-once` | One pass instead of a loop. |
| `shimmer-reverse` | Sweeps the other way. |
| `shimmer-none` | Plain text again, in any class order. |
| `shimmer-color-<color>` | The highlight colour: a theme colour, with an optional `/<opacity>`, or `[<value>]`. |
| `shimmer-duration-<ms>` | One pass in milliseconds. |
| `shimmer-spread-<n>` | The band's width on the spacing scale, or `[<length>]`. `calc(3ch + 40px)` by default. |
| `shimmer-angle-<deg>` | The band's tilt in degrees. `20` by default. |

## Motion and direction

With reduced motion the text renders plainly. In right-to-left text the sweep follows the reading direction; `shimmer-reverse` flips it by hand.

The highlight uses relative colour syntax and `color-mix()`. A browser without them drops the gradient and can leave the text transparent; to support one, apply the class behind `supports-[color:oklch(from_white_l_c_h)]:shimmer`.

::css-vars
---
rows:
  - name: --shimmer-color
    default: the text colour at 20% alpha
    description: The highlight colour.
  - name: --shimmer-duration
    default: 2s
    description: One pass.
  - name: --shimmer-spread
    default: calc(3ch + 40px)
    description: The band's half width.
  - name: --shimmer-angle
    default: 20deg
    description: The band's tilt.
---
::
