## Usage

```vue
<script setup lang="ts">
import { Field, FieldLabel } from '@/components/ui/field'
import { Switch } from '@/components/ui/switch'

const airplane = ref(false)
</script>

<template>
  <Field orientation="horizontal">
    <Switch v-model="airplane" />
    <FieldLabel>Airplane mode</FieldLabel>
  </Field>
</template>
```

Use a switch when the change applies right away. If it waits for a Save button, use a [Checkbox](/docs/components/checkbox) instead.

Turn it on, and the handle grows and slides across with a little bounce. Press it, and the handle swells. Hover and press get the same soft circle as Checkbox.

Inside a [Field](/docs/components/field), it works as usual.

## Examples

### Sizes

`size` runs from `xs`, 16px tall, to `xl`, 32px, in steps of 4px. `md`, the default, is 24px by 39px, between shadcn's switch and Material's; `xl` is Material's 52px by 32px. The width, handle, icons and state layer all scale with the height.

::component-preview{name="switch-sizes"}
::

### Icons

Use the `checked-icon` and `unchecked-icon` slots, or just one of them. The "on" icon spins in as the switch turns on. Add an "off" icon, and the handle stays big in both states to fit it.

Icons look best from `lg` up.

::component-preview{name="switch-icons"}
::

### Description

For a settings row, put the label and description first and the switch after them; the label grows to push the switch to the end of the row.

### Touch target

Smaller than a finger? Add `touch-target`: `expand` when it stands alone, `wrapper` when it sits close to others. [How it works](/docs/getting-started/accessibility#touch-targets).

With `wrapper`, the label moves along with the switch.
