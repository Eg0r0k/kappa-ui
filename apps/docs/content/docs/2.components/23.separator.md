## Usage

```vue
<script setup lang="ts">
import { Separator } from '@/ui/separator'
</script>

<template>
  <Separator />
  <Separator orientation="vertical" />
  <Separator label="or" />
</template>
```

`Separator` is Reka UI's separator with kappa-ui's styles. It is a `--border` line across the full width, or with `orientation="vertical"` the full height of its parent, so a vertical one sits in a row with a set height, such as `h-5` or a stretching flex item.

As in shadcn, the separator is decorative by default: it gets `role="none"` and screen readers skip it. When it divides content that a reader should know is divided, set `:decorative="false"`; it then gets `role="separator"` and, when vertical, `aria-orientation`.

## Examples

### Label

`label`, or the default slot for richer content, puts text in the middle of the line. A vertical separator keeps the text upright between its two halves.

::component-preview{name="separator-label"}

### Sizes

`size` sets the thickness, from 1px for `xs`, the default, to 5px for `xl`.

### CSS variables

::css-vars
---
rows:
  - name: --separator-size
    default: 1px
    description: The line's thickness, set by `size`. Set it in `class`, as in `[--separator-size:0.5px]`, for a thickness outside the scale.
---
::

### Data attributes

::data-slots
---
rows:
  - slot: separator
    attributes: data-orientation
    description: The separator. Without a label it is the line itself.
  - slot: separator-line
    description: One of the two lines on either side of a label.
  - slot: separator-label
    description: The label between the lines.
---
::
