## Usage

```vue
<script setup lang="ts">
import { Kbd, KbdGroup } from '@/ui/kbd'
</script>

<template>
  <KbdGroup>
    <Kbd>Ctrl</Kbd>
    <Kbd>B</Kbd>
  </KbdGroup>
</template>
```

`Kbd` is one key and `KbdGroup` holds the keys of one shortcut. Put separators such as `+` or `then` between the keys yourself; the group only spaces them. Both render `<kbd>`, which is how HTML marks up keyboard input, including a combination nested inside another `<kbd>`.

## Examples

### In a button

::component-preview{name="kbd-button"}
::

Inside a [button](/docs/components/button) a key takes its colour from the button: a translucent layer of the label colour and the label colour itself, so it fits every variant and colour without a class of its own.

The key's text is part of the button's name, so a screen reader would announce "Save Ctrl S". Hide the key and state the shortcut on the button instead, which is where assistive technology looks for it:

```vue
<template>
  <Button aria-keyshortcuts="Control+S">
    Save
    <KbdGroup aria-hidden="true">
      <Kbd>Ctrl</Kbd>
      <Kbd>S</Kbd>
    </KbdGroup>
  </Button>
</template>
```

`aria-keyshortcuts` only describes the shortcut. Listening for the keys is up to your app.

## API Reference

Both parts accept `class`, merged over their base classes. Text is `label-md` from the [typescale](/docs/getting-started/typography); an icon inside a key is sized to 12px unless it has a size class.
