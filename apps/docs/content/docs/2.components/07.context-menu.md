## Usage

```vue
<script setup lang="ts">
import { ContextMenu, ContextMenuContent, ContextMenuItem, ContextMenuTrigger } from '@/ui/context-menu'
</script>

<template>
  <ContextMenu>
    <ContextMenuTrigger class="block">
      Right-click here
    </ContextMenuTrigger>
    <ContextMenuContent>
      <ContextMenuItem @select="copy">Copy</ContextMenuItem>
      <ContextMenuItem @select="paste">Paste</ContextMenuItem>
    </ContextMenuContent>
  </ContextMenu>
</template>
```

`ContextMenu` is Reka UI's context menu with delta-ui's styles. It opens at the pointer on right-click, and on a touch screen after a long press. It has the same parts, keyboard behaviour and look as the [dropdown menu](/docs/components/dropdown-menu): items, checkbox and radio items, labels, separators, shortcuts and submenus.

The menu is [modal](/docs/getting-started/overlays) by default: while it is open, an outside click only closes it, and a right-click elsewhere closes it without opening the browser's own menu. Set `:modal="false"` on `ContextMenu` to let the page stay live.

## Examples

### Sizes

`size` on `ContextMenuContent` runs from `xs` to `xl`. Items are 28, 32, 36, 40 and 48px tall, as tall as an [input](/docs/components/input) of the same size, and the text, icons and padding grow with them: 12px text for `xs` and `sm`, 14px for `md`, the default, and 16px for `lg` and `xl`, with icons from 14 to 20px. A submenu takes the size of the menu it opens from; give its content its own `size` to change it.

::component-preview{name="context-menu-sizes"}
::

### Open state

While the menu is open, `ContextMenuTrigger` carries `data-state="open"`, and `data-state="closed"` otherwise, so the area that was right-clicked can stay highlighted with `data-[state=open]:`.

::component-preview{name="context-menu-open-state"}
::

### Non-modal

With `:modal="false"` there is no scrim and no scroll lock: the list and the page keep scrolling while the menu is open, and a right-click on another row moves the menu there.

::component-preview{name="context-menu-non-modal"}
::

### Data attributes

::data-slots
---
rows:
  - slot: context-menu-trigger
    attributes: data-state, data-disabled
    description: The area that opens the menu. `data-state` is `open` while the menu is open, `closed` otherwise.
  - slot: context-menu-content
    attributes: data-state, data-side, data-align, data-size
    description: The menu's panel. `data-size` is its size, `xs` to `xl`.
  - slot: context-menu-scrim
    description: The transparent layer under a modal menu that takes the first outside click.
  - slot: context-menu-item
    attributes: data-highlighted, data-disabled, data-inset, data-variant
    description: An item.
  - slot: context-menu-sub-content
    attributes: data-state, data-side, data-size
    description: A submenu's panel.
---
