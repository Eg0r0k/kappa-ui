Open **Props** in the corner of the example to try `color` and `size`. `color` fills the reached indicators and lines, in Button's colours or [your own](/docs/getting-started/theming#your-own-tone); `color` on one `TimelineIndicator` retones that record alone: a failed deploy in a green log.

`size` is the density of a record, from `xs` (24px indicator) to `xl` (48px): the indicator, its icon, the gaps, the line and the space between records follow it. The title and description keep their text size.

## Usage

```vue
<script setup lang="ts">
import {
  Timeline,
  TimelineContent,
  TimelineDate,
  TimelineDescription,
  TimelineIndicator,
  TimelineItem,
  TimelineSeparator,
  TimelineTitle,
} from '@/components/ui/timeline'
</script>

<template>
  <Timeline default-value="design">
    <TimelineItem value="kickoff">
      <TimelineIndicator><Rocket /></TimelineIndicator>
      <TimelineSeparator />
      <TimelineContent>
        <TimelineDate datetime="2026-03-15">Mar 15, 2026</TimelineDate>
        <TimelineTitle>Project kickoff</TimelineTitle>
        <TimelineDescription>Aligned the team and set the milestones.</TimelineDescription>
      </TimelineContent>
    </TimelineItem>
    <TimelineItem value="design">…</TimelineItem>
  </Timeline>
</template>
```

A timeline is a record, not a control. Unlike a [Stepper](/docs/components/stepper) it has no triggers, no keyboard navigation and no linear rule: the model only says which record is current, and the parts draw a trail up to it.

- `Timeline`: an `ol`; holds the current `value` through `v-model` or `default-value`
- `TimelineItem`: an `li` with a `value`; carries `data-state` and `aria-current="step"` when current
- `TimelineIndicator`: the circle, with an icon, a number, an [Avatar](/docs/components/avatar) or nothing
- `TimelineSeparator`: the line to the next record; hidden on the last one
- `TimelineContent`: the text column; `TimelineDate` (a `time`), `TimelineTitle` and `TimelineDescription` go inside

Each `TimelineItem` must be a direct child of `Timeline`: the root keeps them in document order and hides the last line.

With a model, the current record is `active`, the ones before it `completed` and the rest `inactive`; the state lands as `data-state` on the item, and the indicator and the line colour themselves from it. Without a model there is no state: every indicator is in colour and every line is muted, the look of a log where everything has happened. A record without a `value` matches the model by its index, and a model that matches no record counts as past the last one, so every record is completed. The state is computed from the order of the records as they mount, so it is in the server-rendered HTML and nothing flips on hydration.

## Examples

### Horizontal

`orientation="horizontal"` lays the records out in a row with the content under each indicator. Give the timeline a minimum width and let its container scroll.

::component-preview{name="timeline-horizontal"}
::

### Newest first

With `reverse` the records after the current one count as completed, for a list that runs from the latest release down. The line after the current record is coloured too, since it leads to completed ones.

::component-preview{name="timeline-reverse"}
::

### Alternating

Each item is a grid, so classes on the parts move the columns around: three columns, the indicator and the line in the middle, the content on alternating sides.

::component-preview{name="timeline-alternating"}
::

### Changelog

No model, rich content: a `Badge` in the title, the date beside it, paragraphs in the description with `as="div"`.

::component-preview{name="timeline-changelog"}
::

## API Reference

Every part takes a `class` that merges with its own.

::api-reference{parts="Timeline,TimelineItem,TimelineIndicator,TimelineSeparator,TimelineContent,TimelineDate,TimelineTitle,TimelineDescription"}
::

### Data attributes

::data-slots
---
rows:
  - slot: timeline
    attributes: data-orientation, data-reverse, data-color, data-size
    description: The root, an `ol`.
  - slot: timeline-item
    attributes: data-state, data-orientation, aria-current
    description: "One record; `data-state` is `active`, `completed` or `inactive`, absent without a model, and `aria-current=\"step\"` marks the current one."
  - slot: timeline-indicator
    attributes: data-color
    description: The circle; `data-color` only when the part has its own colour.
  - slot: timeline-separator
    attributes: data-orientation
    description: The line after a record, decorative, hidden on the last one.
  - slot: timeline-content
    attributes: data-orientation
    description: The text column.
  - slot: timeline-date
    description: A `time`.
  - slot: timeline-title
    description: The title.
  - slot: timeline-description
    description: The description.
---
::

### CSS variables

Set on the root by `size`; a class on a part wins over them.

::css-vars
---
rows:
  - name: --timeline-indicator
    default: --spacing(8)
    description: The indicator's box, 24px at `xs` to 48px at `xl`.
  - name: --timeline-icon
    default: --spacing(4)
    description: An icon in the indicator, 14px to 24px.
  - name: --timeline-text
    default: var(--typescale-label-lg-size)
    description: A number in the indicator.
  - name: --timeline-gap
    default: --spacing(2)
    description: The space between the indicator and the content, and between the indicator and the line.
  - name: --timeline-separator
    default: --spacing(0.5)
    description: The line's thickness, 1px to 4px.
  - name: --timeline-spacing
    default: --spacing(6)
    description: The space between records, 16px to 32px.
---
::
