## Usage

```vue
<script setup lang="ts">
import { Bold, Italic, Underline } from '@lucide/vue'

import { ToggleGroup, ToggleGroupItem } from '@/components/ui/toggle-group'

const formatting = ref<string[]>([])
</script>

<template>
  <ToggleGroup v-model="formatting" type="multiple" variant="outline" size="icon-md">
    <ToggleGroupItem value="bold" aria-label="Bold"><Bold /></ToggleGroupItem>
    <ToggleGroupItem value="italic" aria-label="Italic"><Italic /></ToggleGroupItem>
    <ToggleGroupItem value="underline" aria-label="Underline"><Underline /></ToggleGroupItem>
  </ToggleGroup>
</template>
```

`ToggleGroup` is Reka UI's toggle group laid out like a [Button Group](/docs/components/button-group): the items join, with the inner corners squared and outlined edges shared. Tab reaches the group once, and the arrow keys move between its items. Each item is a [Toggle](/docs/components/toggle) and takes its variants, colours and sizes.

## Examples

### Single

`type="single"` keeps at most one item on and binds its value as a string; `type="multiple"` binds an array.

::component-preview{name="toggle-group-single"}
::

### Style

`variant`, `activeVariant`, `color`, `activeColor` and `size` on the group apply to every item, and an item's own props override them.
