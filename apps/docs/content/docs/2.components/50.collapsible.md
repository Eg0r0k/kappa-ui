## Usage

```vue
<script setup lang="ts">
import { Button } from '@/components/ui/button'
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from '@/components/ui/collapsible'
</script>

<template>
  <Collapsible>
    <CollapsibleTrigger as-child>
      <Button variant="soft" color="neutral">Show details</Button>
    </CollapsibleTrigger>
    <CollapsibleContent>Anything, from a paragraph to a table.</CollapsibleContent>
  </Collapsible>
</template>
```

`Collapsible` is Reka UI's collapsible with kappa-ui's motion. The trigger is a plain `<button>` with `aria-expanded` and `aria-controls`; wrap a [Button](/docs/components/button) with `as-child` to give it a look, and Reka UI puts the trigger's `data-state` on it. The content is the only part with styles: `text-body-md` and the open and close animation.

Closed content stays in the page as `hidden="until-found"`, so the browser's find in page searches it and opens the collapsible on a match, and server-rendered HTML carries the text. This is the same choice as the [accordion](/docs/components/accordion#find-in-page), with the same cost: the content is mounted from the start. Set `unmount-on-hide` when it is heavy.

Space and Enter on the trigger open and close the content.

## Examples

### Icon

Put a chevron in the trigger and turn it with the trigger's own `data-state`: `[&[data-state=open]>svg]:rotate-180` on the Button, with a transition on the icon.

::component-preview{name="collapsible-icon" height="18rem" align="start"}
::

### Controlled

`v-model:open` holds the state, so a button elsewhere can drive it. `default-open` starts open without taking control.

::component-preview{name="collapsible-controlled" height="18rem" align="start"}
::

### Unmount on hide

`unmount-on-hide` unmounts the content while it is closed; the panel stays in the page as an empty `hidden` element. Find in page cannot reach the content then.

::component-preview{name="collapsible-unmount" height="18rem" align="start"}
::

### Disabled

`disabled` disables the trigger and keeps the content as it is, open or closed.

::component-preview{name="collapsible-disabled" height="18rem" align="start"}
::

### Heavy content

Three hundred rows open and close at the same pace as three. The height comes from Reka UI's measurement in `--reka-collapsible-content-height`, so the animation never waits on layout mid-flight.

::component-preview{name="collapsible-heavy"}
::

## Motion

The content animates its height: open over `--transition-duration-medium-1` with `--ease-emphasized-decelerate`, closed over `--transition-duration-short-4` with `--ease-emphasized-accelerate`, the accordion's timing. `overflow: hidden` applies only while the animation runs, so an open panel at rest lets a [Select](/docs/components/select) or [Popover](/docs/components/popover) inside it overflow. Under `prefers-reduced-motion` the content appears and disappears at once. The utilities are `animate-collapsible-down` and `animate-collapsible-up` from `@kappa-ui/core/tailwind.css`.

### Data attributes

::data-slots
---
rows:
  - slot: collapsible
    attributes: data-state, data-disabled
    description: The root.
  - slot: collapsible-trigger
    attributes: data-state, data-disabled, aria-expanded, aria-controls
    description: "The button, or the child it renders with `as-child`."
  - slot: collapsible-content
    attributes: data-state, data-disabled, hidden
    description: "The animated panel; `hidden=\"until-found\"` while closed, or empty and `hidden` with `unmount-on-hide`."
