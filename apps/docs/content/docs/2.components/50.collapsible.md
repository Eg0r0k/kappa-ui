## Usage

```vue
<script setup lang="ts">
import { Button } from '@/components/ui/button'
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from '@/components/ui/collapsible'
</script>

<template>
  <Collapsible>
    <CollapsibleTrigger as-child>
      <Button variant="soft" color="neutral">Show details</Button>
    </CollapsibleTrigger>
    <CollapsibleContent>Anything, from a paragraph to a table.</CollapsibleContent>
  </Collapsible>
</template>
```

The trigger has no styles of its own, so wrap a [Button](/docs/components/button) in it with `as-child`. The content animates open and closed.

Closed content stays in the page, so Ctrl+F finds it and opens the collapsible on a match, and the server-rendered HTML includes the text. Same trade-off as [Accordion](/docs/components/accordion#find-in-page): the content is mounted from the start, so set `unmount-on-hide` when it's heavy.

## Examples

### Icon

Put a chevron in the trigger and rotate it on open: `[&[data-state=open]>svg]:rotate-180` on the Button, plus a transition on the icon.

### Controlled

`v-model:open` holds the state, so a button elsewhere can drive it. `default-open` starts it open without taking control.

::component-preview{name="collapsible-controlled" height="18rem" align="start"}
::

### Unmount on hide

`unmount-on-hide` removes the content while it's closed. Ctrl+F can't find it then.

::component-preview{name="collapsible-unmount" height="18rem" align="start"}
::

### Disabled

`disabled` locks the trigger, and the content stays as it is, open or closed.

::component-preview{name="collapsible-disabled" height="18rem" align="start"}
::

### Heavy content

Three hundred rows open and close as fast as three: the height is measured up front, so the animation never waits on layout. Collapse would approve.

## Motion

| | Duration | Easing |
|---|---|---|
| Open | `--transition-duration-medium-1` | `--ease-emphasized-decelerate` |
| Close | `--transition-duration-short-4` | `--ease-emphasized-accelerate` |

Same timing as Accordion. `overflow: hidden` applies only during the animation, so a [Select](/docs/components/select) or [Popover](/docs/components/popover) inside an open panel can spill out of it. With reduced motion, the content just appears and disappears.

The utilities are `animate-collapsible-down` and `animate-collapsible-up` from `@kappa-ui/core/tailwind.css`.

::data-slots
---
rows:
  - slot: collapsible
