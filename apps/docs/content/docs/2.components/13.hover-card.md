## Usage

```vue
<script setup lang="ts">
import { Button } from '@/components/ui/button'
import { HoverCard, HoverCardContent, HoverCardTrigger } from '@/components/ui/hover-card'
</script>

<template>
  <HoverCard>
    <HoverCardTrigger as-child>
      <Button variant="link">@kappa-ui</Button>
    </HoverCardTrigger>
    <HoverCardContent>A preview of what the link leads to.</HoverCardContent>
  </HoverCard>
</template>
```

`HoverCard` is shadcn-vue's hover card on Reka UI, drawn on the same surface as a popover. It opens when the pointer rests on the trigger or the trigger takes keyboard focus, and closes when both leave. It is for a preview of what a link leads to, content a reader can do without: touch does not open it unless `enableTouch` is set, and screen readers do not announce it.

## Examples

### Delays

`openDelay` and `closeDelay` set how long, in milliseconds, the pointer has to rest before the card opens and how long it stays after the pointer leaves the trigger and the card; 700 and 300 by default.
