## Usage

```vue
<script setup lang="ts">
import { Search } from '@lucide/vue'

import { InputGroup, InputGroupAddon, InputGroupButton, InputGroupInput } from '@/components/ui/input-group'
</script>

<template>
  <InputGroup>
    <InputGroupInput placeholder="Search" />
    <InputGroupAddon>
      <Search />
    </InputGroupAddon>
    <InputGroupAddon align="inline-end">
      <InputGroupButton>Search</InputGroupButton>
    </InputGroupAddon>
  </InputGroup>
</template>
```

The group draws the frame and the control inside draws none, so the focus ring and the invalid colour go around the icons and buttons too. Addons place themselves by `align`, wherever they are in the markup; a click on one, outside its buttons, focuses the control.

### Buttons

`InputGroupButton` is a ghost neutral button by default, in its own sizes: `xs` and `sm`, or `icon-xs` and `icon-sm`. Its radius is the frame's radius less its distance from the frame's edge, so the corners stay concentric at every size, and at the start or end of the line it sits as far from the side as from the top.

### Data attributes

::data-slots
---
rows:
  - slot: input-group
    attributes: data-variant, data-size
    description: The frame.
  - slot: input-group-addon
    attributes: data-align
    description: Icons, text or buttons around the control.
  - slot: input-group-button
    attributes: data-size
    description: A button inside an addon.
  - slot: input-group-control
    description: The input or textarea.
  - slot: input-group-text
    description: Muted text inside an addon.
---
::

### CSS variables

::css-vars
---
rows:
  - name: --input-group-height
    default: 36px
    description: The group's height for its size; buttons centre themselves on it.
  - name: --control-radius
    default: var(--radius-lg)
    description: The frame's radius for its size, the same variable `Input` uses. Buttons take this less their distance from the edge.
  - name: --input-group-padding
    default: 12px
    description: Side padding of the control and of inline addons, per size.
---
::
