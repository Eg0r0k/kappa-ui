## Usage

```vue
<script setup lang="ts">
import { Marquee } from '@/components/ui/marquee'
</script>

<template>
  <Marquee pause-on-hover>
    <img v-for="logo in logos" :key="logo.alt" :src="logo.src" :alt="logo.alt" class="h-10 shrink-0" />
  </Marquee>
</template>
```

The slot is laid out in a row and repeated `repeat` times (two by default); a CSS animation slides each copy by its own width plus the gap, so the strip loops without a seam as long as the copies cover the marquee. Give every child `shrink-0`, and the marquee a width (or a height when vertical). Its content never sizes it: in a box that takes its width from its content, such as a horizontal scroll area, the marquee is as wide as you make it and nothing else. Only the first copy reaches assistive technology and the Tab order: the others are `aria-hidden` and their links and buttons get `tabindex="-1"`, while the pointer works on every copy. The slot really is rendered `repeat` times, so a component inside mounts that many times and an `id` in it repeats.

Set `--marquee-gap` rather than a `gap-*` class: the animation moves each copy by its width plus that variable.

A shadow or a ring on an item is cut at the marquee's edge; pad the marquee if it needs room.

Under reduced motion the strip stands still with the first copy in view; in a right-to-left document it runs the other way.

## Examples

### Pausing

`paused` stops the animation in place, for a control of your own: content that moves for more than five seconds needs a way to stop it (WCAG 2.2.2). `pause-on-hover` holds it under the pointer. Keyboard focus inside the marquee always stops it and shows the content from its start, so a Tab reaches something you can see; a mouse click does not.

### Repeat

`repeat` is how many copies are laid out, two by default. Each copy is at least as wide as the marquee, so two always cover it and loop without a seam; one leaves the marquee empty while the copy travels back, and more than two only cost DOM nodes.

### Fade

The edges dissolve through a mask, a quarter of the width on each side by default; `--marquee-fade` sets how much, and `:fade="false"` turns it off.

## Performance

The fade is a `mask-image`, not a pair of gradient overlays in the page's background colour, so it works on a card, a coloured band or an image as well as on the page. The price is how the browser draws it. A strip without a mask is a finished layer the compositor slides; a masked one cannot be. Every frame the browser draws the moving copies into an off-screen surface and multiplies that surface by the mask, so the cost grows with the marquee's area and with how many run at once. One logo strip is nothing; several full-width rows of cards on a weak phone can drop frames. The mask also dissolves whatever sits near the edges, a card's shadow and a focus ring included.

If that shows, set `:fade="false"`. On a plain background you can draw the fade yourself with two absolutely positioned gradients over the edges, which is what Nuxt UI does, at no cost beyond paint.

## API Reference

::api-reference{parts="Marquee"}
::

### Data attributes

::data-slots
---
rows:
  - slot: marquee
    attributes: data-orientation
    description: The root; clips the copies.
  - slot: marquee-content
    attributes: aria-hidden
    description: One copy of the slot; every copy after the first carries `aria-hidden`, and its focusable elements `tabindex="-1"`.
---
::

### CSS variables

Set with a class on the root: `class="[--marquee-duration:40s]"`.

::css-vars
---
rows:
  - name: --marquee-gap
    default: --spacing(16)
    description: The space between items and between copies.
  - name: --marquee-duration
    default: 20s
    description: How long one copy takes to travel its own length; lower is faster.
  - name: --marquee-fade
    default: 25%
    description: How much of each edge dissolves, a length or a percentage of the marquee.
---
::
