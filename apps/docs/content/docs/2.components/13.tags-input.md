## Usage

```vue
<script setup lang="ts">
import { TagsInput, TagsInputInput, TagsInputItem, TagsInputItemDelete, TagsInputItemText } from '@/components/ui/tags-input'

const fruits = ref(['Apple', 'Banana'])
</script>

<template>
  <TagsInput v-model="fruits">
    <TagsInputItem v-for="fruit in fruits" :key="fruit" :value="fruit">
      <TagsInputItemText />
      <TagsInputItemDelete />
    </TagsInputItem>
    <TagsInputInput placeholder="Add a fruit" aria-label="Fruits" />
  </TagsInput>
</template>
```

- `TagsInput`: the frame, same as [Input](/docs/components/input); grows as tags wrap
- `TagsInputItem`: one per tag, a [Badge](/docs/components/badge) with `TagsInputItemText` and `TagsInputItemDelete`
- `TagsInputInput`: the text box; attributes like `placeholder` go here

Enter or a comma turns the text into a tag. Want another separator? Pass a character or a regex to `delimiter`. Backspace in an empty box selects the last tag; press it again to remove it.

Duplicates and tags over `max` are refused, and `invalid` fires. To allow duplicates, turn on `duplicate`.

Set `name`, and the tags submit with the form. Give the input an `aria-label`, or put it in a [Field](/docs/components/field).
## Examples

### Variants

The five text control variants, the same as on [Input](/docs/components/input).

::component-preview{name="tags-input-variants"}
::

### Sizes

The frame starts at the input's height for its size, from 28px at `xs` to 48px at `xl`, and the tags take the badge size that fits: 20px at `xs`, 24px at `sm` and `md`, 28px at `lg`, 32px at `xl`. Their radius is concentric with the frame's.

::component-preview{name="tags-input-sizes"}
::

### Paste and limits

`delimiter` takes a regular expression, so a comma, a semicolon or a space all end a tag; `addOnPaste` splits pasted text on it and `addOnBlur` keeps what was typed when focus leaves. `max` caps the count, and `invalid` reports what was refused.

::component-preview{name="tags-input-behaviour"}
::

### Objects

With objects in `v-model`, `convertValue` turns the typed text into one and `displayValue` picks the text to show. A tag takes a badge `variant` and `color` of its own.

::component-preview{name="tags-input-objects"}
::

### In a field

Label, description and error come from the field. The label focuses the text box, `required` marks it, and `invalid` turns the frame destructive.

::component-preview{name="tags-input-field"}
::

### Data attributes

::data-slots
---
rows:
  - slot: tags-input
    attributes: data-variant, data-size, data-disabled, data-focused, data-invalid
    description: "The frame, holding the hidden form input. `data-invalid` while a refused tag is still in the text box."
  - slot: tags-input-item
    attributes: data-variant, data-color, data-state, data-disabled
    description: "One tag, a badge. `data-state=\"active\"` while selected from the keyboard."
  - slot: tags-input-item-text
    description: The tag's text, which labels its delete button.
  - slot: tags-input-item-delete
    attributes: data-state, data-disabled
    description: The button that removes the tag, out of the tab order.
  - slot: tags-input-input
    attributes: data-invalid, aria-invalid
    description: The text box.
---
::

### CSS variables

::css-vars
---
rows:
  - name: --control-radius
    default: var(--radius-lg)
    description: The frame's radius for its size. Tags take this less their distance from the edge.
  - name: --control-padding
    default: 12px
    description: Where the text starts from the frame's edge while there are no tags, as in `Input`.
  - name: --tags-inset
    default: 6px
    description: The tags' distance from the frame's outer edge, per size.
---
::

### Keyboard

::keyboard-table
---
rows:
  - keys: Enter
    description: Turns the typed text into a tag. Tab does too with `addOnTab`.
  - keys: Backspace
    description: In an empty text box, selects the last tag; pressed again, removes it.
  - keys: ArrowLeft / ArrowRight
    description: Moves the selection through the tags, and back to the text box past the last one.
  - keys: Home / End
    description: Selects the first or last tag.
  - keys: Delete
    description: Removes the selected tag.
---
::
