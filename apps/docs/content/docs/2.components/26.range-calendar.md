It installs [Calendar](/docs/components/calendar) too, for the shared styles.

## Usage

```vue
<script setup lang="ts">
import { CalendarDate } from '@internationalized/date'
import type { DateRange } from 'reka-ui'
import { RangeCalendar } from '@/components/ui/range-calendar'

const stay = shallowRef<DateRange | null>({
  start: new CalendarDate(2026, 10, 6),
  end: new CalendarDate(2026, 10, 12),
})
</script>

<template>
  <RangeCalendar v-model="stay" />
</template>
```

The first click picks the start, the second the end. Pick them in either order; the range comes back sorted. The ends are filled, the days between sit on a soft band, and while you choose the end a preview follows the pointer or the arrow keys.

`v-model` is `{ start, end }` of `@internationalized/date` values. While the end is being picked it's `{ start, end: undefined }`, so validate the whole range, or listen to `update:valid-model-value`, which fires only once both ends are there. Escape in the middle of a pick brings back the last complete range.

The demo above shows two months, with `:number-of-months="2"`. They sit side by side from `sm` and stack below it, and with `paged-navigation` the arrows move by two. The days from the neighbouring months are hidden, band and all, since the other grid draws them again.

Everything else, from sizes and colours to locales, week numbers, slots and the Field wiring, works as on [Calendar](/docs/components/calendar).

## Examples

### Maximum days

`maximum-days` caps the length: once a start is picked, the days beyond reach are disabled. A range can't cross unavailable days unless `allow-non-contiguous-ranges` is on.

::component-preview{name="range-calendar-maximum-days"}
::

### Presets

Set `v-model` from outside, and move `v-model:placeholder` with it so the range is on screen.

::component-preview{name="range-calendar-presets"}
::

### Date picker

A [Popover](/docs/components/popover) that closes on `update:valid-model-value`, so the first click doesn't close it. Escape mid-pick restores the last range and closes the popover in the same press.

::component-preview{name="range-calendar-date-picker"}
::

### Form

Check-in and check-out kept as ISO strings by [Formisch](/docs/forms/formisch). The schema wants both, and a check-out after the check-in. Pick one day, then the same day again.

::component-preview{name="range-calendar-form"}
::

## Known limits

- `update:model-value` fires with half a range while the end is being picked ([reka-ui#2396](https://github.com/unovue/reka-ui/issues/2396)). Act on `update:valid-model-value` when only finished ranges matter.
- Escape inside a popover both restores the range and closes the popover ([reka-ui#1536](https://github.com/unovue/reka-ui/issues/1536)).
- The preview reuses the band's `--tone-soft`; there's no separate token for it yet.
- Calendar's [known limits](/docs/components/calendar#known-limits) apply here too, except the one about `multiple`.

### Data attributes

The slots are Calendar's with a `range-` prefix. These differ:

::data-slots
---
rows:
  - slot: range-calendar
    attributes: data-size, data-color, data-months, data-disabled, data-readonly, data-invalid
    description: "The root, a `role=\"group\"`. `data-invalid` means an end is disabled."
  - slot: range-calendar-cell
    attributes: data-disabled, data-range-complete
    description: "A day's cell. It draws the band, in `--tone-soft`. `data-range-complete` is set once the range has both ends, even when one of them is in a month off screen."
  - slot: range-calendar-cell-trigger
    attributes: data-value, data-selected, data-selection-start, data-selection-end, data-highlighted, data-highlighted-start, data-highlighted-end, data-today, data-disabled, data-unavailable, data-outside-view
    description: "The day. `data-selection-*` mark the ends, `data-highlighted*` the preview while the end is picked."

## Accessibility

As on [Calendar](/docs/components/calendar#accessibility), with `aria-pressed` on the days in the range and `aria-selected` on their cells.

::keyboard-table
---
rows:
  - keys: ArrowLeft / ArrowRight / ArrowUp / ArrowDown
    description: Moves by a day or a week, flipped in right-to-left. While the end is being picked, the preview follows.
  - keys: Enter / Space
    description: Picks the start, then the end.
  - keys: Escape
    description: In the middle of a pick, brings back the last complete range. Inside a popover it closes it too.
  - keys: Home / End
    description: Moves to the first or last day of the week. Needs reka-ui 2.11 or later.
  - keys: PageUp / PageDown
    description: Moves by a month, or by a year with Shift. Needs reka-ui 2.11 or later.
---
::
