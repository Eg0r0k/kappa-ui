## Usage

```vue
<script setup lang="ts">
import { Info } from '@lucide/vue'
import { Alert, AlertDescription, AlertTitle } from '@/components/ui/alert'
</script>

<template>
  <Alert variant="subtle" color="info">
    <Info />
    <AlertTitle>Heads up!</AlertTitle>
    <AlertDescription>You can add components to your app with the CLI.</AlertDescription>
  </Alert>
</template>
```

## Examples

### Variants

`variant` and `color` are Button's: `solid`, `soft`, `subtle`, `outline`, `ghost` and `link` in `primary`, `neutral`, `destructive`, `success`, `warning` and `info`. Both default to `solid` and `primary`.

::component-preview{name="alert-variants"}
::

A colour declared for a [button](/docs/components/button#custom-colours) works on an alert too: `<Alert color="brand">`.

### Sizes

`xs` to `xl` scale the padding, gaps, radius, type and icon together; `md` is the default. The icon is an `svg` placed first, and it sits centred on the title's first line.

::component-preview{name="alert-sizes"}
::

### Actions

`AlertActions` goes under the description. With `orientation="horizontal"` it moves to the end, and the icon, the text and the actions are centred against each other, whichever is tallest.

::component-preview{name="alert-orientation"}
::

### As a link

`as` renders another element; `as-child` merges the alert onto the single element you pass. `variant="link"` underlines the text on hover.

::component-preview{name="alert-as-link"}
::

## Accessibility

The root has `role="alert"`, so a screen reader announces an alert that appears while the page is open. For a notice that can wait until the reader is idle, pass `role="status"`. An alert rendered as a link needs `role="link"`, or it stops being announced as a link.
