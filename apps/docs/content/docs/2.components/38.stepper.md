## Usage

```vue
<script setup lang="ts">
import {
  Stepper,
  StepperDescription,
  StepperIndicator,
  StepperItem,
  StepperSeparator,
  StepperTitle,
  StepperTrigger,
} from '@/components/ui/stepper'
</script>

<template>
  <Stepper>
    <StepperItem :step="1" class="flex-1">
      <StepperTrigger>
        <StepperIndicator>1</StepperIndicator>
        <StepperTitle>Account</StepperTitle>
        <StepperDescription>Create your account</StepperDescription>
      </StepperTrigger>
      <StepperSeparator />
    </StepperItem>
    <StepperItem :step="2" class="flex-1">
      <StepperTrigger>
        <StepperIndicator>2</StepperIndicator>
        <StepperTitle>Profile</StepperTitle>
        <StepperDescription>Set up your profile</StepperDescription>
      </StepperTrigger>
    </StepperItem>
  </Stepper>
</template>
```

`Stepper` is Reka UI's stepper with kappa-ui's styles. The root is a `role="group"` with a live region that announces "Step n of m" whenever the step changes. Each `StepperItem` takes its `step` number and gets its state from the current step: `active`, `completed` for the steps before it or any marked `completed`, `inactive` for the rest. The state lands as `data-state` on the item, the trigger and the separator, and the indicator and the separator colour themselves from it.

`StepperTrigger` is a `<button>` named by its `StepperTitle` and described by its `StepperDescription`. Wrap a [Button](/docs/components/button) with `as-child` to give it a look, and Reka UI puts the step's `data-state` and `disabled` on it. `StepperIndicator` shows its content, or "Step n" when empty, and hands `step` to its slot. `StepperSeparator` is a line along the stepper's axis that fills the room its item leaves, so give the items `flex-1` to space the steps evenly, or position it yourself as the examples do.

The stepper is `linear` by default: a step opens only once every step before it is done, so the triggers of later steps are disabled and skipped by the arrow keys. Set `:linear="false"` to let the user jump anywhere.

## Examples

### Horizontal

Buttons as triggers through `as-child`, with an icon per state from the item's slot. The separator is positioned across the gap between steps.

::component-preview{name="stepper-horizontal"}
::

### Vertical

`orientation="vertical"` stacks the steps and the up and down arrows move focus. The separator runs down from each button to the next.

::component-preview{name="stepper-vertical"}
::

### Sizes

`size` goes from `xs` (24px indicator) to `xl` (48px) and scales the indicator, its icon, the title, the description, the gaps and the separator with it. The trigger here is laid out as a row with `flex-row text-start`.

::component-preview{name="stepper-sizes"}
::

### Form

One [Formisch](/docs/forms/formisch) form per step. The Next button submits the current form, so the step only moves on when it validates; a click on a later step goes through `update:modelValue`, which validates the current form first. The root slot's `isFirstStep` and `isLastStep` drive the buttons.

::component-preview{name="stepper-form" height="28rem"}
::

## API Reference

Every part accepts `class`, merged over its base classes.

::api-reference{parts="Stepper,StepperItem,StepperTrigger,StepperIndicator,StepperTitle,StepperDescription,StepperSeparator"}
::

### Data attributes

::data-slots
---
rows:
  - slot: stepper
    attributes: data-orientation, data-linear, data-size, role="group"
    description: The root, with a visually hidden live region that reads "Step n of m".
  - slot: stepper-item
    attributes: data-state, data-disabled, data-orientation, aria-current
    description: "One step; `data-state` is `active`, `completed` or `inactive`, and `aria-current=\"true\"` marks the active one."
  - slot: stepper-trigger
    attributes: data-state, data-disabled, data-orientation, aria-labelledby, aria-describedby, tabindex
    description: "The button, or the child it renders with `as-child`; `disabled` while the step cannot be reached."
  - slot: stepper-indicator
    description: The circle with the number or icon.
  - slot: stepper-title
    attributes: id
    description: The title the trigger is named by.
  - slot: stepper-description
    attributes: id
    description: The text the trigger is described by.
  - slot: stepper-separator
    attributes: data-state, data-orientation
    description: The line after a step, decorative.
---
::

### Keyboard

::keyboard-table
---
rows:
  - keys: Tab
    description: Moves focus to a step that can be reached.
  - keys: ArrowRight
    description: Moves focus to the next step when horizontal.
  - keys: ArrowLeft
    description: Moves focus to the previous step when horizontal.
  - keys: ArrowDown
    description: Moves focus to the next step when vertical.
  - keys: ArrowUp
    description: Moves focus to the previous step when vertical.
  - keys: Enter
    description: Selects the focused step.
  - keys: Space
    description: Selects the focused step.
---
