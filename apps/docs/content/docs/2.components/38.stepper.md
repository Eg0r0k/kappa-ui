## Usage

```vue
<!-- код без изменений -->
```

Each `StepperItem` gets a `step` number, and its state follows the current step: `active`, `completed` (the steps before it, or any marked `completed`) or `inactive`. The state lands as `data-state` on the item, the trigger and the separator, and the indicator and the line colour themselves from it.

- `StepperTrigger`: the button; wrap a [Button](/docs/components/button) with `as-child` to style it
- `StepperIndicator`: the circle; shows "Step n" when empty and passes `step` to its slot
- `StepperTitle`, `StepperDescription`: name and describe the trigger
- `StepperSeparator`: the line to the next step; give the items `flex-1` to space them evenly

It's `linear` by default: a step unlocks only once the ones before it are done. `:linear="false"` lets users jump anywhere.

Screen readers hear "Step n of m" on every change.

## Examples

### Horizontal

Buttons as triggers through `as-child`, with an icon for each state from the item's slot. The line is positioned across the gap between steps.

### Vertical

`orientation="vertical"` stacks the steps, and the up and down arrows move focus.

::component-preview{name="stepper-vertical"}

### Sizes

`size` goes from `xs` (24px indicator) to `xl` (48px) and scales everything with it. Here the trigger is a row: `flex-row text-start`.

::component-preview{name="stepper-sizes"}
::

### Form

One [Formisch](/docs/forms/formisch) form per step. Next submits the current form, so you only move on when it's valid. Clicking a later step validates the current form first, through `update:modelValue`. `isFirstStep` and `isLastStep` from the root slot drive the buttons.

::component-preview{name="stepper-form" height="28rem"}
::

## API Reference

Every part takes a `class` that merges with its own.

### Data attributes

::data-slots
---
rows:
  - slot: stepper
    attributes: data-orientation, data-linear, data-size, role="group"
    description: The root, with a visually hidden live region that reads "Step n of m".
  - slot: stepper-item
    attributes: data-state, data-disabled, data-orientation, aria-current
    description: "One step; `data-state` is `active`, `completed` or `inactive`, and `aria-current=\"true\"` marks the active one."
  - slot: stepper-trigger
    attributes: data-state, data-disabled, data-orientation, aria-labelledby, aria-describedby, tabindex
    description: "The button, or the child it renders with `as-child`; `disabled` while the step cannot be reached."
  - slot: stepper-indicator
    description: The circle with the number or icon.
  - slot: stepper-title
    attributes: id
    description: The title the trigger is named by.
  - slot: stepper-description
    attributes: id
    description: The text the trigger is described by.
  - slot: stepper-separator
    attributes: data-state, data-orientation
    description: The line after a step, decorative.
---
::
