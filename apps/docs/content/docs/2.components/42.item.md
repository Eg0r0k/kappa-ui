## Usage

```vue
<script setup lang="ts">
import { Button } from '@/components/ui/button'
import { Item, ItemActions, ItemContent, ItemDescription, ItemTitle } from '@/components/ui/item'
</script>

<template>
  <Item variant="outline">
    <ItemContent>
      <ItemTitle>Two-step sign-in</ItemTitle>
      <ItemDescription>Ask for a code from your phone as well as your password.</ItemDescription>
    </ItemContent>
    <ItemActions>
      <Button variant="outline" color="neutral" size="sm">Turn on</Button>
    </ItemActions>
  </Item>
</template>
```

An item lays its parts in a row: `ItemMedia` at the start, `ItemContent` with an `ItemTitle` and an `ItemDescription` taking the free space, `ItemActions` at the end. `ItemHeader` and `ItemFooter` take the full width above and below.

## Examples

### Variants

Select's set, on a surface: `ghost` (the default) is transparent, `outline` draws a border, `soft` fills, `subtle` does both, and `filled` fills with a bottom border only. Every item keeps a 1px border, transparent unless drawn, so switching variants never moves the content.

::component-preview{name="item-variants"}
::

### Sizes

`size` sets the padding, gap, radius, text and media size together, from `xs` to `xl`; `md` is the default. The parts inside read it from the item, so none of them takes a size of its own.

::component-preview{name="item-sizes"}
::

### Media

`variant="icon"` frames an icon on a muted square; `variant="image"` crops an image to a square. With a description, the media aligns with the title instead of centring on the row.

::component-preview{name="item-media"}
::

### Group

`ItemGroup` stacks items; `ItemSeparator` divides them.

::component-preview{name="item-group"}
::

### Links

With `as-child`, the whole row is your own link and gets a state layer on hover and press. `as="button"` does the same for an action.

  - slot: item-footer
    description: A full-width row below.

## Accessibility

`ItemGroup` is a list, and each item in it a list item. A row rendered as a link or button keeps that role instead — a list item role would hide it — so put such rows in an `ItemGroup` with `role="group"` and an `aria-label`, as the links example does; the items then take no role.
