## Usage

```vue
<script setup lang="ts">
import { Button } from '@/components/ui/button'
import { Drawer, DrawerContent, DrawerHeader, DrawerTitle, DrawerTrigger } from '@/components/ui/drawer'
import { DrawerMenu, DrawerMenuItem, DrawerMenuSeparator } from '@/components/ui/drawer-menu'
</script>

<template>
  <Drawer>
    <DrawerTrigger as-child>
      <Button>Actions</Button>
    </DrawerTrigger>
    <DrawerContent>
      <DrawerHeader>
        <DrawerTitle>report.pdf</DrawerTitle>
      </DrawerHeader>
      <DrawerMenu>
        <DrawerMenuItem>Rename</DrawerMenuItem>
        <DrawerMenuSeparator />
        <DrawerMenuItem variant="destructive">Delete</DrawerMenuItem>
      </DrawerMenu>
    </DrawerContent>
  </Drawer>
</template>
```

`DrawerMenu` goes inside a [Drawer](/docs/components/drawer)'s `DrawerContent`, after its header: the drawer keeps its handle, its swipe and its title, and the menu is labelled by that title. Choosing an item closes the drawer unless its `select` event is prevented. The parts take the props and events of the [dropdown menu](/docs/components/dropdown-menu) ones, so a menu written for one renders through the other (see [Responsive menu](#responsive-menu)).

## Examples

### Selection

Checkbox items and radio items close the drawer like any other item; `@select.prevent` keeps it open while the user changes several of them.

::component-preview{name="drawer-menu-selection"}
::

### Submenus

A `DrawerMenuSub` drills down: its content replaces the list, slides in from the end and starts with a back row named after its trigger. `textValue` on the trigger names the back row instead of the trigger's text.

::component-preview{name="drawer-menu-submenus"}
::

### Sizes

`size` sets the row height and the icon size, `sm` (40px), `md` (48px, the default) or `lg` (56px), all large enough to tap.

::component-preview{name="drawer-menu-sizes"}
::

### Responsive menu

## Accessibility

Each panel is a `menu`: the root one labelled by the drawer's title, a submenu labelled by its trigger, which carries `aria-haspopup`, `aria-expanded` and `aria-controls`. Checkbox and radio items are `menuitemcheckbox` and `menuitemradio` with `aria-checked`. Only the visible panel can be focused; the others are `hidden` and `inert`.

::keyboard-table
---
rows:
  - keys: ArrowDown
    description: Moves focus to the next item.
  - keys: ArrowUp
    description: Moves focus to the previous item.
  - keys: Home
    description: Moves focus to the first item.
  - keys: End
    description: Moves focus to the last item.
  - keys: Enter
    description: Chooses the focused item, or opens its submenu.
  - keys: Space
    description: Chooses the focused item, or opens its submenu.
  - keys: ArrowRight
    description: Opens the focused submenu (ArrowLeft in right-to-left text).
  - keys: ArrowLeft
    description: Goes back from a submenu (ArrowRight in right-to-left text).
  - keys: Backspace
    description: Goes back from a submenu.
  - keys: Escape
    description: Goes back from a submenu; at the top level closes the drawer.
---
::

### Data attributes

::data-slots
---
rows:
  - slot: drawer-menu
    attributes: data-size
    description: The menu inside the drawer. `data-size` is `sm`, `md` or `lg`.
  - slot: drawer-menu-item
    attributes: data-highlighted, data-disabled, data-inset, data-variant
    description: An item. `data-variant` is `default` or `destructive`; `data-highlighted` marks keyboard focus or a resting mouse.
  - slot: drawer-menu-checkbox-item
    attributes: data-state, data-highlighted, data-disabled
    description: A checkbox item. `data-state` is `checked`, `unchecked` or `indeterminate`.
  - slot: drawer-menu-radio-item
    attributes: data-state, data-highlighted, data-disabled
    description: A radio item.
  - slot: drawer-menu-item-indicator
    attributes: data-state
    description: The check or dot of a checked item.
  - slot: drawer-menu-radio-group
    description: A group of radio items.
  - slot: drawer-menu-group
    description: A group of related items.
  - slot: drawer-menu-label
    attributes: data-inset
    description: A label for the items after it.
  - slot: drawer-menu-separator
    description: A line between groups.
  - slot: drawer-menu-sub-trigger
    attributes: data-state, data-highlighted, data-inset
    description: The item that opens a submenu. `data-state` is `open` while its submenu is.
  - slot: drawer-menu-sub-content
    attributes: data-state, data-motion
    description: A submenu's panel. `data-state` is `active` while it is the visible one; `data-motion` is `from-start`, `from-end`, `to-start` or `to-end`.
  - slot: drawer-menu-back
    attributes: data-highlighted
    description: The row at the top of a submenu that goes back.
---
::
