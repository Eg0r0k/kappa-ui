## Usage

```vue
<script setup lang="ts">
import { Image, ImageError, ImageLoading } from '@/components/ui/image'
</script>

<template>
  <Image src="/photo.jpg" alt="A photo" :width="1200" :height="800">
    <ImageLoading />
    <ImageError />
  </Image>
</template>
```

No resizing, no providers: `src`, `srcset`, `sizes` and `sources` take URLs you already have. The `<img>` renders on the server, so the image shows before hydration and even without JavaScript.

## Examples

### Size and ratio

The image fills a box. The box's ratio comes from, in order:

1. `ratio`
2. `width` and `height`
3. the file itself, once it loads (16 / 9 until then)

`width` and `height` are the file's size in pixels, like on `<img>`. They reserve space before the file arrives, so nothing jumps. `width` also sets the box's width, capped at its container; without it, the box fills its container.

Any other size is a class: `w-64`, or `h-40 w-auto` for a fixed height with the width following the ratio.

### Fit and position

`fit` works like `object-fit`: `cover` (the default) fills and crops, `contain` shows everything, and `fill`, `none` and `scale-down` work as in CSS. `position` works like `object-position`, centred by default.

### Loading

`ImageLoading` covers the image while it loads: a spinner by default, or your own content, like a skeleton or a tiny blurred copy. Add `delay-300`, so fast loads never flash it.

Images load lazily. Main character energy? For an image above the fold, set `loading="eager"` and `fetchpriority="high"`.

::component-preview{name="image-placeholder"}
::

`src` is `undefined` because the data is still on its way? The image keeps loading. `null` or `''` means there's no image, and `ImageError` shows. In the demo, each fetch takes three seconds.

::component-preview{name="image-deferred"}
::

### Errors

`ImageError` shows when the image fails, or when there's no `src` and no `srcset`: an icon by default, or your own content. Without it, you get the browser's broken image icon and the `alt` text.

::component-preview{name="image-fallback"}
::

### Sources

`sources` wraps the image in a `<picture>`, one `<source>` per item, in order: newer formats with `type`, other crops with `media`. `src` stays as the fallback.
