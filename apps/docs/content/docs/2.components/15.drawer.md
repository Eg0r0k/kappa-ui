## Usage

```vue
<script setup lang="ts">
import { Button } from '@/components/ui/button'
import {
  Drawer,
  DrawerBody,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from '@/components/ui/drawer'
</script>

<template>
  <Drawer>
    <DrawerTrigger as-child>
      <Button>Edit profile</Button>
    </DrawerTrigger>
    <DrawerContent>
      <DrawerHeader>
        <DrawerTitle>Edit profile</DrawerTitle>
        <DrawerDescription>Changes are saved when you press Save.</DrawerDescription>
      </DrawerHeader>
      <DrawerBody>
        <!-- the content -->
      </DrawerBody>
      <DrawerFooter>
        <DrawerClose as-child>
          <Button>Save</Button>
        </DrawerClose>
      </DrawerFooter>
    </DrawerContent>
  </Drawer>
</template>
```

`Drawer` holds the state, `DrawerTrigger` opens it, and `DrawerContent` is the panel: it renders the overlay, pins the panel to the edge named by `side` (`bottom` by default) and puts a drag handle on it. `DrawerHeader`, `DrawerBody` and `DrawerFooter` lay out the three parts; the body scrolls when the content is taller than the screen. `DrawerClose` around any button closes the drawer, and `v-model:open` opens it from code.

Underneath is [Dialog](/docs/components/dialog): Reka UI's dialog with kappa-ui's parts, so focus, Escape, the overlay and the title fallback are the dialog's. The drawer adds the gesture. A touch anywhere on the panel drags it towards its edge; past a quarter of its size, or on a quick flick, it closes, otherwise it springs back. Dragging from a scrolled body scrolls the body; from the top of the body it moves the drawer. With a mouse, only the handle and the header drag, so text in the body stays selectable.

## Gesture

A drag starts only where it makes sense. Elements under `data-no-drag` never start one, nor does a drag while text is selected. `handle-only` on `Drawer` keeps every touch for the content and leaves dragging to `DrawerHandle`. `modal: false` keeps the page live without an overlay and leaves the gesture on.

::callout
A tap on the handle closes the drawer. Add `data-drawer-drag` to an element to let a mouse drag from it as it can from the header.
::

## Accessibility

The drawer's name comes from its `DrawerTitle` and its description from its `DrawerDescription`; always give it a title. When either is missing, the panel renders an empty hidden one, so Reka UI does not warn. The handle is `aria-hidden`: keyboard users close the drawer with Escape or a button.

::keyboard-table
---
rows:
  - keys: Tab / Shift + Tab
    description: Moves to the next or previous control in the panel, wrapping around inside it.
  - keys: Escape
    description: Closes the drawer and returns focus to the element that opened it.
---
::

## Motion

The panel slides in over `--transition-duration-medium-4` with `--ease-emphasized-decelerate` and out over `--transition-duration-short-4` with `--ease-emphasized-accelerate`. While a finger moves it, `data-swiping` turns transitions off and the panel follows exactly; on release it returns over `--transition-duration-medium-2` with `--ease-standard`, or closes from where it was. Under `prefers-reduced-motion` the panel appears and disappears at once, and still follows a drag. The mechanism is the `drawer-slide` and `drawer-overlay-fade` utilities from `@kappa-ui/core/tailwind.css`, driven by the variables below.

::css-vars
---
rows:
  - name: --drawer-size
    default: measured
    description: The panel's size along its axis, in px.
  - name: --drawer-swipe-movement
    default: 0px
    description: How far a drag has moved the panel towards its edge.
  - name: --drawer-swipe-progress
    default: "0"
    description: Movement divided by size, from 0 to 1; the overlay fades with it.
  - name: --drawer-snap-offset
    default: 0px
    description: Reserved for snap points.
  - name: --drawer-keyboard-inset
    default: 0px
    description: What the visual viewport lost to the keyboard; a bottom drawer lifts by it.
---
::

## API Reference

Every part except `Drawer`, which renders no element, accepts `class`, merged over its own classes with tailwind-merge. On `DrawerContent` it styles the panel, so `h-[85dvh]` sets a bottom drawer's height and `bg-*` replaces its background.
