## Usage

```vue
<script setup lang="ts">
import { Button } from '@/components/ui/button'
import { Popover, PopoverContent, PopoverTrigger } from '@/components/ui/popover'
</script>

<template>
  <Popover>
    <PopoverTrigger as-child>
      <Button variant="outline" color="neutral">Open</Button>
    </PopoverTrigger>
    <PopoverContent>Place content for the popover here.</PopoverContent>
  </Popover>
</template>
```

Put anything inside. It opens below the trigger and moves to stay on screen. Escape or a click outside closes it.

Want it anchored to something else, like the input your button sits in? Wrap that element in `PopoverAnchor`.

## Examples

### Modal

By default, the page stays clickable: a click outside closes the popover and also hits whatever is under it.

Add `modal`, and the page [locks](/docs/getting-started/overlays) while it's open: focus stays inside, scrolling stops, and a click outside only closes the popover.
