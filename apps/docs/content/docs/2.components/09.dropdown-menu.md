## Usage

```vue
<script setup lang="ts">
import { Button } from '@/ui/button'
import { DropdownMenu, DropdownMenuContent, DropdownMenuItem, DropdownMenuTrigger } from '@/ui/dropdown-menu'
</script>

<template>
  <DropdownMenu>
    <DropdownMenuTrigger as-child>
      <Button variant="outline" color="neutral">Open</Button>
    </DropdownMenuTrigger>
    <DropdownMenuContent>
      <DropdownMenuItem @select="rename">Rename</DropdownMenuItem>
      <DropdownMenuItem variant="destructive" @select="remove">Delete</DropdownMenuItem>
    </DropdownMenuContent>
  </DropdownMenu>
</template>
```

`DropdownMenu` is Reka UI's dropdown menu with kappa-ui's styles. The trigger opens it on press, Enter, Space or the down arrow; the arrow keys move through the items, the right arrow opens a submenu and the left arrow closes it, and typing jumps to the item that starts with the typed letters. An item fires `select` and closes the menu.

The menu is [modal](/docs/getting-started/overlays) by default: while it is open, an outside click only closes it. Set `:modal="false"` on `DropdownMenu` to let the page stay live.

Items share their look with the [context menu](/docs/components/context-menu) and the [select](/docs/components/select): the same height, highlight and indicators. A leading icon is 16px and muted; `DropdownMenuShortcut` shows a key combination at the end, for display only.

## Examples

### Sizes

`size` on `DropdownMenuContent` runs from `xs` to `xl`. Items are 28, 32, 36, 40 and 48px tall, as tall as an [input](/docs/components/input) of the same size, and the text, icons and padding grow with them: 12px text for `xs` and `sm`, 14px for `md`, the default, and 16px for `lg` and `xl`, with icons from 14 to 20px. A submenu takes the size of the menu it opens from; give its content its own `size` to change it.

::component-preview{name="dropdown-menu-sizes"}
::

### Open state

While the menu is open, `DropdownMenuTrigger` carries `data-state="open"` and `aria-expanded="true"`, and `data-state="closed"` otherwise. Style the trigger with `data-[state=open]:`, or a container around it with `has-data-[state=open]:`.

::component-preview{name="dropdown-menu-open-state"}
::

### Checkbox items

`DropdownMenuCheckboxItem` toggles a setting. Bind it with `v-model`.

::component-preview{name="dropdown-menu-checkboxes"}
::

### Radio group

`DropdownMenuRadioItem`s inside a `DropdownMenuRadioGroup` pick one option. Bind the group with `v-model`.

::component-preview{name="dropdown-menu-radio-group"}
::

Checkbox and radio items reserve room for their indicator at the start. Give plain items and labels in the same menu `inset` to line their text up with them.

### Non-modal

With `:modal="false"` there is no scrim and no scroll lock: the list and the page keep scrolling while a menu is open, and another row's menu opens with one click instead of two.

::component-preview{name="dropdown-menu-non-modal"}
::

### Data attributes

::data-slots
---
rows:
  - slot: dropdown-menu-trigger
    attributes: data-state, data-disabled
    description: The element that opens the menu. `data-state` is `open` while the menu is open, `closed` otherwise.
  - slot: dropdown-menu-content
    attributes: data-state, data-side, data-align, data-size
    description: The menu's panel. `data-size` is its size, `xs` to `xl`.
  - slot: dropdown-menu-scrim
    description: The transparent layer under a modal menu that takes the first outside click.
  - slot: dropdown-menu-item
    attributes: data-highlighted, data-disabled, data-inset, data-variant
    description: An item. `data-variant` is `default` or `destructive`.
  - slot: dropdown-menu-checkbox-item
    attributes: data-state, data-highlighted, data-disabled
    description: A checkbox item. `data-state` is `checked`, `unchecked` or `indeterminate`.
  - slot: dropdown-menu-radio-item
    attributes: data-state, data-highlighted, data-disabled
    description: A radio item.
  - slot: dropdown-menu-label
    attributes: data-inset
    description: A label for the items after it.
  - slot: dropdown-menu-separator
    description: A line between groups.
  - slot: dropdown-menu-shortcut
    description: A key combination at the end of an item.
  - slot: dropdown-menu-sub-trigger
    attributes: data-state, data-highlighted, data-inset
    description: The item that opens a submenu.
  - slot: dropdown-menu-sub-content
    attributes: data-state, data-side, data-size
    description: A submenu's panel.
---
