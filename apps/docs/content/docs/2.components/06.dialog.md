## Usage

```vue
<script setup lang="ts">
import { Button } from '@/ui/button'
import { Dialog } from '@/ui/dialog'
</script>

<template>
  <Dialog title="Edit profile" description="Changes are saved when you press Save.">
    <Button>Edit profile</Button>

    <template #body>
      <!-- the content -->
    </template>

    <template #footer="{ close }">
      <Button @click="close">Save</Button>
    </template>
  </Dialog>
</template>
```

`Dialog` follows [Nuxt UI's modal](https://ui.nuxt.com/docs/components/modal): one component with props for the title and description and slots for the rest. Whatever is in the default slot becomes the trigger, so a `Button` there opens the dialog. When the trigger is not the slot's only element, such as a button inside a toolbar, mark it with `DialogTrigger` instead, and the rest of the slot renders as it is. `v-model:open` opens the dialog from code. The `header`, `body` and `footer` slots fill the three parts of the window, `actions` adds buttons next to the title, and `content` replaces all of them. The `body` and `footer` slots receive `close`.

Underneath it is Reka UI's dialog: focus moves into the window and stays there, Escape or a click outside closes it, focus returns to the trigger, and screen readers announce the title and description. The page behind is [shut](/docs/getting-started/overlays): it does not scroll, and the dark overlay takes outside clicks.

The window is a flex column, not a grid, so the body can shrink. It is as tall as its content up to the window's height less a margin, and past that the body scrolls in a [scroll area](/docs/components/scroll-area) while the header and footer stay put.

### Not dismissible

With `:dismissible="false"`, Escape and outside clicks leave the window open and fire `close:prevent` instead. Only a button in it closes it. `:close="false"` removes the close button in the header.

::component-preview{name="dialog-dismissible"}
::

### Overlay

With `:overlay="false"`, the page behind stays undimmed. The overlay is still there, only transparent, so the page is still shut: an outside click closes the dialog and reaches nothing under it.

::component-preview{name="dialog-no-overlay"}
::

### Nested

A dialog can open another from its body or footer. The new one stacks on top with its own overlay, Escape and outside clicks close only the top one, and focus returns to the first dialog when it closes. Below, the inner dialog confirms a change and closes itself with its own `close`, and the first dialog stays open and shows the result. To close both at once, call both `close` functions from the slots they come from.

::component-preview{name="dialog-nested"}
::

### Custom layout

The `content` slot replaces the header, body and footer. Build the window from `DialogHeader`, `DialogTitle`, `DialogDescription`, `DialogBody` and `DialogFooter`, and close it with `DialogClose`. Include a `DialogTitle`: it names the window for screen readers.

::component-preview{name="dialog-custom"}
::

### Opened from code

Without a trigger in the default slot, bind `v-model:open` and open the dialog from anywhere, here a [menu](/docs/components/menu) item.

::component-preview{name="dialog-controlled"}

### Data attributes

::data-slots
---
rows:
  - slot: dialog
    attributes: data-state
    description: The window.
  - slot: dialog-trigger
    attributes: data-state
    description: An explicit trigger inside the default slot.
  - slot: dialog-overlay
    attributes: data-state, data-transparent
    description: The layer behind the window that dims the page and takes outside clicks. `data-transparent` is set with `:overlay="false"`.
  - slot: dialog-header
    description: The title, description, actions and close button.
  - slot: dialog-body
    description: The scroll area around the body.
  - slot: dialog-footer
    description: The buttons at the bottom.
