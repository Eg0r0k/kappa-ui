## Usage

```vue
<script setup lang="ts">
import { Avatar, AvatarFallback, AvatarImage } from '@/components/ui/avatar'
</script>

<template>
  <Avatar>
    <AvatarImage src="/me.jpg" alt="Kappa Person" />
    <AvatarFallback>KP</AvatarFallback>
  </Avatar>
</template>
```

The photo shows once it has loaded. Until then, or for good if it fails, `AvatarFallback` shows instead. Put initials or an icon in it, and they're sized for you.

## Examples

### Sizes

`size` goes from `xs` (24px) to `xl` (64px), `md` by default. The fallback's text and icons scale with it.

::component-preview{name="avatar-sizes"}
::

### Fallback

The fallback shows right away, so a slow photo shows initials first. Photos usually load fast? `delay-ms` holds the initials back, so they don't flash.

Square avatar? Add `class="rounded-lg"` to `Avatar`.

::component-preview{name="avatar-fallback"}
::

### Group

`AvatarGroup` overlaps the avatars with a thin ring between them, and `AvatarGroupCount` is the "+3" circle at the end. The ring matches the page background; on another surface, set `--avatar-ring` to match it.

::component-preview{name="avatar-group"}
::

### With Image

Need `srcset`, `<picture>` sources or a loading layer? Put an [Image](/docs/components/image) in the avatar instead of `AvatarImage`. Its `ImageError` becomes the fallback, so skip `AvatarFallback`.

Don't nest one inside the other: `AvatarImage` would hide `Image` until its own request finishes.

::component-preview{name="avatar-image"}
::

## API Reference

Every part takes a `class` that merges with its own.

::api-reference{parts="Avatar,AvatarImage,AvatarFallback,AvatarGroup,AvatarGroupCount"}

### Data attributes

::data-slots
---
rows:
  - slot: avatar
    attributes: data-size
    description: The root, a span that clips to a circle.
  - slot: avatar-image
    attributes: ''
    description: "The img. Hidden with `display: none` until it has loaded."
  - slot: avatar-fallback
    attributes: ''
    description: The fallback, rendered while the image has not loaded.
  - slot: avatar-group
    attributes: ''
    description: The row.
  - slot: avatar-group-count
    attributes: data-size
    description: The count, a circle like a fallback.
---
::

### CSS variables

::css-vars
---
rows:
  - name: --avatar-size
    default: 2.5rem for md
    description: Width and height of an avatar or a count, set by `size`. A group overlaps its children by a quarter of it.
  - name: --avatar-ring
    default: var(--color-background)
    description: Colour of the 2px ring between the members of a group. Set it on the group to the surface it sits on, for example `class="[--avatar-ring:--theme(--color-card)]"`.
---
