## Usage

```vue
<script setup lang="ts">
import { Button } from '@/components/ui/button'
import { Item, ItemActions, ItemContent, ItemDescription, ItemTitle } from '@/components/ui/item'
</script>

<template>
  <Item variant="outline">
    <ItemContent>
      <ItemTitle>Two-step sign-in</ItemTitle>
      <ItemDescription>Ask for a code from your phone as well as your password.</ItemDescription>
    </ItemContent>
    <ItemActions>
      <Button variant="outline" color="neutral" size="sm">Turn on</Button>
    </ItemActions>
  </Item>
</template>
```

- `ItemMedia`: an icon, image or avatar at the start
- `ItemContent`: holds `ItemTitle` and `ItemDescription`, takes the free space
- `ItemActions`: controls at the end
- `ItemHeader`, `ItemFooter`: full-width rows above and below

## Examples

### Variants

The same set as [Input](/docs/components/input#variants):

- `ghost` (default): transparent
- `outline`: a border
- `soft`: a fill
- `subtle`: a fill and a border
- `filled`: a fill with a line underneath

Switching variants never moves the content.

::component-preview{name="item-variants"}
::

### Sizes

`size` goes from `xs` to `xl` and sets the row's density: padding, gap and media. Text keeps its size, so a compact row still reads at body size, and a `text-body-sm` of your own on a part is just a class. The media box follows `--item-media` on the root, and a `size-*` class on an `ItemMedia` wins over it. The description keeps two lines at most until you pass `line-clamp-none` or another clamp.

::component-preview{name="item-sizes"}
::

### Media

`variant="icon"` puts an icon on a muted square, and `variant="image"` crops an image to a square. With a description, the media lines up with the title instead of the middle of the row.

::component-preview{name="item-media"}
::

### Group

`ItemGroup` stacks items, and `ItemSeparator` divides them.

::component-preview{name="item-group"}
::

### Links

With `as-child`, the whole row becomes your link, with hover and press feedback. `as="button"` does the same for actions.

## Accessibility

`ItemGroup` is a list, and its items are list items. Rows that are links or buttons can't be list items, so give their `ItemGroup` `role="group"` and an `aria-label`, as in the links example.
