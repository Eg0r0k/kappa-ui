## Usage

```vue
<script setup lang="ts">
import { Image, ImageError, ImageLoading } from '@/components/ui/image'
</script>

<template>
  <Image src="/photo.jpg" alt="A photo" :width="1200" :height="800">
    <ImageLoading />
    <ImageError />
  </Image>
</template>
```

The API follows Nuxt Image's `NuxtImg` and `NuxtPicture` and Quasar's `QImg`, without providers: nothing resizes or converts the file, so `src`, `srcset`, `sizes` and `sources` take URLs you already have. The `<img>` renders on the server, so the image shows before hydration and without JavaScript.

## Examples

### Size and ratio

The image fills a box. The box's ratio comes from `ratio`, or else from `width` and `height`, or else from the file once it loads, and is 16 / 9 until then. `width` and `height` are the file's size in pixels, as on `<img>`: they reserve the box before the file arrives, and `width` also sets the box's width, capped at its container. Without `width`, the box fills its container, even in a flex row or column that does not stretch its items. A class sets any other size: `class="w-64"`, or a height with `w-auto`, `class="h-40 w-auto"`, for a width that follows the ratio. The demo above gives the file's size and lets the browser pick from `srcset` by `sizes`.

### Fit and position

`fit` places the image in its box like `object-fit`: `cover` (the default) fills it and crops, `contain` shows all of it, and `fill`, `none` and `scale-down` work as in CSS. `position` aligns it, like `object-position`, and is `50% 50%` by default.

::component-preview{name="image-fit"}

### Loading

`ImageLoading` covers the image while it loads, with a spinner unless you give it content: a skeleton, or a small blurred copy of the image. A class like `delay-300` holds it back so fast loads never show it; it hides without delay. The image loads lazily by default; for an image above the fold, set `loading="eager"` and `fetchpriority="high"`.

::component-preview{name="image-placeholder"}
::

While `src` is `undefined`, for example until the data that holds it arrives, the image stays in its loading state and `ImageLoading` shows. `null` or an empty string means there is no image, and `ImageError` shows instead. In this example each fetch takes three seconds to answer.

::component-preview{name="image-deferred"}
::

### Errors

`ImageError` covers the image when it fails to load, or when `src` is `null` or empty and there is no `srcset`, with an icon unless you give it content. Without it, a failed image shows the browser's broken image and its `alt` text.

::component-preview{name="image-fallback"}
::

### Sources

`sources` wraps the image in a `<picture>`, with one `<source>` per item, in order: newer formats with `type`, or other crops with `media`. `src` stays as the fallback.
