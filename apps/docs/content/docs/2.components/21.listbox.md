## Usage

```vue
<script setup lang="ts">
import {
  Listbox,
  ListboxContent,
  ListboxDescription,
  ListboxIcon,
  ListboxItem,
  ListboxTitle,
} from '@/components/ui/listbox'

const channel = ref('email')
</script>

<template>
  <Listbox v-model="channel" aria-label="Notify me by">
    <ListboxItem value="email">
      <ListboxIcon><MailIcon /></ListboxIcon>
      <ListboxContent>
        <ListboxTitle>Email</ListboxTitle>
        <ListboxDescription>A daily digest at 9:00.</ListboxDescription>
      </ListboxContent>
    </ListboxItem>
  </Listbox>
</template>
```

`Listbox` is Reka UI's listbox with kappa-ui's styles: an element with `role="listbox"` and options with `role="option"`. It is one tab stop. The arrow keys move between options, Home and End jump to the ends, typing a few letters jumps to the option that starts with them, and Space or Enter selects. A selected option gets a tint and a check at its end.

An option is put together from parts, like a [card](/docs/components/card): `ListboxIcon` at the start, `ListboxContent` holding a `ListboxTitle` and a `ListboxDescription`, or just text. Attributes and classes on `Listbox` land on the element with `role="listbox"`, so `aria-label` and width classes go there directly.

Inside a [Field](/docs/components/field) the listbox is named by the field's label and described by its description and error. Without a field, give it `aria-label`.

## Examples

### Icons, titles and descriptions

`ListboxIcon` holds an icon at the start of the option. It is hidden from screen readers and turns `--primary` with the option. Icons are 16px unless they set their own size. Below they are 20px, which suits two lines of text.

::component-preview{name="listbox-icons"}
::

### Sizes

`size` runs from `xs` to `xl`. Options are 28, 32, 36, 40 and 48px tall, as tall as a [menu](/docs/components/menu) item or an [input](/docs/components/input) of the same size, and their text, icons, padding and gaps grow with them on the [control scale](/docs/getting-started/sizing). `md` is the default.

::component-preview{name="listbox-sizes"}
::

### Custom indicator

Replace the check in the `indicator-icon` slot. Here `selection-behavior="replace"` also keeps one plan chosen at all times: by default, clicking the selected option clears it.

::component-preview{name="listbox-indicator"}
::

### Multiple

With `multiple`, `v-model` is an array and each click adds or removes an option. Screen readers announce the listbox as multi-select.

::component-preview{name="listbox-multiple"}
::

### Groups

`ListboxGroup` gathers options under a `ListboxGroupLabel`, which also names the group for screen readers. `ListboxSeparator` draws a line between groups and is hidden from screen readers.

::component-preview{name="listbox-groups"}
::

### Disabled

A disabled option cannot be selected, and the arrow keys skip it. A disabled listbox dims every option and ignores the pointer and the keyboard.

::component-preview{name="listbox-disabled"}
::

### On select

`ListboxItem` fires `select` when it is clicked or chosen with the keyboard, with the value in `event.detail.value`. Call `event.preventDefault()` to run an action without selecting the option, which turns the listbox into a list of commands.

::component-preview{name="listbox-select"}
::

### In a scroll area

For a long list, put a `variant="ghost"` listbox in a [scroll area](/docs/components/scroll-area) and give the frame to the scroll area. The arrow keys scroll the highlighted option into view.

::component-preview{name="listbox-scroll-area"}
::

### Field

In a required field the listbox gets `aria-required`, and when the field is invalid, `aria-invalid` and a `--destructive` frame. Press Continue without choosing a region.

::component-preview{name="listbox-field"}
::

## API Reference

Every part accepts `class`, merged over its base classes.

::api-reference{parts="Listbox,ListboxItem,ListboxGroupLabel,ListboxContent,ListboxDescription,ListboxGroup,ListboxIcon,ListboxSeparator,ListboxTitle"}
::

### Data attributes

::data-slots
---
rows:
  - slot: listbox
    attributes: data-variant, data-size, data-orientation, data-disabled
    description: The element with `role="listbox"`. Receives `class` and attributes.
  - slot: listbox-root
    description: "Reka UI's root, laid out with `display: contents`."
  - slot: listbox-item
    attributes: data-state, data-highlighted, data-disabled
    description: One option. `data-state` is `checked` or `unchecked`; `data-highlighted` marks the option the keyboard is on.
  - slot: listbox-item-indicator
    description: The check at the end of a selected option.
  - slot: listbox-icon
    description: The icon at the start of an option.
  - slot: listbox-content
    description: The column holding the title and description.
  - slot: listbox-title
    description: The option's name.
  - slot: listbox-description
    description: The supporting text.
  - slot: listbox-group
    description: A group of options.
  - slot: listbox-group-label
    description: The group's name.
  - slot: listbox-separator
    description: The line between groups.
---
