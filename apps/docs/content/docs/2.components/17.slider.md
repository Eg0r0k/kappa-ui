## Usage

```vue
<script setup lang="ts">
import { Slider } from '@/components/ui/slider'

const volume = ref(50)
</script>

<template>
  <Slider v-model="volume" aria-label="Volume" />
</template>
```

`v-model` is a number for one thumb. Pass an array, and you get one thumb per item.

Click anywhere on the track, and the nearest thumb jumps there. The thumb looks and reacts like the [Switch](/docs/components/switch) handle.

Give it an `aria-label`, or put it in a [Field](/docs/components/field).

## Examples

### Min, max and step

The value runs from `min` to `max`, 0 to 100 by default, in steps of `step`. When the number alone does not say what it means, set `aria-valuetext`, which screen readers read instead.

::component-preview{name="slider-min-max"}
::

### Multiple

Pass an array for a range, like a price filter. Each thumb gets a screen reader name on its own, so you don't need to label them one by one.

::component-preview{name="slider-multiple"}
::

### Min steps between thumbs

`min-steps-between-thumbs` keeps neighbouring thumbs that many steps apart. Without it, thumbs can meet and pass each other.

::component-preview{name="slider-min-steps"}
::

### Orientation

`orientation="vertical"` runs the slider from bottom to top. It fills the height of its container and is at least 176px tall.

::component-preview{name="slider-orientation"}
::

### Sizes

`size` sets the handle, from 12px for `xs` to 24px for `xl`, and the track thickness with it, from 4px to 10px. `md`, the default, is a 16px thumb on a 6px track.

::component-preview{name="slider-sizes"}
::

### Inset

`variant="inset"` puts the thumb inside a thick track, with the fill wrapping around it. The handle shrinks a little while you drag it.

Keep the default `thumb-alignment="contain"`. With `overflow`, the fill and the handle drift apart near the ends.

::component-preview{name="slider-inset"}
::

### Inverted

Same slider, but in Australia. `inverted` flips it: right to left, or top to bottom. Arrow keys still move the thumb the way they point.

On a right-to-left page, a horizontal slider already runs right to left on its own.

::component-preview{name="slider-inverted"}
::

### Colours

`color` draws the range and the thumbs in Button's colours or [your own](/docs/getting-started/theming#your-own-tone), `primary` by default. The rest of the default track is the same colour at 20%; the `inset` track stays grey.

::component-preview{name="slider-colors"}
::

### States

A disabled slider turns grey and ignores the pointer and the keyboard. An invalid one turns its range and thumbs `--destructive`, whatever its `color`, and sets `aria-invalid` on each thumb.

::component-preview{name="slider-states"}
::

### Touch target

Smaller than a finger? Add `touch-target`: `expand` when it stands alone, `wrapper` when it sits close to others. [How it works](/docs/getting-started/accessibility#touch-targets).

The track and each thumb get their own area: press a thumb's to pick it up where it is, or the track's to pull the nearest thumb to your finger.

::component-preview{name="slider-touch-target"}
::

### Data attributes

::data-slots
---
rows:
  - slot: slider
    attributes: data-orientation, data-disabled, data-touch-target, data-variant, data-color, data-size
    description: The root, and the pressable area of the track.
  - slot: slider-track
    attributes: data-orientation, data-disabled
    description: The full length of the track.
  - slot: slider-range
    attributes: data-orientation, data-disabled
    description: The filled part of the track.
  - slot: slider-thumb
    attributes: data-orientation, data-disabled, data-hovered
    description: One thumb, with `role="slider"`. Draws the state layer, or, with `inset`, the disc around the handle.
  - slot: slider-handle
    description: The circle inside a thumb.
---
::
