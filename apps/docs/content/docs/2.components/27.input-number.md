## Usage

```vue
<script setup lang="ts">
import { InputNumber, InputNumberDecrement, InputNumberIncrement, InputNumberInput } from '@/components/ui/input-number'

const quantity = ref(1)
</script>

<template>
  <InputNumber v-model="quantity" :min="0" :max="99">
    <InputNumberDecrement />
    <InputNumberInput aria-label="Quantity" />
    <InputNumberIncrement />
  </InputNumber>
</template>
```

`InputNumber` is Reka UI's number field in the frame of [Input](/docs/components/input): the root draws the border, the variant and the focus ring, `InputNumberInput` is the text box inside it, and `InputNumberIncrement` and `InputNumberDecrement` are ghost buttons that step the value. The root lays them out on a grid, so the buttons take their places from `orientation`, whatever order they are written in, and leaving one out just removes it.

`v-model` holds a `number`, or `undefined` while the field is empty. Typing is filtered to what the format allows, and the text is parsed and clamped to `min` and `max` when the field loses focus or Enter is pressed. The buttons, the arrow keys and the mouse wheel on the focused field step by `step`, snapping to its multiples unless `stepSnapping` is off; holding a button down repeats. A button disables at the end of the range. Under `name`, a hidden input submits the number with the form.

Attributes on `InputNumberInput` go to the `<input>`, so `placeholder` and `aria-label` work as usual. Inside a [Field](/docs/components/field) the input takes its `id`, description, error and state from it.

## Examples

### Vertical

`orientation="vertical"` stacks both buttons at the end of the field as chevrons, half the field's height each. The text keeps to the start, where it reads as a plain input.

::component-preview{name="input-number-vertical"}
::

### Variants

The five text control variants, the same as on [Input](/docs/components/input).

::component-preview{name="input-number-variants"}
::

### Sizes

The field runs from 28px at `xs` to 48px at `xl`, the heights of the matching inputs. Horizontal buttons are squares inset from the frame, from 24px to 40px, with a radius concentric with the frame's; vertical buttons are as wide as those squares and split the height.

::component-preview{name="input-number-sizes"}
::

### Formatting

`formatOptions` takes `Intl.NumberFormat` options and `locale` a BCP 47 tag. The text shows the formatted value, the model keeps the number: a percentage is stored as a fraction, a currency as its amount. The options also decide what can be typed, so a decimal format accepts a decimal separator and an integer format does not, and the phone keyboard switches between numeric and decimal to match.

::component-preview{name="input-number-format"}
::

### States

`disabled` fades the frame, the text and both buttons; `readonly` keeps the text readable and disables the buttons. At `min` or `max` only the step that would leave the range is disabled.

::component-preview{name="input-number-states"}
::

### In a field

Label, description and error come from the field. The label focuses the input, `required` marks it, and `invalid` turns the frame destructive.

::component-preview{name="input-number-field"}
::

### Data attributes

::data-slots
---
rows:
  - slot: input-number
    attributes: data-orientation, data-variant, data-size, data-disabled, data-readonly
    description: "The frame, a `role=\"group\"`, holding the hidden form input."
  - slot: input-number-input
    attributes: data-disabled, data-readonly, aria-invalid
    description: "The text box, a `role=\"spinbutton\"` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`."
  - slot: input-number-increment
    attributes: data-disabled, data-pressed
    description: The button that adds a step.
  - slot: input-number-decrement
    attributes: data-disabled, data-pressed
    description: The button that takes a step away.
---

### CSS variables

::css-vars
---
rows:
  - name: --control-radius
    default: var(--radius-lg)
    description: The frame's radius for its size. Buttons take this less their distance from the edge.
  - name: --control-padding
    default: 12px
    description: Side padding of the input where no button sits; next to a button it is 6px.
  - name: --stepper-size
    default: 28px
    description: The side of a horizontal button and the width of the vertical column, per size.
  - name: --stepper-inset
    default: 4px
    description: A horizontal button's distance from the frame's outer edge.
  - name: --stepper-icon
    default: 16px
    description: Icon size in horizontal buttons, per size.
  - name: --stepper-chevron
    default: 14px
    description: Icon size in vertical buttons, one step smaller.
---
::

### Keyboard

::keyboard-table
---
rows:
  - keys: ArrowUp / ArrowDown
    description: Steps the value up or down.
  - keys: PageUp / PageDown
    description: Steps by ten steps.
  - keys: Home / End
    description: Jumps to `min` or `max`.
  - keys: Enter
    description: Commits the typed text, parsing and clamping it.
