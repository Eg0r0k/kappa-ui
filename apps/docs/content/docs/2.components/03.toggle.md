## Usage

```vue
<script setup lang="ts">
import { Bold } from '@lucide/vue'

import { Toggle } from '@/components/ui/toggle'

const bold = ref(false)
</script>

<template>
  <Toggle v-model="bold" size="icon" aria-label="Bold">
    <Bold />
  </Toggle>
</template>
```

`Toggle` is Reka UI's toggle styled like a [Button](/docs/components/button). It is a button with `aria-pressed`, and `v-model` binds whether it is on. For a set of toggles, use [Toggle Group](/docs/components/toggle-group).

## Examples

### Variants

`variant` and `color` style the toggle while it is off, `activeVariant` and `activeColor` while it is on, from Button's variants and colours. By default a toggle is transparent and neutral, and fills softly when on.

::component-preview{name="toggle-variants"}
::

### Active look

Any pair works: an outline toggle that turns solid primary, or soft warning for a favourite.

::component-preview{name="toggle-active"}
::

`activeColor` sets `data-active-color`, and while the toggle is on, the colour rules match it over `data-color`. A [custom colour](/docs/components/button#custom-colours) you want as `activeColor` needs its rule to match that too:

```css
[data-slot][data-color='pro'],
[data-slot][data-state='on'][data-active-color='pro'] {
  --tone: var(--pro);
  /* … */
}
```

### Sizes
