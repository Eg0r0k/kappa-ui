## Usage

```vue
<script setup lang="ts">
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from '@/components/ui/breadcrumb'
</script>

<template>
  <Breadcrumb>
    <BreadcrumbList>
      <BreadcrumbItem>
        <BreadcrumbLink href="/">Home</BreadcrumbLink>
      </BreadcrumbItem>
      <BreadcrumbSeparator />
      <BreadcrumbItem>
        <BreadcrumbLink href="/docs/components">Components</BreadcrumbLink>
      </BreadcrumbItem>
      <BreadcrumbSeparator />
      <BreadcrumbItem>
        <BreadcrumbPage>Breadcrumb</BreadcrumbPage>
      </BreadcrumbItem>
    </BreadcrumbList>
  </Breadcrumb>
</template>
```

## Examples

### Custom separator

Put your own icon in `BreadcrumbSeparator`'s slot.

::component-preview{name="breadcrumb-custom-separator"}
::

### Dropdown

The demo above opens a [menu](/docs/components/menu) from the ellipsis. The button around it carries the `aria-label`, since the ellipsis itself is hidden from screen readers.

### Collapsed

`BreadcrumbEllipsis` stands in for the middle of a long trail.

::component-preview{name="breadcrumb-collapsed"}
::

### Link component

`BreadcrumbLink` renders an `a`. Use `as-child` to render your router's link instead, such as `NuxtLink` or `RouterLink`.

::component-preview{name="breadcrumb-as-child"}
::

### Data attributes

::data-slots
---
rows:
  - slot: breadcrumb
    description: The `nav`, labelled "breadcrumb".
  - slot: breadcrumb-list
    description: The ordered list.
  - slot: breadcrumb-item
    description: One step of the trail.
  - slot: breadcrumb-link
    description: A link to an earlier page.
  - slot: breadcrumb-page
    description: The current page, with `aria-current="page"`.
  - slot: breadcrumb-separator
    description: The icon between two items, hidden from screen readers.
  - slot: breadcrumb-ellipsis
    description: The icon in place of collapsed items.
---
::
