Button, Toggle, Item links, menu and list items, tabs, accordion triggers, calendar days and the rest of the pressable parts already ripple: they import the directive themselves, so there's nothing to register for them. Install it to ripple your own elements.

## Installation

::install-tabs{name="ripple"}
::

Register it once in your app entry, or import it in the component that uses it, as kappa-ui's parts do:

```ts
import vRipple from '@/lib/ripple'

app.directive('ripple', vRipple)
```

## Usage

```vue
<button v-ripple>Press me</button>
<button v-ripple="{ color: 'red', opacity: 0.3 }">Tinted</button>
```

On a Button, the directive overrides the built-in ripple:

```vue
<Button v-ripple="{ color: 'red', opacity: 0.3 }">Tinted</Button>
<Button v-ripple="false">Off</Button>
```

The wave starts small under your finger, drifts to the centre as it grows, and has a soft edge. Enter and Space ripple too, from the centre. If the element is `position: static`, the directive makes it `relative`.

No stylesheet needed: it runs on the Web Animations API. Colour, opacity and timing come from the variables below, read at the moment of the press.

- A quick tap still shows the ripple for at least 225ms, so it never just flashes.
- Holding keeps the wave up until you let go.
- With reduced motion, the wave appears fully grown and only fades.
- In forced colours mode, there's no wave at all.
- A disabled element (`disabled`, `aria-disabled="true"` or `data-disabled`) doesn't ripple.

::css-vars
---
rows:
  - name: --kappa-ripple-color
    default: currentColor
    description: Colour of the wave.
  - name: --kappa-ripple-opacity
    default: var(--state-pressed, 12%)
    description: Opacity of the wave. The ripple item sets it on :root; without it the directive uses 0.12.
  - name: --kappa-ripple-grow-duration
    default: 450ms
    description: Time to expand.
  - name: --kappa-ripple-fade-duration
    default: 375ms
    description: Time to fade after release.
  - name: --kappa-ripple-easing
    default: var(--ease-standard, cubic-bezier(0.2, 0, 0, 1))
    description: Easing of the expansion. The ripple item sets it on :root; without it the directive uses cubic-bezier(0.2, 0, 0, 1).
---
::
