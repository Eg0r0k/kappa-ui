## Usage

```vue
<script setup lang="ts">
import { Card, CardContent, CardDescription, CardFooter, CardHeader, CardTitle } from '@/components/ui/card'
</script>

<template>
  <Card>
    <CardHeader>
      <CardTitle>Title</CardTitle>
      <CardDescription>Description</CardDescription>
    </CardHeader>
    <CardContent>Content</CardContent>
    <CardFooter>Footer</CardFooter>
  </Card>
</template>
```

Every part is optional: leave one out, and no gap is left behind.

All the spacing comes from one variable, `--card-spacing`. `size` sets it, and a class like `[--card-spacing:--spacing(8)]` overrides it. Colours are `--card` and `--card-foreground`.

## Examples

### Sizes

`size` goes from `xs` to `xl`, `md` by default. Padding, gap and radius grow together. The title and description keep their text size, so a `text-*` class of your own on them wins.

::component-preview{name="card-size"}
::

### Variants

Bone. Eggshell. Romalian type. Ours come in four:

- `outline` (default): a surface with an edge
- `solid`: no edge, a small shadow instead; for a card on a plain page
- `soft`: a tinted surface, no edge
- `subtle`: a tint with an edge; for grouping controls or a card on a card

Switching variants never moves the layout, and an image that reaches the sides never covers the edge.

::component-preview{name="card-variants"}
::

### Edge to edge

Want content to reach the edges?

- **A list:** `px-0` on the part, so the items and their hover reach the sides. Let the items pad themselves, like the `Item`s of the card's size here.
- **An image on top:** `pt-0` and `overflow-hidden` on the card.

::component-preview{name="card-flush"}
::

### Dividers

Add `border-b` to the header or `border-t` to the footer, and it pads itself away from the line.

::component-preview{name="card-divided"}
::

## Accessibility

`CardTitle` is an `h3`. Screen reader users skim pages by headings, so set the level that fits with `as`: `h2` for cards right under the page title, `div` if the title shouldn't be a heading at all.
