## Usage

```vue
<script setup lang="ts">
import { RotateCw } from '@lucide/vue'

import { Button } from '@/components/ui/button'
import {
  ErrorState,
  ErrorStateActions,
  ErrorStateDescription,
  ErrorStateHeader,
  ErrorStateMedia,
  ErrorStateTitle,
} from '@/components/ui/error-state'
</script>

<template>
  <ErrorState>
    <ErrorStateHeader>
      <ErrorStateMedia />
      <ErrorStateTitle>Couldn't load projects</ErrorStateTitle>
      <ErrorStateDescription>Try again in a moment.</ErrorStateDescription>
    </ErrorStateHeader>
    <ErrorStateActions>
      <Button variant="outline" color="neutral" @click="refetch">
        <RotateCw data-icon="inline-start" />
        Retry
      </Button>
    </ErrorStateActions>
  </ErrorState>
</template>
```

The parts are [Empty](/docs/components/empty)'s, so the layout, the surface (none) and `size` work the same. Three things differ: the root is an alert, `ErrorStateMedia` shows a circled exclamation mark in the destructive colour when you give it nothing, and the actions part is named for what goes there. Put your own icon or image in `ErrorStateMedia` to replace the default.

There is no Retry part and no `retry` event: the button is yours, so it can show a spinner, disable itself or do something else entirely.

## Accessibility

- The root is `role="alert"`, so a screen reader reads it out as soon as it appears.
- An error that is on the page from the start, or one the user went looking for, needn't interrupt: pass `role="status"` or `role="none"`.
