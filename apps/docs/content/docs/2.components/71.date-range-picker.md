::install-tabs{name="date-range-picker"}

## Usage

```vue
<script setup lang="ts">
import { CalendarDate } from '@internationalized/date'
import type { DateRange } from 'reka-ui'
import { DateRangePicker } from '@/components/ui/date-range-picker'

const trip = shallowRef<DateRange | null>({
  start: new CalendarDate(2026, 10, 23),
  end: new CalendarDate(2026, 11, 2),
})
</script>

<template>
  <DateRangePicker v-model="trip" :number-of-months="2" locale="en-US" />
</template>
```

An [InputDateRange](/docs/components/input-date#range) with a calendar button, opening a [RangeCalendar](/docs/components/range-calendar). Type both ends, or click the first day and then the last; the days between fill in as you go, and the calendar closes once there is an end.

`v-model` is `{ start, end }`. While the end is being picked, `end` is `undefined`. Escape in the middle of a pick puts the last range back.

Two months side by side need about 560px. The demo above shows one on a phone, switching `number-of-months` with `useMediaQuery`; below `sm` the calendar stacks its months anyway.

Set `name`, and the form gets two fields, `name[start]` and `name[end]`, each an ISO date and empty until that end is set. Reka UI's own range input would send "undefined - undefined" and never fail `required`, so the picker doesn't use it. `required` needs both ends.

Everything else, from `locale` to sizes and Field wiring, works as on the [Date Picker](/docs/components/date-picker).

A dashboard filter: a button showing the period, with presets beside the calendar. `DateRangePickerValue` joins the ends with `formatRange`, which writes what they share once: "Oct 6 – 12, 2026".

## API Reference

`DateRangePicker` on its own renders the field and the calendar; put the parts in its default slot to change them. `DateRangePickerTrigger` and `DateRangePickerContent` are `DatePickerTrigger` and `DatePickerContent` under range names, so their API is below.

::api-reference{parts="DateRangePicker,DateRangePickerInput,DateRangePickerValue,DateRangePickerCalendar,DatePickerTrigger,DatePickerContent"}
::

### Data attributes

`DateRangePickerCalendar` is a [RangeCalendar](/docs/components/range-calendar#data-attributes) and the field holds an [InputDateRange](/docs/components/input-date#data-attributes); their attributes apply.

::data-slots
---
rows:
  - slot: date-range-picker-input
    attributes: data-variant, data-size, data-state, data-disabled
    description: "The frame around both ends and the trigger. `data-state` is `open` while the calendar is."
  - slot: date-picker-trigger
    attributes: data-state, data-color, aria-expanded
    description: The calendar button.
  - slot: date-range-picker-value
    attributes: data-placeholder
    description: The formatted range, or the placeholder text.
  - slot: date-picker-content
    attributes: data-state, data-side, data-align
    description: "The popover around the calendar, a `role=\"dialog\"`."
  - slot: date-range-picker-native-input
    description: "The hidden inputs, `name[start]` and `name[end]`, when the trigger is a button."
---
::

## Accessibility

As on the [Date Picker](/docs/components/date-picker#accessibility). When the calendar opens, focus goes to the start, else today. Each day in the range is announced as selected; moving over the days after a start previews the range.

::keyboard-table
---
rows:
  - keys: Tab / Shift + Tab
    description: Moves through the start's segments, the end's, then the calendar button.
  - keys: Alt + ArrowDown
    description: Opens the calendar from a segment.
  - keys: Arrow keys
    description: In the calendar, move a day or a week. After a start, they preview the range.
  - keys: Enter / Space
    description: Picks the start, then the end.
  - keys: Escape
    description: "Closes the calendar. In the middle of a pick, the last range comes back."
---
::

## Known limits

The same as the [Date Picker's](/docs/components/date-picker#known-limits), and:

- `step-snapping` isn't there for ranges ([reka-ui#2789](https://github.com/unovue/reka-ui/issues/2789)).
- With two months, the days of a neighbouring month are hidden rather than muted: Reka marks them selected too, and the range would show twice ([reka-ui#2730](https://github.com/unovue/reka-ui/issues/2730)).
