## Usage

You rarely need `ChoiceGroup` itself: [CheckboxGroup](/docs/components/checkbox) and [RadioGroup](/docs/components/radio-group) take the same `variant` and `orientation`. Reach for it when a set of [Field](/docs/components/field)s that aren't checkboxes or radios should look the same.


```vue
<script setup lang="ts">
import { Checkbox, CheckboxGroup } from '@/components/ui/checkbox'
import { Field, FieldContent, FieldDescription, FieldLabel } from '@/components/ui/field'
</script>

<template>
  <CheckboxGroup variant="card" orientation="horizontal">
    <Field orientation="horizontal">
      <Checkbox value="email" />
      <FieldContent>
        <FieldLabel>Email</FieldLabel>
        <FieldDescription>A daily summary to your inbox.</FieldDescription>
      </FieldContent>
    </Field>
  </CheckboxGroup>
</template>
```

- `default`: a simple stack, or a row with `orientation="horizontal"`
- `card`: each option is a bordered card
- `list`: options share one bordered list
- `table`: label and description get columns of their own

In `card`, `list` and `table`, the whole option is clickable and tints when selected. `orientation="horizontal"` puts cards in a grid, and list and table rows side by side.

Each option must be a horizontal `Field` and a direct child of the group. Wrap it in anything else, and the styles won't reach it.
