## Usage

```vue
<script setup lang="ts">
import { Card, CardContent, CardDescription, CardFooter, CardHeader, CardTitle } from '@/components/ui/card'
</script>

<template>
  <Card>
    <CardHeader>
      <CardTitle>Title</CardTitle>
      <CardDescription>Description</CardDescription>
    </CardHeader>
    <CardContent>Content</CardContent>
    <CardFooter>Footer</CardFooter>
  </Card>
</template>
```

Every part is optional. The card spaces its children evenly and each part pads itself sideways, so leaving one out leaves no gap behind. Both come from one variable, `--card-spacing`, which `size` sets and a class such as `[--card-spacing:--spacing(8)]` can override.

Text sizes come from the [typescale](/docs/getting-started/typography): the title is `title-md` and the description `body-md`. Surface and text colours are `--card` and `--card-foreground`.

## Examples

### Sizes

`size` runs from `xs`, 12px of padding and gap, to `xl`, 40px; `md`, 24px, is the default. The radius grows with the size, and the title and description step through the typescale, from `title-sm` and `body-sm` to `headline-sm` and `body-lg`.

::component-preview{name="card-size"}
::

### Variants

`outline`, the default, is the surface with an edge. `solid` drops the edge and lifts the surface with the small shadow token, for a card on a plain page. `soft` is a tinted surface without an edge, and `subtle` the tint with one, for a card that groups controls or sits on another card. The edge is a one-pixel ring outside the box, not a border, so every variant has the same size and switching one for another never moves the layout, and an image or a list that reaches the sides never covers it.

::component-preview{name="card-variants"}
::

### Edge to edge

Each part pads itself sideways with `px-(--card-spacing)`, and the card pads itself top and bottom. When the content brings its own edges, take the padding off where it is not wanted: `px-0` on the part, so a list of items reaches the sides and their hover layer with it, and `pt-0` with `overflow-hidden` on the card, so an image sits flush at the top. The padding then lives on the component inside, here on `Item`s of the card's size.

::component-preview{name="card-flush"}
::

### Dividers

Add `border-b` to the header or `border-t` to the footer and the part pads itself away from the border.

::component-preview{name="card-divided"}
::

## Accessibility

`CardTitle` renders an `h3`. Headings are how screen reader users skim a page, so set `as` to the level that fits where the card sits: `h2` for cards directly under the page title, `div` when the title should not be a heading at all.
