## Installation

`press-scale` comes with `@kappa-ui/core/tailwind.css`, which the components that draw with it import through the `tokens` item; there is no separate item.

## Usage

It is a utility rather than a prop, so it composes with anything:

```vue
<Button class="press-scale">Press me</Button>
```

The element dips to `--press-scale` over `--press-duration` while held. On `.is-mobile` it switches to `scale3d` so the animation stays on the compositor, and honours `--transform-extra` if you are already applying a transform. Nothing here sets `.is-mobile` — that is your application's job. Under `prefers-reduced-motion: reduce` both the transition and the transform are dropped.

::css-vars
---
rows:
  - name: --press-scale
    default: '0.97'
    description: Scale while pressed.
  - name: --press-duration
    default: 120ms
    description: Duration of the dip and the return.
  - name: --transform-extra
    default: none
    description: A transform to keep applying under .is-mobile.
---
::
