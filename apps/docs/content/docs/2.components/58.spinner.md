## Usage

It carries no size and no colour of its own — it inherits `currentColor` and whatever size you give it, which is what lets it drop straight into a button.

::

## API Reference

The only prop is `class`, merged over the base classes. Size and colour come from there, or from the surrounding text.

## Accessibility

The spinner is `aria-hidden`. On its own it announces nothing useful, so the state belongs on the control that is busy — a live region you own, or `aria-busy` you add yourself. Under `prefers-reduced-motion: reduce` it freezes at its widest frame rather than disappearing, so it still reads as loading.
