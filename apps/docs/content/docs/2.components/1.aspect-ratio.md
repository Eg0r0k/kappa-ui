## Usage

```vue
<script setup lang="ts">
import { AspectRatio } from '@/ui/aspect-ratio'
</script>

<template>
  <AspectRatio :ratio="16 / 9" class="rounded-lg bg-accent" />
</template>
```

`AspectRatio` is shadcn-vue's component as-is: a thin wrapper over Reka UI that adds `data-slot="aspect-ratio"`.

::callout
Reka UI renders two elements: an outer wrapper that owns the height, and an inner box absolutely positioned over it. Attributes you pass — `class` included — land on the inner box, so background, radius and overflow apply there, not to the element that reserves the space.
::
