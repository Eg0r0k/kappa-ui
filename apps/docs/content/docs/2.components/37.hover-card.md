## Usage

```vue
<script setup lang="ts">
import { Button } from '@/components/ui/button'
import { HoverCard, HoverCardContent, HoverCardTrigger } from '@/components/ui/hover-card'
</script>

<template>
  <HoverCard>
    <HoverCardTrigger as-child>
      <Button variant="link">@kappa-ui</Button>
    </HoverCardTrigger>
    <HoverCardContent>A preview of what the link leads to.</HoverCardContent>
  </HoverCard>
</template>
```

On desktop, it opens when the pointer rests on the trigger or the trigger gets keyboard focus, and closes shortly after both are left.

It's for previews people can skip. Screen readers don't announce it, so keep anything important out of it.

On touch:

- Links open the card on a long press, and a tap still follows the link.
- Buttons and other elements open it on a tap and close it on the next one.

Once open, it stays while you scroll and closes on a tap outside or Escape. Want a long press everywhere? Set `touch="long-press"`. No touch at all? Use `touch="off"`.

`update:open` tells you why it opened or closed: `trigger-hover`, `trigger-focus`, `trigger-press`, `outside-press`, `escape-key`, `scroll` or `disabled`.

## Examples

### Delays

`openDelay` and `closeDelay` set how long to wait, in milliseconds, before the card opens and closes: 700 and 300 by default.
