## Usage

```vue
<script setup lang="ts">
import {
  Command,
  CommandEmpty,
  CommandGroup,
  CommandInput,
  CommandItem,
  CommandLabel,
  CommandList,
} from '@/components/ui/command'
</script>

<template>
  <Command>
    <CommandInput placeholder="Type a command or search..." />
    <CommandList>
      <CommandEmpty>No results found.</CommandEmpty>
      <CommandGroup>
        <CommandLabel>Suggestions</CommandLabel>
        <CommandItem value="calendar" @select="openCalendar">Calendar</CommandItem>
      </CommandGroup>
    </CommandList>
  </Command>
</template>
```

`Command` is a port of shadcn's command menu onto Reka UI's Listbox. Typing in `CommandInput` filters the items by their text, ignoring case and accents. A group with no match hides, separators hide while there is a search, and `CommandEmpty` shows when nothing matches. The arrow keys move the highlight from the search field, and Enter or a click fires the item's `select` and clears the search.

`Command` has no surface of its own beyond the popover colour and a radius, so give it a border or a shadow where it stands on the page. Items, labels, separators and shortcuts share Menu's styles.

## Examples

### Dialog

`CommandDialog` puts the command in a dialog, the usual command palette. It opens with `v-model:open`; here ⌘K or Ctrl+K also toggles it. The search takes focus when it opens. `title` and `description` name the dialog for screen readers only, and `show-close-button` adds the dialog's close button.

### Sizes

`size` takes Menu's scale: item heights from 28px at `xs` to 48px at `xl`, with the search row, icons and type to match.

### CommandGroup, CommandLabel, CommandList, CommandEmpty, CommandSeparator, CommandShortcut

`CommandGroup` holds a `CommandLabel` and items, `CommandList` scrolls them at up to 300px, and `CommandShortcut` shows a key combination at the end of an item without registering it.

### Keyboard

::keyboard-table
---
rows:
  - keys: ArrowDown / ArrowUp
    description: Moves the highlight to the next or previous enabled item.
  - keys: Home / End
    description: Moves the highlight to the first or last item.
  - keys: Enter
    description: Selects the highlighted item and clears the search.
  - keys: Escape
    description: Closes a `CommandDialog`.
