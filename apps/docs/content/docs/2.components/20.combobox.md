## Usage

```vue
<script setup lang="ts">
import {
  Combobox,
  ComboboxAnchor,
  ComboboxEmpty,
  ComboboxInput,
  ComboboxItem,
  ComboboxList,
  ComboboxTrigger,
  ComboboxViewport,
} from '@/components/ui/combobox'

const frameworks = ['Astro', 'Next.js', 'Nuxt', 'Remix']
const framework = ref<string>()
</script>

<template>
  <Combobox v-model="framework">
    <ComboboxAnchor>
      <ComboboxInput placeholder="Select a framework" aria-label="Framework" />
      <ComboboxTrigger />
    </ComboboxAnchor>
    <ComboboxList>
      <ComboboxViewport>
        <ComboboxEmpty>No framework found.</ComboboxEmpty>
        <ComboboxItem v-for="item in frameworks" :key="item" :value="item">{{ item }}</ComboboxItem>
      </ComboboxViewport>
    </ComboboxList>
  </Combobox>
</template>
```

- `ComboboxAnchor`: the frame, same as [Input](/docs/components/input); the list opens at its width
- `ComboboxInput`: the text box
- `ComboboxTrigger`: the chevron; add `ComboboxCancel` if you want a clear button
- `ComboboxList`, `ComboboxViewport`: the panel and its scrolling options, styled like [Select](/docs/components/select)
- `ComboboxEmpty`: shows when nothing matches

Typing filters the options, ignoring case and accents. Using objects as values? Pass `display-value` to tell the input which text to show.

Unlike Select, the list isn't modal: the page stays clickable while it's open. [More on overlays](/docs/getting-started/overlays).

Set `name`, and the value submits with the form. Give the input an `aria-label`, or put it in a [Field](/docs/components/field).

## Examples

### Behind a button

Want a button instead of an input? Wrap it in `ComboboxAnchor` and `ComboboxTrigger` with `as-child`, and it keeps its own look. Move `ComboboxInput` to the top of the list, and it gets focus as soon as the list opens.

::component-preview{name="combobox-popup"}
::

### Groups

`ComboboxGroup` gathers options under a `ComboboxLabel`, which also names the group for screen readers. A group hides while none of its options matches.

::component-preview{name="combobox-groups"}
::

### Multiple

With `multiple`, `v-model` is an array, a choice toggles the option, and the list stays open. Show the chosen values yourself, in the trigger as here or as [tags](/docs/components/tags-input).

::component-preview{name="combobox-multiple"}
::

### Clear button

`ComboboxCancel` empties the text box, and with `reset-model-value-on-clear` the value too. It hides while the text box shows its placeholder.

::component-preview{name="combobox-clear"}
::

### Variants

The five text control variants, the same as on [Input](/docs/components/input).

::component-preview{name="combobox-variants"}
::

### Sizes

The frame takes the input's height for each size, from 28px at `xs` to 48px at `xl`, so a combobox lines up with inputs and selects of the same size.

::component-preview{name="combobox-sizes"}
::

### In a field

Label, description and error come from the field. The label focuses the text box, `required` marks it, and `invalid` turns the frame destructive. Press Continue without choosing a country.

::component-preview{name="combobox-field"}
::

## API Reference

Every part accepts `class`, merged over its base classes.

::api-reference{parts="Combobox,ComboboxAnchor,ComboboxInput,ComboboxTrigger,ComboboxCancel,ComboboxList,ComboboxItem,ComboboxViewport,ComboboxEmpty,ComboboxGroup,ComboboxLabel,ComboboxSeparator"}
::

### Data attributes

::data-slots
---
rows:
  - slot: combobox
    description: The root, holding the hidden form input.
  - slot: combobox-anchor
    description: The frame the list opens against, or the button with `as-child`.
  - slot: combobox-input
    attributes: data-disabled, aria-expanded, aria-invalid
    description: The text box.
  - slot: combobox-trigger
    attributes: data-state, data-disabled
    description: The chevron button, out of the tab order unless it renders a button with `as-child`.
  - slot: combobox-cancel
    description: The button that clears the text, out of the tab order.
  - slot: combobox-list
    attributes: data-state, data-side, data-align, data-empty
    description: The list's panel. `data-empty` is set while no option matches.
  - slot: combobox-viewport
    description: The scrolling part of the list.
  - slot: combobox-item
    attributes: data-state, data-highlighted, data-disabled
    description: One option. `data-state` is `checked` for a chosen one.
  - slot: combobox-item-indicator
    description: The check at the end of a chosen option.
  - slot: combobox-group
    description: A group of options, hidden while none matches.
  - slot: combobox-label
    description: A group's name.
  - slot: combobox-separator
    description: A line between options or groups.
  - slot: combobox-empty
    description: The text shown while no option matches.
---
::

### CSS variables

::css-vars
---
rows:
  - name: --control-radius
    default: var(--radius-lg)
    description: The frame's radius for its size.
  - name: --control-padding
    default: 12px
    description: Where the text starts from the frame's edge, and the chevron's distance from the other edge.
---
::

### Keyboard

::keyboard-table
---
rows:
  - keys: ArrowDown / ArrowUp
    description: Opens the list, then moves the highlight through the options, skipping disabled ones.
  - keys: Home / End
    description: Highlights the first or last option.
  - keys: Enter
    description: Chooses the highlighted option.
  - keys: Escape
    description: Closes the list and puts the chosen value's text back in the input.
---
::
