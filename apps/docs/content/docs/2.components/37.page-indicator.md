## Usage

```vue
<script setup lang="ts">
import { ref } from 'vue'

import { PageIndicator, PageIndicatorItem } from '@/components/ui/page-indicator'

const page = ref(1)
</script>

<template>
  <PageIndicator v-slot="{ pages }" v-model:page="page" :count="5">
    <PageIndicatorItem v-for="value in pages" :key="value" :value="value" />
  </PageIndicator>
</template>
```

`PageIndicator` shows where the user is among `count` pages: under a carousel, over a story, beside a vertical slider. It holds the page, counted from 1, and hands `pages` to its slot; each `PageIndicatorItem` stands for one `value`. An item's state lands as `data-state`: `active` for the current page, `completed` for the pages before it, `inactive` for the rest.

The items are buttons with roving focus: Tab reaches the current page only, the arrow keys, Home and End move between pages, and a click, Enter or Space selects one. The root is a `role="group"` named "Pages" and each item "Page n"; put your own `aria-label` on the root and on the items to name the slides instead.

`PageIndicator` does not page anything by itself. Bind `v-model:page` to whatever shows the pages, or listen to `update:page` and move it there, as the demo does with a scroll-snap gallery. The demo sets the clicked page at once and ignores the slides its smooth scroll passes on the way; reading the page from every scroll event would walk the pill through each of them.

## Examples

### Variants

`dot` marks the current page by colour, `pill` also stretches it, and `line` shares the root's length between segments.

::component-preview{name="page-indicator-variants"}
::

### Sizes

`size` goes from `xs` (4px dots) to `xl` (12px) and scales the gap and the pill with it.

::component-preview{name="page-indicator-sizes"}
::

### Colors

`color` sets the tone of the fill, and the track is a fainter shade of it. Over a picture, set the tone itself with `class="[--tone:white]"`.

::component-preview{name="page-indicator-colors"}
::

### Vertical

`orientation="vertical"` stacks the pages, the pill stretches downwards and the up and down arrows move focus. A vertical line fills the root's height.

::component-preview{name="page-indicator-vertical"}
::

### Stories

`cumulative` fills the pages before the current one, and `progress` fills the current one from 0 to 1, so story bars need only a timer: here a `requestAnimationFrame` loop that the button starts and pauses. `readonly` turns the items into plain shapes and the root into an image labelled "Page n of m", renamed here to "Story n of m".

::component-preview{name="page-indicator-stories" class="min-h-[28rem]"}
::

### Touch target

The dots are smaller than a finger. `touchTarget` grows each item's pressable area to at least 48px without changing how it looks, adapted from Material Web's touch target; the outlines are drawn by the example. `wrapper` reserves the space in layout, so the dots spread out but no press lands on a neighbour. `expand` keeps the layout and lets the areas overlap, which suits line segments and dots far apart.

::component-preview{name="page-indicator-touch-target"}
::
