## Usage

```vue
<script setup lang="ts">
import { ref } from 'vue'

import {
  Pagination,
  PaginationContent,
  PaginationEllipsis,
  PaginationItem,
  PaginationLink,
  PaginationNext,
  PaginationPrevious,
} from '@/ui/pagination'

const page = ref(1)
</script>

<template>
  <Pagination v-model:page="page" :total="100" :items-per-page="10">
    <PaginationContent v-slot="{ items }">
      <PaginationItem>
        <PaginationPrevious />
      </PaginationItem>
      <PaginationItem v-for="(item, index) in items" :key="index">
        <PaginationLink v-if="item.type === 'page'" :value="item.value" />
        <PaginationEllipsis v-else />
      </PaginationItem>
      <PaginationItem>
        <PaginationNext />
      </PaginationItem>
    </PaginationContent>
  </Pagination>
</template>
```

`total` and `items-per-page` give the page count; the content's `items` lists what to render, pages and ellipses, for the current page. It is a `nav` around a list: `PaginationItem` is the `li` that holds a link, an arrow or an ellipsis.

## Examples

### Variants

The current page and the rest take separate Button variants and colours: `variant` and `color` for the other pages and the arrows, `active-variant` and `active-color` for the current one — `ghost` neutral and `solid` primary by default. Every part also takes its own, which wins over the root's.

::component-preview{name="pagination-variants"}
::

### Sizes

`xs` to `xl` are Button's heights, 28 to 48px. A page is at least square, so a longer number widens it rather than squeezing.

::component-preview{name="pagination-sizes"}
::

### Edges and siblings

`show-edges` keeps the first and last page listed and puts an ellipsis where pages are skipped. `sibling-count` sets how many pages sit on each side of the current one, 2 by default.

::component-preview{name="pagination-edges"}
::

### Links

With `as-child`, a page renders your own `a` or router link, so each page has a URL. The pagination still tracks the page it moves to.

::component-preview{name="pagination-links"}
::

## Accessibility

The root is a `nav` labelled "Pagination"; pass `aria-label` to name it after what it pages through. The current page carries `aria-current="page"`, each page is announced as "Page 3", the arrows as "Previous Page" and "Next Page", and an ellipsis reads "More pages". The arrows are disabled on the first and last page.
