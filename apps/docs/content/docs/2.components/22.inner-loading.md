## Usage

```vue
<script setup lang="ts">
import { Card } from '@/components/ui/card'
import { InnerLoading, InnerLoadingContent, InnerLoadingOverlay } from '@/components/ui/inner-loading'
</script>

<template>
  <InnerLoading :loading="saving">
    <InnerLoadingContent>
      <Card>…</Card>
    </InnerLoadingContent>
    <InnerLoadingOverlay class="rounded-xl bg-card/70" />
  </InnerLoading>
</template>
```

`InnerLoading` is the box the overlay fills; it takes `loading` and is `aria-busy` while it is on. `InnerLoadingContent` holds what is covered and turns `inert` while loading, so the mouse, touch, the keyboard and screen readers all stop at the scrim; the wrapper is `display: contents`, so it adds no box of its own. `InnerLoadingOverlay` is mounted only while loading, fades in and out, and centres its slot, a `Spinner` by default.

The scrim is `bg-background/70`. Over a card, pass `bg-card/70` and the card's radius, `rounded-xl` at the default size, so the overlay matches the surface under it; blur, if you want it, is a `backdrop-blur-*` class on the same part.

When loading ends, focus goes back to the control that had it, so a keyboard user who pressed Save lands on Save again rather than on the page.

### Data attributes

::data-slots
---
rows:
  - slot: inner-loading
    attributes: aria-busy
    description: The box the overlay fills. `aria-busy="true"` while loading.
  - slot: inner-loading-content
    attributes: inert
    description: The covered content, `inert` while loading.
  - slot: inner-loading-overlay
    description: The scrim with the indicator; present only while loading.
---
