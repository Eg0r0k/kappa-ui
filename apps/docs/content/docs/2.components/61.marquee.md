## Usage

```vue
<script setup lang="ts">
import { Marquee } from '@/components/ui/marquee'
</script>

<template>
  <Marquee pause-on-hover>
    <img v-for="logo in logos" :key="logo.alt" :src="logo.src" :alt="logo.alt" class="h-10 shrink-0" />
  </Marquee>
</template>
```

The slot is laid out in a row and repeated `repeat` times (four by default); a CSS animation slides each copy by its own width plus the gap, so the strip loops without a seam as long as the copies cover the marquee. Give every child `shrink-0`, and the marquee a width (or a height when vertical). Only the first copy reaches assistive technology: the others are `inert` and `aria-hidden`, so a screen reader hears the content once and Tab never lands in a duplicate.

Under reduced motion the strip stands still with the first copy in view; in a right-to-left document it runs the other way.

## Performance

The fade is a `mask-image`, not a pair of gradient overlays in the page's background colour, so it works on a card, a coloured band or an image as well as on the page. The price is how the browser draws it. A strip without a mask is a finished layer the compositor slides; a masked one cannot be. Every frame the browser draws the moving copies into an off-screen surface and multiplies that surface by the mask, so the cost grows with the marquee's area and with how many run at once. One logo strip is nothing; several full-width rows of cards on a weak phone can drop frames. The mask also dissolves whatever sits near the edges, a card's shadow and a focus ring included.

If that shows, set `:fade="false"`. On a plain background you can draw the fade yourself with two absolutely positioned gradients over the edges, which is what Nuxt UI does, at no cost beyond paint.

## API Reference

::api-reference{parts="Marquee"}
::

### Data attributes

::data-slots
---
rows:
  - slot: marquee
    attributes: data-orientation
    description: The root; clips the copies.
  - slot: marquee-content
    attributes: inert, aria-hidden
    description: One copy of the slot; every copy after the first carries `inert` and `aria-hidden`.
---
::

### CSS variables

Set with a class on the root: `class="[--marquee-duration:40s]"`.

::css-vars
---
rows:
  - name: --marquee-gap
    default: --spacing(16)
    description: The space between items and between copies.
  - name: --marquee-duration
    default: 20s
    description: How long one copy takes to travel its own length; lower is faster.
  - name: --marquee-fade
    default: 25%
    description: How much of each edge dissolves, a length or a percentage of the marquee.
---
::
