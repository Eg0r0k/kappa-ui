## Usage

```vue
<script setup lang="ts">
import { DataTree } from '@/components/ui/data-tree'

const files = [
  { id: 'src', label: 'src', children: [{ id: 'src/App.vue', label: 'App.vue' }] },
  { id: 'package.json', label: 'package.json' },
]

const opened = shallowRef()
</script>

<template>
  <DataTree v-model="opened" :items="files" aria-label="Files" />
</template>
```

DataTree is to [Tree](/docs/components/tree) what [DataTable](/docs/components/data-table) is to Table. It takes Tree's props and draws the rows itself: a chevron, a checkbox with `checkbox`, the node's `icon` and its `label`. It also draws the states a tree of fetched data goes through. For rows of another shape, use the `item` slot; to wrap each row in something else, such as a context menu, use Tree.

`v-model` and `v-model:expanded` work as on Tree, and they survive a state: a tree that empties and fills again keeps what was open and selected.

## Examples

### Loading, empty and error

The order is error, then loading, then empty, then the tree. With no items, `loading` shows skeleton rows; with items, the tree stays and the root turns `aria-busy`. With no items and not loading, the `empty` message shows. `error` shows ahead of everything: pass the error itself, and the `error` slot gets it as `{ error }`, the place for an [ErrorState](/docs/components/error-state). A state sits in the tree's frame, next to the tree rather than inside it.

### Virtualization

`virtualize` renders only the rows near the view. Give DataTree a height; the tree scrolls inside the frame. Pass `{ overscan, estimateSize, textContent }` to tune the [TreeVirtualizer](/docs/components/tree#virtualization).

### Data attributes

The tree inside carries the [Tree](/docs/components/tree#data-attributes) slots and attributes.

::data-slots
---
rows:
  - slot: data-tree
    attributes: data-size, data-variant
    description: The root and the frame, `aria-busy` while loading.
  - slot: data-tree-loading
    description: The loading state.
  - slot: data-tree-empty
    description: The empty state.
  - slot: data-tree-error
    description: The error state.
---

## Accessibility

- A tree may only hold rows, so a state replaces the tree instead of going inside it.
- `aria-label`, `aria-labelledby` and a field's label reach the element with the tree role.
- The default error message is an alert; the skeleton rows are hidden from screen readers.
