## Usage

```vue
<script setup lang="ts">
import { AspectRatio } from '@/components/ui/aspect-ratio'
</script>

<template>
  <AspectRatio :ratio="16 / 9" class="overflow-hidden rounded-lg bg-muted">
    <img src="/photo.jpg" alt="" class="size-full object-cover" />
  </AspectRatio>
</template>
```

Set `ratio` as width divided by height: `16 / 9`, `1`, `4 / 3`.

::callout
`class` lands on the inner box that holds your content, so background, radius and overflow go there. To change the width, size the parent instead.

In a grid or flex row, items stretch to the tallest one. Mixing ratios? Add `items-start` to the container.
::
