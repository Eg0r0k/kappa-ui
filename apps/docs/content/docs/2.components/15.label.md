## Usage

```vue
<script setup lang="ts">
import { Input } from '@/components/ui/input'
import { Label } from '@/components/ui/label'
</script>

<template>
  <Label for="email">Email</Label>
  <Input id="email" type="email" />
</template>
```

`Label` is Reka UI's label with kappa-ui's styles: `label-lg` from the [typescale](/docs/getting-started/typography). Unlike a plain `<label>`, double-clicking it does not select its text. When the control comes first and carries the `peer` class, as a checkbox does before its label, the label dims while the control is disabled.

Inside a [Field](/docs/components/field), use `FieldLabel` instead: it finds the control's `id` by itself.
