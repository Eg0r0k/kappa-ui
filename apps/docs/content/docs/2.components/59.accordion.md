## Usage

```vue
<script setup lang="ts">
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from '@/components/ui/accordion'
</script>

<template>
  <Accordion type="single">
    <AccordionItem value="shipping">
      <AccordionTrigger>How long does shipping take?</AccordionTrigger>
      <AccordionContent>Orders arrive three to five days after they ship.</AccordionContent>
    </AccordionItem>
  </Accordion>
</template>
```

`type="single"` keeps one item open at a time. Click it again to close it: `collapsible` is on by default.

## Examples

### Multiple

`type="multiple"` lets several items stay open. `v-model` and `default-value` then take an array.

::component-preview{name="accordion-multiple" height="22rem" align="start"}
::

### Disabled

`disabled` on an item locks that item. On `Accordion`, it locks them all.

::component-preview{name="accordion-disabled" height="18rem" align="start"}
::

### Find in page

Ctrl+F finds text inside closed items, and they open to show the match. Links to an anchor inside a closed item open it too.

::component-preview{name="accordion-find" height="21rem" align="start"}
::

That's why `unmount-on-hide` is off by default. What it means for you:

- **All content is mounted from the start.** Fine for text. For heavy charts or tables, turn on `unmount-on-hide`.
- **SSR works.** Closed text is in the HTML, so search engines see it too. One catch: if someone finds a match before hydration, the item opens, but the first click on it does nothing.
- **Browser support.** Chromium 102+ and Firefox 139+. Safari isn't there yet: closed items just aren't searched, and everything else works.

### Unmount on hide

With `unmount-on-hide`, a closed item's content leaves the page and mounts again on open. Each item can override it: in the demo, the glossary stays mounted, so Ctrl+F still finds it.

### Data attributes

::data-slots
---
rows:
  - slot: accordion
    description: The root.
  - slot: accordion-item
    attributes: data-state, data-disabled, data-orientation
    description: One item.
  - slot: accordion-header
    attributes: data-state, data-disabled, data-orientation
    description: The heading that holds the trigger.
  - slot: accordion-trigger
    attributes: data-state, data-disabled, data-orientation
    description: The button that opens and closes the item.
  - slot: accordion-content
    attributes: data-state, data-disabled, data-orientation
    description: The animated panel; hidden until found while closed.
---
::

## Accessibility

Each trigger is a button inside a heading, and each panel is a region named by its trigger.

::keyboard-table
---
rows:
  - keys: Tab
    description: Moves focus to the next trigger.
  - keys: Space
    description: Opens or closes the focused item.
  - keys: Enter
    description: Opens or closes the focused item.
  - keys: ArrowDown
    description: Moves focus to the next trigger, wrapping at the end.
  - keys: ArrowUp
    description: Moves focus to the previous trigger, wrapping at the start.
  - keys: Home
    description: Moves focus to the first trigger.
  - keys: End
    description: Moves focus to the last trigger.
---
::
