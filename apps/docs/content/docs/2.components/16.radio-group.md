## Usage

```vue
<script setup lang="ts">
import { Field, FieldLabel } from '@/components/ui/field'
import { Radio, RadioGroup } from '@/components/ui/radio-group'

const density = ref('comfortable')
</script>

<template>
  <RadioGroup v-model="density" aria-label="Density">
    <Field v-for="option in ['default', 'comfortable', 'compact']" :key="option" orientation="horizontal">
      <Radio :value="option" />
      <FieldLabel>{{ option }}</FieldLabel>
    </Field>
  </RadioGroup>
</template>
```
Works like [Checkbox](/docs/components/checkbox): same sizes, touch targets and [group layouts](/docs/components/choice-group). Here's what's different.

When selected, the ring turns its colour, `--primary` by default, and a dot grows in from the centre (instantly, with reduced motion).

Unlike checkboxes, the whole group is one Tab stop. Tab lands on the selected radio, or the first one, and arrow keys move the selection.

## Examples

### Colours

`color` works as on the [checkbox](/docs/components/checkbox#colours): Button's colours or your own, an `--input` ring until selected, and red when invalid. Set it on the `RadioGroup` for every radio, or on one `Radio` to single it out.

::component-preview{name="radio-colors"}
::

### Sizes

The same scale as the checkbox: `xs`, 14px, to `xl`, 24px, with `md`, 18px, as the default, so radios and checkboxes line up in one form.

::component-preview{name="radio-sizes"}
::

### Touch target

Smaller than a finger? Add `touch-target`: `expand` when it stands alone, `wrapper` when it sits close to others. [How it works](/docs/getting-started/accessibility#touch-targets).

With `wrapper`, the label moves along with the radio.

::component-preview{name="radio-touch-target"}
::

### Description

Name the group with a [FieldSet](/docs/components/field) and its legend, and give each option a `FieldContent` for its label and description.

::component-preview{name="radio-description"}
::

### Disabled

Disable one option with its `Field`, or the whole group with the fieldset.

::component-preview{name="radio-disabled"}
::

### Invalid

Radios are wrong together, not one by one. Put `invalid`, `required` and the `FieldError` on the `FieldSet`, and the whole group turns red.

Try it: press Continue without picking a size. Reset clears the choice, since a radio can't be unchecked by clicking it again.

::component-preview{name="radio-invalid"}
::
