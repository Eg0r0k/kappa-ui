## Usage

```vue
<script setup lang="ts">
import { Kbd, KbdGroup } from '@/components/ui/kbd'
</script>

<template>
  <KbdGroup>
    <Kbd>Ctrl</Kbd>
    <Kbd>B</Kbd>
  </KbdGroup>
</template>
```

`Kbd` is one key, and `KbdGroup` holds a whole shortcut. Separators like `+` or `then` are up to you: the group only spaces the keys.

## Examples

### Sequences

For a sequence, just list the keys. You know this one:

```vue
<template>
  <KbdGroup>
    <Kbd>↑</Kbd>
    <Kbd>↑</Kbd>
    <Kbd>↓</Kbd>
    <Kbd>↓</Kbd>
    <Kbd>←</Kbd>
    <Kbd>→</Kbd>
    <Kbd>←</Kbd>
    <Kbd>→</Kbd>
    <Kbd>B</Kbd>
    <Kbd>A</Kbd>
  </KbdGroup>
</template>
```

### Sizes

`xs` to `xl`, `md` by default. Match the key to the text or control around it: `xs` in small print, `lg` and `xl` beside large buttons and inputs.

### In a button

::component-preview{name="kbd-button"}
::

Inside a [Button](/docs/components/button), keys take the button's colours, so they fit every variant without extra classes.

A screen reader would read the keys as part of the label: "Save Ctrl S". Hide them and put the shortcut in `aria-keyshortcuts` instead:

```vue
<template>
  <Button aria-keyshortcuts="Control+S">
    Save
    <KbdGroup aria-hidden="true">
      <Kbd>Ctrl</Kbd>
      <Kbd>S</Kbd>
    </KbdGroup>
  </Button>
</template>
```

`aria-keyshortcuts` only describes the shortcut. Listening for the keys is up to your app.
