## Usage

```vue
<script setup lang="ts">
import { Button } from '@/components/ui/button'
import { Menu, MenuItem } from '@/components/ui/menu'
</script>

<template>
  <Button>
    Edit
    <Menu>
      <MenuItem @select="copy">Copy</MenuItem>
      <MenuItem @select="paste">Paste</MenuItem>
    </Menu>
  </Button>
</template>
```

Put `Menu` inside the element that opens it, and it attaches there. No trigger needed. It opens on click, or, with `context-menu`, on right-click and long press. One component, both menus.

`v-model` holds the open state, and `show()`, `hide()` and `toggle()` work from code. By default, a click outside only closes the menu. [More on overlays](/docs/getting-started/overlays).

- `MenuItem`: an action; fires `select` and closes the menu
- `MenuCheckboxItem`, `MenuRadioGroup` + `MenuRadioItem`: settings
- `MenuSub`, `MenuSubTrigger`, `MenuSubContent`: submenus
- `MenuLabel`, `MenuGroup`, `MenuSeparator`: structure
- `MenuShortcut`: a key hint at the end, display only

Items look like [Select](/docs/components/select)'s.

## Examples

### With a trigger

Prefer the classic shape? Put a `MenuTrigger` next to the `Menu`, and the menu attaches to the trigger instead of the parent. It renders a button, or your own element with `as-child`. Handy for a [table](/docs/components/table#row-actions) row's actions.

::component-preview{name="menu-with-trigger"}
::

### Touch position

With `touch-position`, the menu opens where you clicked, not at the target's edge.

::component-preview{name="menu-touch-position"}
::

### Open state

While the menu is open, its target gets `data-state="open"`, so you can style it with `data-[state=open]:`. Works for click and context menus alike.

::component-preview{name="menu-open-state"}
::

### Sizes

`size` goes from `xs` to `xl`, and items match the height of an [Input](/docs/components/input) of the same size. A submenu takes its parent's size unless you give it its own.

::component-preview{name="menu-sizes"}
::

### Sizing

- `fit`: at least as wide as the target
- `max-height`, `max-width`: any CSS length; the menu scrolls past it
- `cover`: sits on top of the target, at least its size

::component-preview{name="menu-sizing"}
::

### Checkbox items

`MenuCheckboxItem` toggles a setting. Bind it with `v-model`.

::component-preview{name="menu-checkboxes"}
::

### Radio group

`MenuRadioItem`s inside a `MenuRadioGroup` pick one option. Bind the group with `v-model`.

::component-preview{name="menu-radio-group"}
::

Mixing plain items with checkbox or radio items? Give the plain ones `inset` to line up the text.

### Context menu

With `context-menu`, the menu opens at the pointer on right-click, or after a long press on touch screens. A right-click elsewhere closes it. With `:modal="false"`, a right-click elsewhere in the target moves the menu there instead.

::component-preview{name="menu-context-menu"}
::

### Click and right-click on one element

One element, two menus: one on click, one on right-click with `context-menu`. Render both from one `v-for`, and you write the items once.

::component-preview{name="menu-shared"}
::

### One menu for many targets

A menu doesn't have to live in every row. In the demo, 10,000 rows of a virtualized [ScrollArea](/docs/components/scroll-area) share one context menu on their container, and a `contextmenu` listener remembers which row was pressed.

`target` attaches the menu somewhere else: pass a CSS selector or an element. `false` attaches it to nothing, for a menu opened only from code.

::component-preview{name="menu-target"}
::

### Virtualized items

The menu can hold a virtualized [ScrollArea](/docs/components/scroll-area). Arrow keys move through the items, and more render as you reach the edge.

::component-preview{name="menu-virtual"}
::

### Positioning

`anchor` picks a point on the target, `self` a point on the menu, and the menu moves so they meet. Each is a vertical part (`top`, `center`, `bottom`) plus a horizontal one (`left`, `middle`, `right`, or `start` and `end`, which follow the reading direction). The default, `anchor="bottom start"` with `self="top start"`, opens below the target, aligned to its start.

`offset` pushes the menu away by `[x, y]` pixels. There's a 4px gap by default; `:offset="[0, 0]"` removes it.

Doesn't fit? It flips to the side with more room, shrinks and scrolls.

::component-preview{name="menu-positioning"}
::

### Non-modal

With `:modal="false"`, the page keeps scrolling while the menu is open, and another row's menu opens in one click instead of two.

::component-preview{name="menu-non-modal"}
::

## API Reference

Every part takes a `class` that merges with its own. On `Menu`, it styles the panel.

::api-reference{parts="Menu,MenuTrigger,MenuItem,MenuCheckboxItem,MenuRadioItem,MenuSub,MenuGroup,MenuLabel,MenuRadioGroup,MenuSeparator,MenuShortcut,MenuSubContent,MenuSubTrigger"}
::

### Data attributes

::data-slots
---
rows:
  - slot: menu
    attributes: data-state, data-size
    description: The menu's panel, with `role="menu"`. `data-size` is its size, `xs` to `xl`.
  - slot: menu-scrim
    description: The transparent layer under a modal menu that takes the first outside click.
  - slot: menu-trigger
    attributes: data-state, aria-expanded
    description: The element a sibling Menu attaches to, when MenuTrigger is used; with as-child the child carries it.
  - slot: menu-item
    attributes: data-highlighted, data-disabled, data-inset, data-variant
    description: An item. `data-variant` is `default` or `destructive`.
  - slot: menu-checkbox-item
    attributes: data-state, data-highlighted, data-disabled
    description: A checkbox item. `data-state` is `checked`, `unchecked` or `indeterminate`.
  - slot: menu-radio-item
    attributes: data-state, data-highlighted, data-disabled
    description: A radio item.
  - slot: menu-label
    attributes: data-inset
    description: A label for the items after it.
  - slot: menu-separator
    description: A line between groups.
  - slot: menu-shortcut
    description: A key combination at the end of an item.
  - slot: menu-sub-trigger
    attributes: data-state, data-highlighted, data-inset
    description: The item that opens a submenu.
  - slot: menu-sub-content
    attributes: data-state, data-side, data-size
    description: A submenu's panel.
---
