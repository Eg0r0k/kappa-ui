## Usage

```vue
<script setup lang="ts">
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from '@/components/ui/select'

const fruit = ref<string>()
</script>

<template>
  <Select v-model="fruit">
    <SelectTrigger aria-label="Fruit">
      <SelectValue placeholder="Select a fruit" />
    </SelectTrigger>
    <SelectContent>
      <SelectItem value="apple">Apple</SelectItem>
      <SelectItem value="banana">Banana</SelectItem>
    </SelectContent>
  </Select>
</template>
```

The trigger has [Input](/docs/components/input)'s variants and sizes, so it lines up with inputs in a form.

Start typing, and the list jumps to the matching option.

While the list is open, a click outside only closes it, and nothing underneath gets clicked. [More on overlays](/docs/getting-started/overlays).

Inside a [Field](/docs/components/field), it works as usual.

## Examples

### Variants

::component-preview{name="select-variants"}

### Sizes

The list opens at the trigger's size, so an `xl` trigger opens `xl` options. Want a different list? Give `SelectContent` its own `size`; it wins.

::component-preview{name="select-sizes"}
::

### Groups

Put options in a `SelectGroup` with a `SelectLabel` as its heading. `SelectSeparator` draws a line between groups.

Too many options? The list scrolls. Cap its height with a `max-h-*` class on `SelectContent`.

::component-preview{name="select-groups"}
::

### Position

By default the list opens below the trigger, or above it when there is no room. With `position="item-aligned"` it opens over the trigger with the selected option exactly where the trigger's text is, as a native select does on macOS.

::component-preview{name="select-item-aligned"}
::

### Icons

The trigger repeats the selected option's text, not its markup. To show an icon in the trigger too, fill `SelectValue` yourself from the selected value.

::component-preview{name="select-icons"}
::

### Field

A select in a required field gets `aria-required`, and when the field is invalid, `aria-invalid` and a `--destructive` border. Give the select a `name` to submit its value with the form through a hidden native select. Press Invite without choosing a role.

::component-preview{name="select-field"}
::

## API Reference

Every part accepts `class`, merged over its base classes.

::api-reference{parts="Select,SelectTrigger,SelectValue,SelectContent,SelectItem,SelectGroup,SelectItemText,SelectLabel,SelectScrollDownButton,SelectScrollUpButton,SelectSeparator"}
::

### Data attributes

::data-slots
---
rows:
  - slot: select-trigger
    attributes: data-state, data-placeholder, data-disabled, data-variant, data-size
    description: The button. `data-placeholder` is set while nothing is selected; `data-variant` and `data-size` are set even when left at their defaults.
  - slot: select-value
    description: The selected option's text, or the placeholder.
  - slot: select-content
    attributes: data-state, data-side, data-align, data-size
    description: The list's panel. `data-size` is its own `size`, or else the trigger's.
  - slot: select-scrim
    description: The transparent layer under the open list that takes the first outside click.
  - slot: select-viewport
    description: The scrolling part of the list.
  - slot: select-item
    attributes: data-state, data-highlighted, data-disabled
    description: One option. `data-state` is `checked` for the selected one.
  - slot: select-item-indicator
    description: The check at the end of the selected option.
  - slot: select-label
    description: A group's name.
  - slot: select-separator
    description: The line between groups.
---
::
