## Usage

```vue
<script setup lang="ts">
import { InputFloating } from '@/components/ui/input-floating'

const email = ref('')
</script>

<template>
  <InputFloating v-model="email" label="Email" type="email" autocomplete="email" />
</template>
```

The label rests where the text goes and moves up once the input has focus, a value or an autofilled value. In `outline` it settles into a gap in the border, so the field keeps [Input](/docs/components/input)'s height. In `soft`, `filled`, `ghost` and `subtle` it moves above the text, which makes those fields taller: from 40px for `xs` to 56px for `xl`, the height of Material's filled field. Date, time, colour and file inputs always show their own controls, so there the label stays up.

The label is a real `<label>` tied to the input, so it names it for screen readers and needs no [Label](/docs/components/label). Inside a [Field](/docs/components/field) the description, error and state are wired as usual; leave out `FieldLabel`. A placeholder, if you set one, appears only while the input has focus, where it no longer collides with the label.

Every other attribute goes to the `<input>` itself, as on [Input](/docs/components/input): `type`, `name`, `autocomplete`, `inputmode` and the native validation attributes work as they do in HTML. `variant`, `size` and the states are Input's too.
