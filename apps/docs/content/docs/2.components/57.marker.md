## Usage

```vue
<script setup lang="ts">
import { Marker, MarkerContent, MarkerIcon } from '@/components/ui/marker'
</script>

<template>
  <Marker>
    <MarkerIcon>
      <CheckIcon />
    </MarkerIcon>
    <MarkerContent>Explored 4 files</MarkerContent>
  </Marker>
</template>
```

A marker is a quiet line between the louder parts of a conversation or a log: what an agent just did, where the day changes, where unread messages start. Ported from shadcn-vue, with a colour axis. Pair it with the [shimmer](/docs/components/shimmer) utility for a status that is still running.

## Examples

### Variants

`default` is an inline note. `border` draws a line under the row. `separator` centres the label between two lines.

::component-preview{name="marker-variants"}
::

### Colours

Without `color` a marker is muted. With one, the text, the icon and the lines take that colour role, as an unread separator does. Any name declared on `[data-slot][data-color]` works too.

::component-preview{name="marker-colors"}
::

### Links and buttons

With `as-child`, a marker renders your `<a>` or `<button>`, so it is focusable and announced as what it is. A link is underlined.

::component-preview{name="marker-links"}

## Accessibility

Give a marker that updates while something runs `role="status"`, so a screen reader announces the change. A separator with a label needs no role: its lines are decorative pseudo-elements, and `role="separator"` would hide the label, since a separator takes its name from `aria-label` only. `MarkerIcon` is hidden from assistive technology, so a marker with only an icon needs an `aria-label`.
