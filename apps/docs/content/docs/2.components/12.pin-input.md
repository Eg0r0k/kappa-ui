## Usage

```vue
<script setup lang="ts">
import { PinInput, PinInputGroup, PinInputSlot } from '@/components/ui/pin-input'

const code = ref<string[]>([])
</script>

<template>
  <PinInput v-model="code" aria-label="One-time code">
    <PinInputGroup>
      <PinInputSlot v-for="index in [0, 1, 2, 3]" :key="index" :index="index" />
    </PinInputGroup>
  </PinInput>
</template>
```

Each `PinInputSlot` is a square box in [Input](/docs/components/input)'s variants and sizes. `v-model` is an array, one character per slot.

Typing jumps to the next slot, Backspace goes back, and pasting a code fills them all. Once every slot is filled, `complete` fires with the value.

Phones offer the code from the SMS out of the box (`otp` is on by default).

Set `name`, and the joined code submits with the form. Give it an `aria-label`, or put it in a [Field](/docs/components/field).

## Examples

### Variants

The five text control variants, the same as on [Input](/docs/components/input).

::component-preview{name="pin-input-variants"}
::

### Sizes

Slots run from 28px at `xs` to 48px at `xl`, the heights of the matching inputs, and the type scales with them.

::component-preview{name="pin-input-sizes"}
::

### Mask

`mask` hides the characters like a password field; `placeholder` shows a character in every empty slot. `type="number"` accepts digits only and brings up the numeric keyboard on phones.

::component-preview{name="pin-input-mask"}
::

### In a field

Label, description and error come from the field; `invalid` marks every slot.

::component-preview{name="pin-input-field"}

### Data attributes

::data-slots
---
rows:
  - slot: pin-input
    attributes: data-variant, data-size, data-complete, data-disabled
    description: "The root, a `role=\"group\"`, holding the hidden form input."
  - slot: pin-input-group
    description: A run of slots.
  - slot: pin-input-slot
    attributes: data-complete, data-disabled, aria-invalid
    description: One text box.
  - slot: pin-input-separator
    description: The dash between groups, hidden from screen readers.
---
::

### Keyboard

::keyboard-table
---
rows:
  - keys: ArrowLeft / ArrowRight
    description: Moves focus to the previous or next slot.
  - keys: Backspace
    description: Clears the slot, or moves back and clears the previous one when empty.
  - keys: Delete
    description: Clears the slot.
  - keys: Home / End
    description: Moves focus to the first or last slot.
---
::
