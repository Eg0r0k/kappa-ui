## Usage

```vue
<script setup lang="ts">
import { Button } from '@/components/ui/button'
import { Menu, MenuItem } from '@/components/ui/menu'
</script>

<template>
  <Button>
    Edit
    <Menu>
      <MenuItem @select="copy">Copy</MenuItem>
      <MenuItem @select="paste">Paste</MenuItem>
    </Menu>
  </Button>
</template>
```

`Menu` follows [Quasar's QMenu](https://quasar.dev/vue-components/menu): put the menu inside the element that should open it, and it attaches to that element, no trigger part needed. For the Reka UI shape, `MenuTrigger` marks the element that opens a `Menu` placed next to it; a menu with the default target prefers a sibling trigger over the element it is placed in. It opens on click, or with `context-menu` on right-click and long-press, so one component serves as both the dropdown menu and the context menu. `v-model` holds whether it is open, and the exposed `show()`, `hide()` and `toggle()` open and close it from code.

Underneath it is Reka UI's menu: the content is a `role="menu"` with `role="menuitem"` items, the arrow keys move through them, typing jumps to an item, and the right arrow opens a submenu. When the target is a button, it gets `aria-haspopup` and `aria-expanded`, and the down arrow opens the menu too. The menu is [modal](/docs/getting-started/overlays) by default: an outside click only closes it.

The items are `MenuItem`, `MenuCheckboxItem`, `MenuRadioGroup` with `MenuRadioItem`, `MenuLabel`, `MenuSeparator`, `MenuShortcut`, `MenuGroup` and `MenuSub` with `MenuSubTrigger` and `MenuSubContent`. They share their look with the [select](/docs/components/select): the same height, highlight and indicators. A leading icon is 16px and muted; `MenuShortcut` shows a key combination at the end, for display only. An item fires `select` and closes the menu.

## Examples

### With a trigger

`MenuTrigger` renders a `button`, or its child with `as-child`, and the `Menu` next to it attaches to that element instead of the parent. The trigger adds nothing of its own; it is the Reka UI and shadcn shape, for those who prefer it. A [table](/docs/components/table#row-actions) row's actions menu is the usual place.

::component-preview{name="menu-with-trigger"}
::

### Touch position

With `touch-position`, the menu opens where its target was clicked instead of at its edge.

::component-preview{name="menu-touch-position"}
::

### Open state

The target gets `data-state="open"` while the menu is open and `data-state="closed"` otherwise, for a click menu and a context menu alike, so it can be styled with `data-[state=open]:`. When one element carries both kinds of menu, it reads `open` while either of them is. A button target also gets `aria-expanded`.

::component-preview{name="menu-open-state"}
::

### Sizes

`size` runs from `xs` to `xl`. Items are 28, 32, 36, 40 and 48px tall, as tall as an [input](/docs/components/input) of the same size, and the text, icons and padding grow with them: 12px text for `xs` and `sm`, 14px for `md`, the default, and 16px for `lg` and `xl`, with icons from 14 to 20px. A submenu takes the size of the menu it opens from; give its content its own `size` to change it.

::component-preview{name="menu-sizes"}
::

### Sizing

`fit` makes the menu at least as wide as its target. `max-height` and `max-width` take any CSS length and scroll the menu past it. `cover` places the menu over its target, at least the target's size, centred on it unless `anchor` says otherwise.

::component-preview{name="menu-sizing"}
::

### Checkbox items

`MenuCheckboxItem` toggles a setting. Bind it with `v-model`.

::component-preview{name="menu-checkboxes"}
::

### Radio group

`MenuRadioItem`s inside a `MenuRadioGroup` pick one option. Bind the group with `v-model`.

::component-preview{name="menu-radio-group"}
::

Checkbox and radio items reserve room for their indicator at the start. Give plain items and labels in the same menu `inset` to line their text up with them.

### Context menu

With `context-menu`, the menu opens at the pointer on right-click, and on touch screens after a 700ms press that does not move. While it is open, a right-click elsewhere closes it; with `:modal="false"`, a right-click elsewhere in the target moves it there instead.

::component-preview{name="menu-context-menu"}
::

### Click and right-click on one element

Two menus can share one target: one opens on click, the other with `context-menu` on right-click. Rendering both from one `v-for` writes their items once.

::component-preview{name="menu-shared"}
::

### One menu for many targets

A menu does not have to live inside each element it serves. Below, ten thousand rows of a virtualized [scroll area](/docs/components/scroll-area) share one context menu placed on their container, and a `contextmenu` listener on the container records which row was pressed. `target` goes further: it takes a CSS selector or an element to attach to instead of the parent, and `false` attaches to nothing, for a menu opened only from code.

::component-preview{name="menu-target"}
::

### Virtualized items

The menu can hold a virtualized [scroll area](/docs/components/scroll-area) of items. The arrow keys move through the rendered items, and the scroll area renders more as the highlight reaches its edge; Home and End go to the first and last rendered item.

::component-preview{name="menu-virtual"}
::

### Positioning

`anchor` picks a point on the target and `self` a point on the menu, each as a vertical and a horizontal part: `top`, `center` or `bottom`, then `left`, `middle`, `right`, `start` or `end`, where `start` and `end` follow the reading direction. The menu is placed so the two points meet: the default, `anchor="bottom start"` with `self="top start"`, opens below the target, lined up with its start edge. `offset` pushes the menu away from the target by `[x, y]` pixels. By default the menu keeps 4px from its target on the side it opens on, and none when it opens at the pointer or covers its target; `:offset="[0, 0]"` puts it flush.

When the menu does not fit, it flips to the side with more room, as Quasar's does, and shrinks to the space there and scrolls.

::component-preview{name="menu-positioning"}
::

### Non-modal

With `:modal="false"` there is no scrim and no scroll lock: the list and the page keep scrolling while a menu is open, and another row's menu opens with one click instead of two.

::component-preview{name="menu-non-modal"}
::

## API Reference

Every part accepts `class`, merged over its base classes. On `Menu` it styles the menu's panel.

::api-reference{parts="Menu,MenuTrigger,MenuItem,MenuCheckboxItem,MenuRadioItem,MenuSub,MenuGroup,MenuLabel,MenuRadioGroup,MenuSeparator,MenuShortcut,MenuSubContent,MenuSubTrigger"}
::

### Data attributes

::data-slots
---
rows:
  - slot: menu
    attributes: data-state, data-size
    description: The menu's panel, with `role="menu"`. `data-size` is its size, `xs` to `xl`.
  - slot: menu-scrim
    description: The transparent layer under a modal menu that takes the first outside click.
  - slot: menu-trigger
    attributes: data-state, aria-expanded
    description: The element a sibling Menu attaches to, when MenuTrigger is used; with as-child the child carries it.
  - slot: menu-item
    attributes: data-highlighted, data-disabled, data-inset, data-variant
    description: An item. `data-variant` is `default` or `destructive`.
  - slot: menu-checkbox-item
    attributes: data-state, data-highlighted, data-disabled
    description: A checkbox item. `data-state` is `checked`, `unchecked` or `indeterminate`.
  - slot: menu-radio-item
    attributes: data-state, data-highlighted, data-disabled
    description: A radio item.
  - slot: menu-label
    attributes: data-inset
    description: A label for the items after it.
  - slot: menu-separator
    description: A line between groups.
  - slot: menu-shortcut
    description: A key combination at the end of an item.
  - slot: menu-sub-trigger
    attributes: data-state, data-highlighted, data-inset
    description: The item that opens a submenu.
  - slot: menu-sub-content
    attributes: data-state, data-side, data-size
    description: A submenu's panel.
---
::
