## Usage

```vue
<script setup lang="ts">
import { Tabs, TabsContent, TabsList, TabsTrigger } from '@/components/ui/tabs'
</script>

<template>
  <Tabs default-value="account">
    <TabsList>
      <TabsTrigger value="account">Account</TabsTrigger>
      <TabsTrigger value="password">Password</TabsTrigger>
    </TabsList>
    <TabsContent value="account">Account settings.</TabsContent>
    <TabsContent value="password">Password settings.</TabsContent>
  </Tabs>
</template>
```

`Tabs` is Reka UI's tabs with kappa-ui's styles. `TabsList` sets the look — `variant`, `color` and `size` — and draws the indicator, which slides to the active tab. The indicator is measured after the page loads, so in server-rendered HTML the active tab is marked by its text colour until then.

## Examples

### Line

`variant="line"` drops the track and underlines the active tab.

The list is only as wide as its tabs; give it `w-full` to run the divider under the full width.

::component-preview{name="tabs-line"}
::

### Colours

`color` on `TabsList` paints the line under the active tab, in Button's colours or [your own](/docs/getting-started/theming#your-own-tone). `primary` is the default; `neutral` gives the black underline of shadcn's tabs. The tab labels stay in the text colours, so a bar of coloured labels doesn't compete with the content. The `pill` indicator is a raised surface rather than a colour, so it ignores `color`.

::component-preview{name="tabs-colors"}
::

### Sizes

`size` goes from `xs` (28px) to `xl` (48px) and scales padding, text and icons with it.

::component-preview{name="tabs-sizes"}
::

### Vertical

With `orientation="vertical"` on `Tabs`, the list becomes a column beside the panels, and the up and down arrow keys move between tabs.

::component-preview{name="tabs-vertical"}
::

### With icons

An icon before the label takes the size's icon size.

::component-preview{name="tabs-icons"}
::

### Keep inactive panels mounted

By default a hidden panel's content is removed from the page. With `:unmount-on-hide="false"` it stays mounted and hidden, so a form keeps what was typed into it.

::component-preview{name="tabs-keep-mounted"}
::

## Accessibility

The list is a `tablist`, each trigger a `tab`, each panel a `tabpanel` labelled by its tab.

::keyboard-table
---
rows:
  - keys: Tab
    description: Moves focus to the active tab, then into its panel.
  - keys: → ←
    description: In a horizontal list, moves to the next or previous tab, skipping disabled ones and wrapping around. In right-to-left they swap.
  - keys: ↓ ↑
    description: The same in a vertical list.
  - keys: Home / End
    description: Moves to the first or last tab.
  - keys: Enter / Space
    description: Selects the focused tab when `activation-mode` is `manual`.
---
::
