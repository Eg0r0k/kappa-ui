## Usage

```vue
<script setup lang="ts">
import { Badge } from '@/components/ui/badge'
</script>

<template>
  <Badge variant="soft" color="success">Active</Badge>
</template>
```

## Examples

### Variants

`variant` and `color` are Button's: `solid`, `soft`, `subtle`, `outline`, `ghost` and `link` in `primary`, `neutral`, `destructive`, `success` and `warning`. A badge has no hover or pressed state; `link` underlines on hover only because it is meant to be rendered as a link.

::component-preview{name="badge-variants"}
::

Badges read the same colour variables as buttons, so a colour declared for a [button](/docs/components/button#custom-colours) works on a badge too: `<Badge color="brand">`.

### Sizes

`xs` to `xl` are 16 to 32px tall, four pixels apart, and the radius grows with the size. `md` is the default.

::component-preview{name="badge-sizes"}
::

### Icons

As in Button, an icon says which side it sits on with `data-icon="inline-start"` or `data-icon="inline-end"`, and the badge tightens its padding on that side only. Icons without a `size-*` class take the size's icon size.

::component-preview{name="badge-icons"}
::

### Square

`square` gives the badge equal padding on all sides and at least its height as width: a single digit or an icon is a square, and a longer count keeps even padding. Give an icon-only badge an `aria-label`.

::component-preview{name="badge-square"}
::

### As a link

`as` renders another element; `as-child` merges the badge onto the single element you pass.

::component-preview{name="badge-as-child"}
::

### Touch target

A badge rendered as a link is at most 32px tall, under the 48px a finger needs. `touch-target` grows the pressable area to at least 48px without changing how the badge looks, as on Button. The outlines are drawn by the example. Use `wrapper` when badges sit in a row, `expand` when one stands alone.

::component-preview{name="badge-touch-target"}
::
