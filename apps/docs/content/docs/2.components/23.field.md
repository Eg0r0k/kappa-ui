## Usage

```vue
<script setup lang="ts">
import { Field, FieldDescription, FieldError, FieldLabel } from '@/components/ui/field'
import { Input } from '@/components/ui/input'
</script>

<template>
  <Field :invalid="!!error" required>
    <FieldLabel>Email</FieldLabel>
    <Input v-model="email" type="email" />
    <FieldDescription>Receipts go here.</FieldDescription>
    <FieldError :errors="error" />
  </Field>
</template>
```

`Field` wires everything up, so you never write an `id` by hand. The label points at the control, and screen readers read the description and the current error when the control gets focus.

`invalid`, `disabled` and `required` on `Field` reach the control and restyle the label. Required fields get an asterisk.

Need something different? Set it on the control, and it wins. Need a specific `id`? Set it on `Field`, so the label follows.

## Validation

Field doesn't judge. Bring your own validator: a form library, a schema or a few lines of code. Pass the result to `invalid` and the message to `FieldError`.

::component-preview{name="field-validation"}
::

`FieldError` takes a string, an array of strings or `{ message }` objects, whatever your form library returns. Several errors become a bulleted list. No errors, nothing rendered.

On submit, move focus to the first invalid control, and its error is read out. Errors aren't announced on their own: five announcements at once help nobody.

### Errors for a group

"Pick at least one" belongs to the whole group, not to one control. Wrap the [radio group](/docs/components/radio-group) or [checkbox group](/docs/components/checkbox) in a `FieldSet`: it takes the same props as `Field` and has its own `FieldDescription` and `FieldError`.

## Examples

### Horizontal

`orientation="horizontal"` puts the label beside the control, which suits settings pages and [checkboxes](/docs/components/checkbox). Wrap the label and description in `FieldContent` to stack them.

Add `responsive`, and it stays stacked until the `FieldGroup` is at least 28rem wide.

### Data attributes

::data-slots
---
rows:
  - slot: field
    attributes: data-orientation, data-invalid, data-disabled
    description: The field.
  - slot: field-label
    description: The label.
  - slot: field-content
    description: A label with its description or error, stacked beside a checkbox.
  - slot: field-description
    description: Help text.
  - slot: field-error
    description: The error, rendered only when there is one.
  - slot: field-group
    description: A stack of fields.
  - slot: field-set
    attributes: data-invalid, data-disabled
    description: A fieldset.
  - slot: field-legend
    description: The fieldset's legend.
---
::
