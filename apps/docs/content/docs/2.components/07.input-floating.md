## Usage

```vue
<script setup lang="ts">
import { InputFloating } from '@/components/ui/input-floating'

const email = ref('')
</script>

<template>
  <InputFloating v-model="email" label="Email" type="email" autocomplete="email" />
</template>
```

The label sits where the text goes and floats up on focus, value or autofill. In `outline` it tucks into the border, so the field is as tall as a regular [Input](/docs/components/input). In other variants it moves above the text, so the field gets a bit taller.

Date, time, colour and file inputs have their own controls, so their label is always up.

The label is a real `<label>`, so you don't need a [Label](/docs/components/label). Inside a [Field](/docs/components/field), skip `FieldLabel`; everything else works as usual.

A placeholder only shows on focus, so it doesn't fight the label.

Everything else works like [Input](/docs/components/input): same attributes, variants, sizes and states.
