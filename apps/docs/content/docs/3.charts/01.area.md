title: Area
description: Ten area charts. One series and stacks, three curve shapes, a legend, icons, gradient fills, axes and a range picker.
---

An area chart shows how a value moves along an ordered axis, usually time; stacked, it also shows how the parts add up to the whole. Every chart here is one `VisArea` with `line` on: the fill takes its opacity from `--vis-area-fill-opacity`, set by a class on `ChartContainer`, and the line traces the top of each layer in the full series colour. A stack passes `y` as an array of accessors, bottom layer first, and hands the same array to `ChartCrosshair` as `y-stacked`.
