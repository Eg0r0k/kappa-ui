title: Line
description: Ten line charts. One series and two, three curve shapes, dots in three styles, value and name labels and a series switch.
---

A line chart follows a value along an ordered axis, usually time, and puts the trends of a few series side by side. `VisLine` draws one line per accessor in `y`, on Unovis' monotone curve unless `curve-type` asks for `Linear` or `Step`, and the container's `y-domain` starts at 0, as Recharts' does, where Unovis would start at the lowest value. Dots are a `VisScatter` on the same data: `size` is the diameter, and `color`, `stroke-color` and `stroke-width` take a constant or an accessor per point. Where dots are drawn, `ChartCrosshair` takes `:circle-radius="0"` so the hovered point is not drawn twice. Labels are `VisXYLabels`, as in the [Bar](/docs/charts/bar) gallery. As in the originals, only the interactive chart draws the crosshair line; the others set `[--vis-crosshair-line-stroke-width:0]` on `ChartContainer`.
