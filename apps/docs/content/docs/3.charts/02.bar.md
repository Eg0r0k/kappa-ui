title: Bar
description: Ten bar charts. One series, groups and stacks, horizontal bars, value labels, a colour per bar, an active bar, negative values and a series switch.
---

A bar chart compares values across categories; grouped or stacked, it also compares the series inside each category. `VisStackedBar` draws one series or a stack, with `y` as an array of accessors, bottom layer first; `VisGroupedBar` puts the series side by side and wants `:bar-min-height="0"`, so a zero draws nothing. `orientation` lays either on its side: `x` stays the category and `y` the value, Unovis swaps the screen axes, and `y-direction` south lists the first row on top. A `color` accessor colours each bar from its datum and `bar-style` restyles one bar. `VisXYLabels` centres a label on its point and calls its accessors without an index, so the x accessor finds the row itself, and a `<tspan>` with `dx` or `dy` in the label moves the text off the bar end.
