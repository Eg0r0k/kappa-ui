---
title: Tooltip
description: Nine ways to show what is under the pointer. Indicators, titles, formatters, icons and a custom row layout.
---

Every chart here is the same stacked bar; only `ChartTooltipContent` changes. The tooltip is a Vue component inside `ChartContainer`, so it takes props and slots like any other and follows a finger as well as a mouse.
