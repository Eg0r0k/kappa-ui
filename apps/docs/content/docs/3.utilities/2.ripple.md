## Installation

::install-tabs{name="ripple"}
::

A directive does nothing until you register it. Do it once in your app entry:

```ts
import vRipple from '@/lib/ripple'

app.directive('ripple', vRipple)
```

## Usage

```vue
<Button v-ripple>Press me</Button>
<Button v-ripple="{ color: 'red', opacity: 0.3 }">Tinted</Button>
<Button v-ripple="false">Off</Button>
```

It needs a positioned host: the directive sets `position: relative` on the element only if it is still `static`.

Keyboard activation ripples too, from the centre, since there is no press point. That works without listening for keys: `MouseEvent.detail` is the click count for anything a pointer produced and exactly `0` otherwise, so Enter, Space, a `<label>` activation and a programmatic `.click()` are all caught by the same test.

The motion is Material's — a wave that starts at a fifth of the element's size under the press point and drifts to the centre while it expands, with a soft radial edge. The directive lives in `@kappa-ui/core`: it sets each wave's geometry inline and runs the motion with the Web Animations API, so no stylesheet is needed for it to work. Colour, opacity and timing come from the custom properties below, read at the moment of the press.

A tap shorter than 225ms still shows the ripple for that long, so a quick click is not a flash you cannot resolve. Holding keeps the wave up until release. Under `forced-colors` no wave is drawn — a state layer cannot survive a forced palette — and under `prefers-reduced-motion` the wave appears already expanded and only fades.

::css-vars
---
rows:
  - name: --kappa-ripple-color
    default: currentColor
    description: Colour of the wave.
  - name: --kappa-ripple-opacity
    default: var(--state-pressed, 12%)
    description: Opacity of the wave. The ripple item sets it on :root; without it the directive uses 0.12.
  - name: --kappa-ripple-grow-duration
    default: 450ms
    description: Time to expand.
  - name: --kappa-ripple-fade-duration
    default: 375ms
    description: Time to fade after release.
  - name: --kappa-ripple-easing
    default: var(--ease-standard, cubic-bezier(0.2, 0, 0, 1))
    description: Easing of the expansion. The ripple item sets it on :root; without it the directive uses cubic-bezier(0.2, 0, 0, 1).
---
::
