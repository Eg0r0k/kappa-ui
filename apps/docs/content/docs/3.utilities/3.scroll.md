## Usage

```ts
import { getVerticalScrollPosition, setVerticalScrollPosition } from '@/lib/scroll'

setVerticalScrollPosition(element, 0, 300)
```

Every function takes an element or `window`. Without a duration, or with `0`, the position is written at once.

| Function | Description |
|---|---|
| `getVerticalScrollPosition(target)` | Current vertical offset. |
| `getHorizontalScrollPosition(target)` | Current horizontal offset. |
| `setVerticalScrollPosition(target, offset, duration?)` | Scrolls vertically, animated over `duration` milliseconds. |
| `setHorizontalScrollPosition(target, offset, duration?)` | Scrolls horizontally, animated over `duration` milliseconds. |
| `animVerticalScrollTo(target, to, duration?)` | The animation behind `setVerticalScrollPosition`. |
| `animHorizontalScrollTo(target, to, duration?)` | The animation behind `setHorizontalScrollPosition`. |
