## Installation

::install-tabs{name="scroll-fade"}
::

The item adds `@import "@delta-ui/core/tailwind.css";` to your global stylesheet. That file, from the `@delta-ui/core` package, carries the utilities below and the ones delta-ui's components are drawn with. Every component adds the same import, and the CLI adds it only once.

## Two ways to fade

`scroll-fade` masks the scroll container: its content turns transparent towards the edges, over any background. It is shadcn-vue's utility with the same classes and variables, plus the [Firefox](#firefox) path and `-l` and `-r` that stay on their physical edge in right-to-left. The mask's gradient moves while you scroll, so while you scroll near an edge the browser repaints the whole masked area on every frame — noticeable on long lists and slow devices.

If you already import `shadcn-vue/tailwind.css`, it defines the same mask utilities. Tailwind keeps both definitions, and the additions here apply whichever comes first.

`scroll-fade-overlay` lays a gradient over each edge instead and only changes its opacity, which costs nothing while scrolling. The gradient runs to a colour, `--scroll-fade-color` (the page background by default), so it suits regions on a plain background.

On a [ScrollArea](/docs/components/scroll-area), use the overlay: it follows the area's `data-overflow-*` attributes and works in every browser. Elsewhere, both modes rely on scroll-driven animations to show an edge only once you can scroll back to it — see [Firefox](#firefox) for browsers without them.

The mask needs the scroll container itself, so it does not work on a ScrollArea, whose root is not the scroller — use the overlay there.

## Usage

```vue
<script setup lang="ts">
import { vScrollFade } from "@delta-ui/core/scroll-fade";
</script>

<!-- mask: on the scroll container itself -->
<div v-scroll-fade class="scroll-fade overflow-y-auto">…</div>

<!-- overlay: the scroll container must be the wrapper's only element child -->
<div class="scroll-fade-overlay overflow-hidden">
  <div v-scroll-fade class="h-full overflow-y-auto">…</div>
</div>

<!-- overlay on a scroll area -->
<ScrollArea orientation="horizontal" class="scroll-fade-overlay-x">…</ScrollArea>
```

The overlay's wrapper must have the scroll container as its only element child. A second child, or a component whose root is not the scroller, leaves the overlays hidden.

## Firefox

Firefox has no scroll-driven animations yet, so CSS alone cannot tell how far a region has scrolled there. Put `v-scroll-fade` on the scroll container: where scroll-driven animations are missing, it marks the element with `data-scroll-fade` and the edges it can still scroll towards with `data-overflow-x-start`, `-x-end`, `-y-start` and `-y-end`, the same attributes a ScrollArea sets, and the utilities fade by them. Where scroll-driven animations run, it does nothing.

## Reference

| Class | Mode | Edges |
|---|---|---|
| `scroll-fade`, `scroll-fade-y` | mask | top and bottom |
| `scroll-fade-x` | mask | start and end |
| `scroll-fade-t`, `-b`, `-l`, `-r`, `-s`, `-e` | mask | one edge; `s` and `e` follow the reading direction |
| `scroll-fade-<n>`, `scroll-fade-[<length>]` | both | sets `--scroll-fade-size`, the fade depth on the spacing scale or arbitrary |
| `scroll-fade-t-<n>`, `-b-<n>`, `-s-<n>`, `-e-<n>` | mask | depth of one edge |
| `scroll-fade-none` | mask | removes the mask |
| `scroll-fade-overlay`, `scroll-fade-overlay-y` | overlay | top and bottom |
| `scroll-fade-overlay-x` | overlay | start and end |
| `scroll-fade-overlay-s`, `-e`, `-t`, `-b` | overlay | one edge |
| `scroll-fade-overlay-none` | overlay | removes both overlays |

::css-vars
---
rows:
  - name: --scroll-fade-size
    default: min(12%, calc(var(--spacing) * 10))
    description: Depth of the fade, for both modes.
  - name: --scroll-fade-t-size
    default: --scroll-fade-size
    description: Depth of one edge in mask mode; also -b-, -s-, -e-.
  - name: --scroll-fade-reveal
    default: calc(var(--spacing) * 24)
    description: Scroll distance over which an edge fades in or out.
  - name: --scroll-fade-color
    default: var(--background)
    description: Colour the overlay gradients run to.
---
::
