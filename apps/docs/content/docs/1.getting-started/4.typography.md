Text follows Material 3's typescale: five roles in three sizes each. A role is a Tailwind utility that sets size, line height and weight together, so `text-label-lg` is all a button label needs, and `leading-*` or `font-*` still override one part of it.

| Role | For |
| --- | --- |
| `display` | The largest text on a screen: short hero lines and numerals. |
| `headline` | Page and section titles. |
| `title` | Titles inside a surface: a card, a dialog, a list group. |
| `body` | Running text. |
| `label` | Text inside controls: buttons, tabs, chips, form labels. |

## Usage

Pick the role by what the text does, not by how big it should be. Components do the same: every button label is `label-lg`, so changing that one role restyles all of them.

```vue
<template>
  <p class="text-label-md text-muted-foreground">Release 2.4</p>
  <h3 class="text-headline-sm">Faster sync for large projects</h3>
  <p class="text-body-md">Changes now stream in as they happen.</p>
</template>
```

The utilities come with the `tokens` item. `cn()` has to be told about them, or tailwind-merge drops them next to a text colour; see [Installation](/docs/getting-started/installation#what-installing-changes).

## Customising

Each role reads `--typescale-<role>-size`, `-line-height` and `-weight` from `:root`, so a role changes in one place:

```css
:root {
  --typescale-label-lg-size: 0.9375rem;
  --typescale-label-lg-weight: 600;
}
```

Because they are plain variables, they can also change with the screen. Material scales the large roles by window size rather than continuously; body and label stay put:

```css
@media (width < 600px) {
  :root {
    --typescale-display-lg-size: 2.8125rem;
    --typescale-display-lg-line-height: 3.25rem;
  }
}
```

There is no letter-spacing. Material's is tuned for Roboto, so text keeps the spacing its font was designed with. Font family is left to your project, but the label and title roles use weight 500, so pick a font that has one. Without it the browser falls back to regular: Segoe UI on Windows 10 is one such font.
