---
title: Sizing
description: One control scale behind every size prop, as tokens you can override.
---

Every control with a `size` prop takes its dimensions from one scale: a height, an inline padding, an icon size and the gap between icon and text for each of `xs` to `xl`. A Button, an Input and a Select of one size line up in a row, and a Menu item matches the Select that opened it.

## Scale

| Size | Height | Padding | Icon | Gap |
| --- | --- | --- | --- | --- |
| `xs` | 28px | 8px | 14px | 4px |
| `sm` | 32px | 10px | 16px | 6px |
| `md` | 36px | 12px | 16px | 8px |
| `lg` | 40px | 12px | 20px | 8px |
| `xl` | 48px | 16px | 20px | 8px |

Each cell is a variable on `:root`, added by the `tokens` item: `--control-height-md`, `--control-padding-md`, `--control-icon-md`, `--control-gap-md` and so on for every size. The values are steps of `--spacing`, so `--control-height-md` is `calc(var(--spacing) * 9)`, the same as `h-9`. Button's `default` size is `md`.

## What reads it

- **Height**: Button and everything built on it (Toggle, ToggleGroup, Toolbar, Pagination), Input, InputFloating's outline variant, Select, Combobox, InputNumber, TagsInput (as a minimum), PinInput, InputTime, InputGroup, Menu items and the lists of Select, Combobox and Command, Listbox options, Tabs triggers and ColorPicker's controls.
- **Padding**: the text fields (Input, InputFloating, Select, Combobox, InputNumber, TagsInput, InputTime, InputGroup's addons), Menu items, Listbox options and Tabs triggers.
- **Icon**: Button and everything built on it, InputTime, InputGroup's addons, Menu items, Listbox options and Tabs triggers.
- **Gap**: Button, Menu items, Listbox options and Tabs triggers.

Button pads wider than a field, from 10px at `xs` to 32px at `xl`, so it reads as an action.

## Customising

Override a token on `:root` and every control of that size follows:

```css
:root {
  --control-height-md: calc(var(--spacing) * 10);
  --control-padding-md: calc(var(--spacing) * 3.5);
}
```

A token set on an element reaches only the controls inside it. Menus, select lists and other overlays render under `<body>`, so they only see `:root`.
