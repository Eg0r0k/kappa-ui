## Lucide

kappa-ui draws its icons from [Lucide](https://lucide.dev) through the `@lucide/vue` package, as shadcn-vue does. Components that show an icon of their own, such as the check in a [select](/docs/components/select) or the chevron of a submenu, list `@lucide/vue` as a dependency, so the CLI installs it with them. To use Lucide in your own code, add it once:

```bash
pnpm add @lucide/vue
```

Each icon is a component named after it in PascalCase. Import only the ones you use, and the rest stay out of your bundle:

```vue
<script setup lang="ts">
import { Mail, Trash2 } from '@lucide/vue'
</script>

<template>
  <Mail />
  <Trash2 class="size-5 text-destructive" />
</template>
```

Lucide marks its icons `aria-hidden`, since an icon next to a label adds nothing for a screen reader. An icon on its own, such as in an icon button, needs a name on the element around it: `aria-label` on the button.

## Size and colour

Icons take the size of the component they sit in. Buttons, menu items, select options and similar parts make an icon without its own `size-*` class 16px, and the icon draws in `currentColor`, so it follows the text colour: muted in a menu item, `--destructive` in a destructive one. Give the icon a `size-*` or `text-*` class to override either.

In a [button](/docs/components/button), mark an icon beside the label with `data-icon="inline-start"` or `data-icon="inline-end"` so the button tightens its padding on that side:

```vue
<Button>
  <Plus data-icon="inline-start" />
  New project
</Button>
```

## Replacing a component's icon

Where a component draws its own icon, a slot takes a different one without editing the component:

| Component | Slot | Default |
| --- | --- | --- |
| Select, Listbox | `indicator-icon` | Check |
| Dropdown menu, context menu, menu: checkbox and radio items | `indicator-icon` | Check, dot |
| Switch | `checked-icon`, `unchecked-icon` | None |
| Select | `SelectScrollUpButton`, `SelectScrollDownButton` default slots | Chevrons |
| Dialog | `close` | X in a ghost button |

To change an icon everywhere, change the import in the component's source: the component was copied into your project, so it is yours to edit.

## Another icon set

Nothing depends on Lucide beyond those imports. Any Vue component that renders an `<svg>`, such as [Iconify](https://iconify.design) through `@iconify/vue` or `unplugin-icons`, sits in the same places and picks up the same size and colour, because the components style `svg` elements rather than Lucide's classes.

The check in a [checkbox](/docs/components/checkbox) and the [spinner](/docs/components/spinner) are drawn by the components themselves, not taken from an icon set: the check draws itself in as the box is ticked, and the spinner's arc grows and shrinks as it turns, which a static icon cannot do.
