A transition is an easing curve and a duration. Both come from Material 3 and ship with the `tokens` item as Tailwind utilities, `ease-standard` and `duration-medium-2` for example, and as variables for your own CSS.

## Choosing a curve

The curve follows where the element is going:

- **Staying on screen**, moving or resizing: `ease-standard`.
- **Entering**: a decelerating curve, so it arrives quickly and settles.
- **Leaving**: an accelerating curve, so it starts gently and gets out of the way.

The `emphasized` curves are the same idea with more character. Use them for the one element the user should follow, such as a dialog opening, and the `standard` ones for everything else.

## Choosing a duration

The duration follows how far and how large the change is. `short` covers small changes of state such as hover and selection, `medium` covers elements expanding or collapsing within the page, and `long` covers large surfaces entering or leaving. An exit is usually a step or two shorter than the matching entrance.

## Entering and leaving

::component-preview{name="motion-enter-exit"}
::

With Vue's `<Transition>`, give the entrance and the exit their own curve and duration:

```vue
<template>
  <Transition
    enter-active-class="transition duration-medium-2 ease-emphasized-decelerate motion-reduce:transition-none"
    leave-active-class="transition duration-short-3 ease-emphasized-accelerate motion-reduce:transition-none"
    enter-from-class="translate-y-2 opacity-0"
    leave-to-class="translate-y-2 opacity-0"
  >
    <Notification v-if="open" />
  </Transition>
</template>
```

`motion-reduce:transition-none` drops the movement for people who ask their system for less of it. delta-ui's own motion, the [ripple](/docs/utilities/ripple) and [press scale](/docs/utilities/press-scale), already does.

In your own CSS, read the variables and give a fallback, since Tailwind only emits a theme variable once something uses it:

```css
.drawer {
  transition: transform var(--transition-duration-long-1, 450ms)
    var(--ease-emphasized-decelerate, cubic-bezier(0.05, 0.7, 0.1, 1));
}
```

## Tokens

::css-vars
---
rows:
  - name: --ease-standard
    default: cubic-bezier(0.2, 0, 0, 1)
    description: Movement that starts and ends on screen.
  - name: --ease-standard-decelerate
    default: cubic-bezier(0, 0, 0, 1)
    description: Elements entering the screen.
  - name: --ease-standard-accelerate
    default: cubic-bezier(0.3, 0, 1, 1)
    description: Elements leaving the screen.
  - name: --ease-emphasized-decelerate
    default: cubic-bezier(0.05, 0.7, 0.1, 1)
    description: Prominent entrances, such as a dialog opening.
  - name: --ease-emphasized-accelerate
    default: cubic-bezier(0.3, 0, 0.8, 0.15)
    description: Prominent exits.
  - name: --transition-duration-short-1…4
    default: 50–200ms
    description: Small changes of state, such as hover and selection. Steps of 50ms.
  - name: --transition-duration-medium-1…4
    default: 250–400ms
    description: Elements expanding or collapsing within the page.
  - name: --transition-duration-long-1…4
    default: 450–600ms
    description: Large surfaces entering or leaving.
  - name: --transition-duration-extra-long-1…4
    default: 700–1000ms
    description: Full-screen transitions.
---
::
