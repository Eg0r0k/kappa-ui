## Requirements

delta-ui needs **Tailwind CSS v4**. Components rely on v4-only utilities and semantics — `size-9`, `min-h-svh`, v4 `outline` behaviour — that do not exist or behave differently on v3. The registry-item schema has no field to declare this, so check your project before adding anything.

Your project also needs `shadcn-vue` set up with a `components.json`, since the CLI is what copies the files.

## What installing changes

Some items write to your global stylesheet, not only to their own files. Decide before you install rather than after.

::callout{type="warning"}
**Adding the button sets `--radius`.** delta-ui ships its own radius scale — `--radius: 0.75rem`, with `--radius-sm/md/lg/xl` derived from it. Because `--radius` is the same variable shadcn components read, if your project already uses shadcn, their corners change to match. That is intentional, but it is project-wide. To opt out, set `--radius` back in your own CSS after adding the component; the component itself only uses `rounded-lg`.
::

The button also adds the base rule `shadcn-vue init --pointer` installs. Tailwind v4 removed the pointer cursor from buttons; this restores it for every button in your project, not only delta-ui's:

```css
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) { cursor: pointer; }
}
```

Components also ship five easing curves — `--ease-smooth`, `--ease-snappy`, `--ease-gentle`, `--ease-bouncy` and `--ease-elastic` — usable as the utilities `ease-smooth`, `ease-snappy` and so on. The names are delta-ui's own, so unlike `--radius` they cannot collide with anything shadcn defines. Tailwind only emits a theme variable once something uses it, so unused curves are absent from your compiled CSS until you reference them.
